# 受限前提的复合

题面：给定集合 A、B、C，函数 f:A→B、g:B→C，谓词 P、Q、S 分别定义在 A、B、C 上。
已知对每个 a，P(a)⇒Q(f(a))；对每个 b，Q(b)⇒S(g(b))。
证明对每个 a，P(a)⇒S(g(f(a)))。
