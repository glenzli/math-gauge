# 局部保持条件的两步使用

题面：X 为任意集合，U⊆X，R 为 X 上任意二元关系，f:X→X。
已知 f(U)⊆U；并且对 x,y∈U，R(x,y)⇒R(f(x),f(y))。
证明对 x,y∈U，R(x,y)⇒R(f(f(x)),f(f(y)))。
不要求 U 非空，也不要求 R 是等价关系。
