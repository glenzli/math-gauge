# 参考审核：双重平均与不变记录

题面的弱目标成立。设 $Z=\ker(I-T)\cap\ker(I-S)$，$D$ 为双重平均范数收敛的全部状态。准确结果为

$$\{x:A_{N,M}x\to0\}=Y,\qquad D=Z\oplus Y,$$

$D$ 是闭子空间，极限 $P:D\to Z$ 为有界投影，$\ker P=Y$、$\|P\|\le K_TK_S$。一般 $D\ne E$，也不推出算子范数收敛。

## 从实际平均算子出发

令 $U_N=N^{-1}\sum_{i<N}T^i$、$V_M=M^{-1}\sum_{j<M}S^j$。交换性给出 $A_{N,M}=U_NV_M$，并且 $\|A_{N,M}\|\le K:=K_TK_S$。

望远镜恒等式给出

$$A_{N,M}(I-T)=\frac{I-T^N}{N}V_M,\qquad A_{N,M}(I-S)=U_N\frac{I-S^M}{M}.$$

因此它们分别在 $(I-T)E$、$(I-S)E$ 的每个固定向量上趋于零。对其和仍趋零；再用统一的算子界 $K$ 和范数稠密逼近，得到 $A_{N,M}y\to0$ 对所有 $y\in Y$。

另一方面，$I-U_N$ 是 $(I-T)$ 乘一个算子多项式，$I-V_M$ 同理。由

$$I-U_NV_M=(I-U_N)+U_N(I-V_M)$$

及交换性，$x-A_{N,M}x\in (I-T)E+(I-S)E\subset Y$。这证明平均保持商记录。如果平均趋于零，由 $Y$ 闭可得 $x\in Y$，完成零记录的双向刻画。

## 收敛域与投影

若 $A_{N,M}x\to z$，则

$$\|(I-T)A_{N,M}x\|\le\frac{(1+K_T)K_S}{N}\|x\|,$$

以及对 $S$ 的对称估计，故连续性给出 $Tz=Sz=z$。又 $x-A_{N,M}x\in Y$ 且 $Y$ 闭，所以 $x-z\in Y$。因此 $D\subset Z+Y$。

反过来，若 $x=z+y$，其中 $z\in Z,y\in Y$，则 $A_{N,M}x=z+A_{N,M}y\to z$。若 $z\in Z\cap Y$，同一平均既恒等于 $z$ 又趋于零，故 $z=0$。于是分解为直和，极限唯一。

定义 $P(z+y)=z$。极限的线性及 $\|A_{N,M}\|\le K$ 给出 $P$ 线性、$\|Px\|\le K\|x\|$；$P^2=P$、像为 $Z$、核为 $Y$。

还须证明 $D$ 闭。设 $x_j\in D$、$x_j\to x$。上面的界使 $Px_j$ 成为 Cauchy 列；Banach 完备性及 $Z$ 闭给出 $Px_j\to z\in Z$。于是 $x_j-Px_j\to x-z\in Y$，故 $x\in Z+Y=D$。没有预先假定整个 $E$ 可分解。

投影因而给出 $D/Y\cong Z$。若 $q:E\to Q$ 是商映射，则

$$\|qz\|_Q\le\|z\|\le K\|qz\|_Q\qquad(z\in Z),$$

第二个界通过对 $z+y$ 使用 $P$ 后取 $y\in Y$ 的下确界得到。因此可恢复的不变记录 $q(Z)$ 是 $Q$ 中闭子空间，但它未必是整个 $Q$。

## 不能推广到全部状态

取 $E=\ell^1(\mathbb N_0^2)$，$T,S$ 为沿两坐标的右移，二者交换且所有幂范数为 $1$。令 $e_{00}$ 为原点单位质量，则 $A_{N,M}e_{00}$ 是 $N\times M$ 方块上的均匀质量，范数始终为 $1$，每个固定坐标却趋于零。若范数收敛，坐标连续性迫使极限为零，与范数矛盾。

这里 $Z=0$：右移固定的绝对可和序列沿首行归纳只能为零。总质量泛函连续、消去两个差分范围，所以 $e_{00}\notin Y$，其商记录非零且不能由不变向量恢复。

事实上 $Y$ 恰为总质量为零的闭子空间。每个有限支撑零质量向量都可写成有限个 $e_{ij}-e_{00}$ 的线性组合；沿格路径望远镜展开可把每项写成两个差分范围之和。任意零质量 $\ell^1$ 向量用有限截断、并在原点补回截断质量，可由这类有限支撑向量范数逼近。

## 更强结论的准确位置

如果额外假设 $E$ 自反，则每个有界网 $A_{N,M}x$ 有弱收敛子网。连续估计使弱极限属于 $Z$；$Y$ 为范数闭线性子空间，Hahn–Banach 保证它弱闭，所以 $x-z\in Y$。这时 $D=E$。这是显式条件化结论，不是题设。

即便 $E$ 是 Hilbert 空间，也不因此有算子范数收敛。取 $E=\ell^2(\mathbb N_0^2)$ 上同样的右移：自反性与 $Z=0$ 给出每点平均趋零，但 $\|A_{N,M}\|=1$。上界为 $1$；对固定 $N,M$，用 $L\times L$ 方块上值为 $1/L$ 的单位向量，内侧方块的输出仍为 $1/L$，给出下界 $\sqrt{(L-N+1)(L-M+1)}/L\to1$。
