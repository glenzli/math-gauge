# 共享运行器验证

本次中性发布改动的[定点证据](v0.3.0/neutral-release-delta.json)覆盖88项工具/旧格式检查，另有3项输入投影检查。6个初次失败用例按两个根因修正后单独通过；没有重复全套。此前406通过、17跳过的完整运行及旧离线收据保留原输入身份，不能当作新源码全量验收。设计计划的 `pending-new-version-validation` 仅表示当前没有重新签发完整验收；当前发布链路的定点结果另行绑定。

当前默认合同为32题、80槽：全部题A1进入四类能力分，六题panel额外A2/A3只进入重复稳定性，同六题各开三分支两轮。11题reserve经显式manifest使用同一运行器，不进入默认导出。题文、附件、KEEP/FULL与原样Lean证据门槛保持。

新版离线验收使用独立的 `offline-acceptance-v0.3.0.json` 与 `v0.3.0/logs/`；当前材料检查只核验实际保存的日志、命令、计数和输入身份，不自行重跑或重绑旧测试结果。旧 `offline-acceptance.json` 和原日志保留为其源码版本的历史证据，不声称它们验证了新版。

重点回归覆盖逐题初答安排、A1能力分不受额外重跑加权、固定分母与缺测、分支原始历史、KEEP/FULL材料、具名审核、原样Lean收据、追加式运行审核，以及独立控制器的check/freeze/request/record/pack/import。离线合成答卷始终标fixture，不能变成模型成绩；验证不调用候选模型或Lean。

旧177槽运行按原profile、原答卷和同一审核快照可继续读取与评分。新版工程曾对root冻结报告复算，分项、逐题、切片、轨迹、配对、分母、覆盖及资格字段均保持相同；对照身份见 `v0.3.0/legacy177-comparison.json`。公开结果及限制见[旧版试跑记录](../../docs/terra-pilot-2026-11-02.md)。

任务包仍保持solver/controller/evaluator边界。新版控制器按显式slots区分core与repeat，兼容旧controller/dataset；默认包只有32题任务和约定附件，参考、rubric、完整profile、选择及作者证据不进入候选材料。旧发布资产不重打、不替换；新版当前只准备源码与配置，未发布。

工程验收、AI数学审核、作者编译、候选原样Lean核验和人工批准分别记录。题目仍human pending，新版0.3.0尚无候选运行；旧177槽为单独保留的AI暂定开发结果。
