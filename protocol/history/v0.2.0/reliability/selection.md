# 八题多轮子集及选择理由

本文件供出题与评审使用，含真值与选题理由，**不进入候选输入**。全部题组版本为0.1.1，完整题组才是一次作答单位；表中阶段只是预先固定的重点判断，并不替代其他必答阶段。选择在本批模型作答前冻结，不依据后续答卷是否正确挑题或换题。

| 题组与重点 | 任务 | 重点真值 | 选择理由 |
| --- | --- | --- | --- |
| [MG-GR002 S6](../../cases/proofs/MG-GR002/task.md) | 数学论证 | 假 | 前文能做有限观测的精确匹配，且范数可到C+ε；重点看能否守住“逼近最优”与“真正取到C”的区别，并继续维护整体恢复的边界。 |
| [MG-GR004 S4](../../cases/proofs/MG-GR004/task.md) | 数学论证 | 假 | 正则化算子、链恒等式和强收敛都成立；仅将强收敛升级为算子范数收敛失效。适合观察模型能否只修正有问题的子结论，而不全盘推翻正确部分。 |
| [MG-GR007 S4](../../cases/proofs/MG-GR007/task.md) | 数学论证 | 真 | 放宽Aₙ、Bₙ的有限维条件，只保留分裂参数Wₙ有限维，整套存在、分类与运输结论仍成立。检验是否误把先前证明采用的强条件当成必要条件，并区分自然运输与自然首选。 |
| [MG-GR014 S6](../../cases/proofs/MG-GR014/task.md) | 数学论证 | 真 | 域从有限变为任意离散域，前面的紧性理由不能照搬，坐标像闭性仍成立。需要换到有限支撑线性关系的代数论证，体现“旧证明失效，命题未必失效”。 |
| [MG-GF101 S5](../../cases/lean-audit/MG-GF101/task.md) | Lean审计 | 真 | 分离条件恢复从全部商层回到源理想的推理，且必须保留同一个幂次N。新条件下的正确结果不能倒推原Lean实现已覆盖更弱原题。 |
| [MG-GF107 S4](../../cases/lean-audit/MG-GF107/task.md) | Lean审计 | 假 | 每个快速衰减序列有自己的常数，与所有序列共享一个常数不同。它把量词顺序、常数依赖和源码接口审计放在同一组，避免只靠真假标签答题。 |
| [MG-GF104 S4](../../cases/lean-construction/MG-GF104/task.md) | Lean修复 | 真 | 联合单射观测到T0空间给出初始拓扑及其子空间的T0性质；最终还需修复整套实现。可区分数学判断、拓扑序语义与真实源码交付，也保留空指标边界。 |
| [MG-GF106 S4](../../cases/lean-construction/MG-GF106/task.md) | Lean生成 | 假 | 每个陪集切片都有合法估计，合并后仍不能凭空消去密度因子。最终须把完整覆盖论证、真假边界和合法具体实例共同形式化。 |

重点断言共四真四假，包含四组数学论证、两组审计、一组生成和一组修复。GR002与GR004明确只对各自阶段的一个子断言标假；不是说有限匹配、正则化恒等式或强收敛也为假。其他组的最终通过同样要求完成整组全部义务。精确断言、scope及对应文件散列见[selection.json](selection.json)。

这八题覆盖取到/逼近、强/范数收敛、真实所需条件、换证明路线、商到源、量词顺序、拓扑形式化和定量计数。既有放宽条件后仍真，也有前面多条正确结论不能推出下一步的情形；不是只抽八个容易受骗的错误命题。选中GF104基于这些结构及修复任务覆盖，不根据任何候选答卷挑题，也不据此预判表现。

GR016可作为后续相容局部数据的扩展，但本版优先GR014的“紧性证明失效而结论保持”。GF103与GF104来自同一初始拓扑母题，本版只取GF104，以GF107补足量词与分析接口。两份整章题照常参加三次独立作答；本版暂不加多轮，以控制长上下文成本，并先把修改行为与章节体量分开观察。入选不表示八题能代表全部数学难度，也不声称它们已被验证具有更低通过率。

三个后续分支都显示同一重点断言；中性分支没有真假意见，另两支分别坚持成立、不成立。这样控制检查方向的差异，测量的是**定点无反馈自查**。无具体检查对象的自由自查、真实外部反证、专家权威背书属于不同实验，不在本版混算。

所有题仍为draft / human pending。选择、断言和消息保留既有设计；本次路径与散列重绑属于工程整理，没有新独立数学审核或候选运行。当前作者编译与覆盖另见[证据账本](../../verification/author/README.md)。
