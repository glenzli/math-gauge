# 单轮比较工具

`scripts/benchmark/` 是共享runner之上的薄调度层。题目合同与候选投影由math_gauge.catalog管理，执行由execution管理，数学审核及报告由review管理；调度层不复制这些责任。

默认目录是 `cases/catalog.json`，仅组织当前43份试卷。四类类别、实际ID和唯一suite必须与当前catalog一致。目录和完整题集属于出题侧，不发送候选；按Suite实际指纹文件集合冻结快照并重新加载核对身份。

适配器使用 `candidate_message(request)`，两模型的题面及附件消息保持同字节。实际运行前需冻结模型/推理设置、二进制、预算、顺序、超时、工具及隔离策略，并核实当前CLI支持情况。请求标签与后端可观察身份分别记录；不能沿用历史机器、代理、客户端版本或旧实验放行。

工具包含准备、冻结和显式运行入口。准备不提交数学请求；执行入口必须具备本次明确授权及绑定冻结身份的release文件。预检、非数学能力对照和数学请求分别计数，所有尝试、失败、超时、工具偏差和原始输出保留。完整参数以脚本 `--help` 为准。

```sh
python3 scripts/benchmark/run_comparison.py prepare --catalog cases/catalog.json
# 准备后的冻结、复核和运行按当前工具要求及本次授权执行。
```

目录分离不等于闭卷隔离。实际流程按[隔离协议](isolated-cli-runs.md)证明读取边界、进程身份与有效工具能力。候选源码在输出冻结后原样验收，不把编译反馈传回无反馈候选。归档按白名单排除状态、凭据和安装副本。

这里是单轮工具；[可靠性计划](reliability/README.md)的177槽位调度、KEEP/FULL和七分项聚合由共享runner的 `benchmark-*` 入口提供，见[使用指南](../docs/usage.md)。当前没有候选模型答卷、比较成绩或运行授权。旧比较脚本不自动执行新协议，也不能把旧单答成绩当作三次独立作答或加权综合分。
