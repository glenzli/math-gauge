状态：**材料已准备；未启动候选模型；未产生新通过率。** 本版采用清理后的0.1.1题面，人工审核与新增目标的完整作者Lean核验仍待完成。

- [执行协议](../reliability-execution.md)：全题三次独立作答，固定A1分支，八题各做中性/支持/怀疑两轮，无正确性反馈。
- [评分标准](../reliability-scoring.md)：整组完成、三次稳定性、真实纠错、改坏答案、未完成补全、立场影响与错误归因分别报告。
- [八题及选择理由](selection.md)：四真四假，四论证、两审计、一生成、一修复；[精确清单](selection.json)绑定阶段、断言及来源身份。
- [冻结消息](prompts.json)：48条后续消息；每条只投影content。[共同作答格式](reply-format.md)支持KEEP和完整重答FULL，暂不引入局部补丁。
- [运行计划](plan.json)与[槽位表](schedule.json)：43份试卷×3次初答，加8×3分支×2轮，每模型177个计划槽位；两模型槽位共354，实际调用为0。
- [离线材料核验](validation.json)：题面边界、数学不变性、版本/来源、八题平衡、消息及历史依赖检查；[复核记录](reviews/README.md)保留独立意见与处置。

主试卷是[41个递进题组](../../drafts/progressive-groups-20261030/README.md)和[两份整章题](../../drafts/chapter-exams-20261030/README.md)。原41道单题保留历史材料及已有结果，不与扩展题重复计入43份。分值和逐阶段判准位于评审合同、rubric及评分标准，候选题面保留数学条件、目标和交付要求。

本包是准备好的执行规格与材料，现有共享runner尚未实现并验收多轮编排及KEEP引用解析。模型真实后端、预算、超时及重试等待策略在实际运行前核实并冻结；每槽位最多两次传输attempt已在协议中固定。不得把当前计划直接当成已验收可启动的调度器。用户当前明确要求不跑模型，`execution_authorized=false`。

在仓库根目录运行 `python3 protocol/reliability-20261030/validate_materials.py` 可只读复核本包、43份候选投影及归档差分，不调用模型或Lean。材料有明确修订且完成复核后，才用 `--write-report` 刷新本地核验记录；此选项也不执行模型。

选择依据、真值、合同、评分与复核文件均属于评审侧。公开可读不等于可附入候选上下文；实际首答只使用显式题面和附件，后续只使用本分支原始历史及对应消息content。
