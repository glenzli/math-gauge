# 当前题包分发

Benchmark0.6.0仍是本地草稿，尚未发布。公私使用同一版本；公开题包只含当前26份任务的题文和明确附件，私有部分另行受控交付。参考、判准、真假、完整评审计划、审核及作者目标实现留在评审端。

release准备前须冻结候选投影、操作说明和[正式结果记录合同](result-record.md)。单一操作者README须说明如何保存完整原答、自评、完整交付、逐轮变化、最终状态与缺失材料；操作者说明不作为额外候选提示。候选作答要求只来自其实际收到的版本化题文与提示。

当前共享工具可准备v1目录包并独立核验，同一冻结计划可选不同预算兼容的分组。新C003为每轮10800秒，其余七项新Lean为5400秒，书面和新AR为2700秒，使用独立runtime。命令见[运行指南](../docs/running.md)。准备与打包不调用模型，实际派发仍需相应接入能力。

完整性清单绑定全部交付字节，原始输入或明确声明的投影必须可由可信来源重建。版本、UUID或散列本身不认证后端、运行时间或隔离。当前收集记录不把旧答改称新执行；不因记录格式变化补造历史自评。

每次模型、预算或目标选择使用新运行目录，题包保持不可变。工程在首次原生终态或截止时停止写入并封卷；所有原始尝试、失败、超时和未知项保留。最终正式档案仅在用户选定固定留档时保留。

旧发行配置与旧成绩已交由Git历史，本工作树不复刻历史版本。既有远端发布资产本次不做修改。未来发布使用同版本题集、精确干净源提交及单独授权；本次项目整理没有发布或推送。
