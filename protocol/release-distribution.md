# 0.6.0题包分发

0.6.0已封版。公私使用同一benchmark版本：公版25个独立A1；受控完整私版39个独立A1，含公25／私14、35个数学家族。C003另外固定连续三轮，共42次规定交付；三轮不增加独立家族，不在A1便携清单内自动调度。

统一运行、答题结构、交付和记录要求见[Harness指南](../docs/harness-guide.md)。公版README与独立指南均为operator资料；候选仅接收生成的精确角色消息、明确附件、冻结参数及允许的自身历史。参考、判准、预期真假、作者实现、原答、评审和完整计划不进入候选ZIP或候选上下文。

公开候选资产由scripts/release.py从精确干净提交生成，并独立校验内容白名单、源码／投影字节和SHA256SUMS。现有公开v3中性投影只改已版本化的输入身份表面；题文、数学结构和证明要求保持。评审计划留在外侧，可由同版本源码恢复。GitHub自动源码归档不等于候选题包。

受控私版使用同一公有发布器的external v2完整数据路径，并发布39题完整包与单独评审计划。包内local_dataset来源类型保持原交换语义；发布层release-lock.json另外绑定精确公私源码提交、共同runner、资产散列与数量。私有原题、原答、逐题评审、私版ZIP及评审计划只发布到已确认的私有仓库。私库不复制另一份runner实现，不纳入candidates/或临时运行目录。

发行包附同版本三轮合同与固定提示。每个模型和预算使用新的runtime／工作区；普通任务2700秒，其余七项Lean5400秒，C003初答与各自查轮10800秒。原生、broker、外层预算分别冻结；首次原生终态或截止即停止写入并封卷。完整原答、自评、实际交付、失败和全部物理请求保留，未知项不补造。

便携控制器的每槽两次transport交换与benchmark三次有效模型尝试分别记录，正式接纳还需完整尝试账本；详见统一指南。最终以共享评分器按固定权重聚合，不发布重新归一化的公有或私有总分。封版不改变AI／人审状态或未知覆盖。

发布的v0.6.0标签和资产固定，不覆盖旧发行；后续数学更改另发版本。构建、检查、导入和打包均不调用候选模型。
