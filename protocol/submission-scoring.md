# 正常交卷与截止工程

提交来源组件0.1.0配合聚合方法0.9.0、MC0.3.0使用；SMC保留Strict0.2.0的数学要求。题目、39个初答分母、三轮自查和35／35／30权重不变。此调整在观察已有答卷后确定，不改写既有0.8.0结果及原始审核。

每题在各尝试条件内采用第一份正常交卷。正常交卷后停止该题，不为数学错误重跑，不比较数学分数择优。同题有正常答卷时，三个评分都只审核这份实际交付的内容；未随它交付的更大工作区工程不能补入。正常交卷可以不完整或错误，是否数学正确由独立评审判断。单凭进度句、文件非空、工具DONE或正常进程退出，不能认定数学答卷已经交付。

只有在该条件内没有正常交卷时，MC才可审核最后一次有效尝试在截止前已存在的原始数学正文或完整工程文件。必须绑定原字节、尝试、截止证据和独立数学审核；Lean还须核验完整原模块及其实际依赖、公理和语义。没有Main时不制造Main，不补import，不截断失败文件来取得可编译片段，也不替模型修源码。完整的独立模块可单独审核。原环境、给定背景和数值实验脚本不自动成为证明成果；不从思考日志拼出答案。不借其他尝试或后续自查补齐本次答卷。

无正常交卷的任务，RMC与SMC均为0。MC只累计上述可核实的有效数学工作，保留全部原题要求为分母；错误或缺失部分不给分，也不把已完成部分放大为满分。GR021–023的10分可靠性项仍从MC正向分母剔除，只归一其90分数学要求。已在原数学审核计过的同一正文只引用一次。

排行榜以“主动交卷／强收有内容／总初答题数”列示提交进度。前两项互斥；强收计数表示存在可评审的数学内容，允许其MC为0。只有环境、进度或数值脚本的空交付不计强收。三轮自查另列，每轮独立采用其实际来源，不能跨轮择优；没有正常交卷的轮次RMC为0，且整段SMC轨迹失败。无正常交卷但有对应轮次原成果时，MC仍可按该轮原来源审核。

没有运行的任务保持未知。只有明确授权暂按0记录的缺失原档可以暂置0，须标“待补原记录复核”，不能写成已证实白卷或虚构原生终态。GLM三项末次缺档最初采用该暂记方式，已于2026-11-11补原记录后另建源绑定复核凭据销项；原暂记判断保留，不补跑。来源审核完成不把未执行的自查改成已交付。

完整提交分类、非final工作审核及来源留在私库；公库只提供公有逐题分类、三段计数和匿名私有统计。所有当前结果另绑新组件及方法身份，旧方法、六种分数视图和原审核字节继续保留。页面只读共享评分器输出。
