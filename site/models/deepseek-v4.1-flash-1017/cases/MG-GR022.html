3.5 pp 诱导的完成映射

因为 Q^≃C^,C^^≃C^, \widehat Q\simeq\widehat C,\qquad \widehat{\widehat C}\simeq\widehat C, 故 pp 诱导的完成映射 p^:Q^⟶C^^ \widehat p:\widehat Q\longrightarrow\widehat{\widehat C} 在同构 Q^≃C^,C^^≃C^ \widehat Q\simeq\widehat C,\qquad \widehat{\widehat C}\simeq\widehat C 下就是恒等映射： p^:C^⟶C^ 是恒等同构. \boxed{ \widehat p:\widehat C\longrightarrow\widehat C \text{ 是恒等同构}. } 特别地，p^\widehat p 是满射且是单射。

另一方面，因为 E=⋂mtmQ, E=\bigcap_m t^mQ, 包含映射 E↪QE\hookrightarrow Q 的完成映射 E^→Q^ \widehat E\to\widehat Q 在同构 E^≃E\widehat E\simeq E、Q^≃C^\widehat Q\simeq\widehat C 下是零映射： E^⟶Q^ 为零映射. \boxed{ \widehat E\longrightarrow\widehat Q \text{ 为零映射}. } 这正是完成函子在非有限生成模上不保持左正合的体现。

3.6 EE 的两种拓扑比较

1. 从 QQ 继承的子空间拓扑

由定理 3.1， E=⋂m≥1tmQ. E=\bigcap_{m\ge1}t^mQ. 因此对每个 mm， E∩tmQ=E. E\cap t^mQ=E. 所以 EE 从 QQ 继承的子空间拓扑是平凡拓扑（不可分拓扑）：其零点邻域基只有 EE 本身。

2. EE 自身的 tt-进拓扑

自身的零点邻域基为 tmE=Wm+VV. t^mE=\frac{W_m+V}{V}. 断言： ⋂m≥1tmE=0. \boxed{ \bigcap_{m\ge1}t^mE=0. } 证明如下。设 e=[c]∈⋂mtmEe=[c]\in\bigcap_m t^mE，c∈Wc\in W。对每个 mm，存在 d(m)∈Wmd^{(m)}\in W_m 及 v(m)∈Vv^{(m)}\in V，使得 c=d(m)+v(m). c=d^{(m)}+v^{(m)}. 固定 MM。取 m≥Mm\ge M。因为 d(m)∈Wmd^{(m)}\in W_m，故 dn(m)∈tmS⊆tMS∀n. d^{(m)}_n\in t^mS\subseteq t^MS\qquad\forall n. 又 v(m)∈Vv^{(m)}\in V，故对除有限个之外的 nn， vn(m)∈tmS⊆tMS. v^{(m)}_n\in t^mS\subseteq t^MS. 于是对除有限个之外的 nn， cn∈tMS. c_n\in t^MS. 由于 MM 任意，得到 vt(cn)→∞, v_t(c_n)\to\infty, 即 c∈Vc\in V，从而 e=0e=0。因此 ⋂mtmE=0. \bigcap_m t^mE=0. 所以 EE 自身的 tt-进拓扑总是分离的。

3. 两种拓扑何时相同

  • 若 E=0E=0，两种拓扑当然相同。
  • 若 E≠0E\ne0，自身拓扑是分离的，而继承拓扑是平凡拓扑，故两者不同；更精确地，自身的 tt-进拓扑严格细于继承拓扑。

因此 E 的自身 t-进拓扑等于从 Q 继承的子空间拓扑  ⟺  E=0  ⟺  sup⁡n≥1νn<∞. \boxed{ E\text{ 的自身 }t\text{-进拓扑等于从 }Q\text{ 继承的子空间拓扑} \iff E=0 \iff \sup_{n\ge1}\nu_n<\infty. }
