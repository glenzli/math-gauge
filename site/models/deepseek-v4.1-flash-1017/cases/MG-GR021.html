(b) C\mathcal C 的约化

(c) 固定点集的约化

2.4 哪些固定类能提升为真正的 σ\sigma-固定解

若 U∈SK(A)U\in S_K(A) 且 σμ(U)=U\sigma_\mu(U)=U，则 UU 的系数全在 F=Q2F=\mathbb Q_2 中，故 SK(A)σμ=SF(A). S_K(A)^{\sigma_\mu}=S_F(A). 因此：

  • 一个 CK,M(A)\mathcal C_{K,M}(A) 中的固定类 Uˉ=A+2M−1θC \bar U=A+2^{M-1}\theta C 能提升为真正的 σμ\sigma_\mu-固定解 U∈SK(A),σμ(U)=U U\in S_K(A),\qquad \sigma_\mu(U)=U 当且仅当 C=0且A∈RF,M(A). \boxed{ C=0 \quad\text{且}\quad A\in\mathcal R_{F,M}(A). } 这里 AA 是基域精度 MM 的类；A∈RF,MA\in\mathcal R_{F,M} 正表示它能提升为 SF(A)S_F(A) 中的真正解。

  • 一个固定类能作为某条逐层相容的固定矩阵类序列 (Uˉm∈CK,mσ)m≥M (\bar U_m\in\mathcal C_{K,m}^{\sigma})_{m\ge M} 在精度 MM 的分量，当且仅当同样有 C=0且A∈RF,M(A). \boxed{ C=0\quad\text{且}\quad A\in\mathcal R_{F,M}(A). } 原因是从 M+1M+1 到 MM 的固定类约化会把顶层的非零 CC 杀死；若某一层 C≠0C\ne0，它甚至不能提升到下一层的固定点集。所以无限相容的固定类序列的每一层缺陷都必须为零，其极限正是 SF(A)S_F(A) 中的一个真正固定元素。

  • 对 RK,Mσ\mathcal R_{K,M}^{\sigma} 同样：一个固定类能来自真正的 σ\sigma-固定解，当且仅当它属于嵌入的 RF,M(A)⊂SK(A)σμ. \mathcal R_{F,M}(A)\subset S_K(A)^{\sigma_\mu}.

3. 从 KμK_\mu 向基域下降的最优精度 NN

固定块大小、μ\mu、M≥2M\ge2。令 Nmax⁡N_{\max} 为满足题述性质的最大整数 N∈{0,…,M}N\in\{0,\dots,M\}。

3.1 统一上界

设 U∈SK(A),σμ(U)≡U(mod2MOK). U\in S_K(A),\qquad \sigma_\mu(U)\equiv U\pmod{2^M O_K}. 由 2.1，存在 U≡A+2M−1θC(mod2MOK), U\equiv A+2^{M-1}\theta C\pmod{2^M O_K}, 其中 A∈CF,M(A),C=diag⁡(C1,…,Cr),Cj=CjT∈Mnj(F2). 3.2 最优性：只要某个 nj≥2n_j\ge2，就有 Nmax⁡=M−1N_{\max}=M-1

设某块 nj≥2n_j\ge2。取合法输入 Ai=Ei(i=1,…,r). A_i=E_i\qquad(i=1,\dots,r). 记 J=(01−10). J=\begin{pmatrix}0&1\\-1&0\end{pmatrix}. 在 njn_j 维块中取矩阵 [ U_M^{(j)}

(I+2^{M-2}\theta J)(I-2^{M-2}\theta J)^{-1} \oplus I_{n_j-2}, ] 并令其余块上为恒等矩阵，从而得到 UM∈Od(OK). U_M\in O_d(O_K). Cayley 变换保证 UMTUM=Id,UM≡Id(mod2). U_M^{\mathsf T}U_M=I_d,\qquad U_M\equiv I_d\pmod2. 展开 UM(j)=I+2M−1θJ+O(2M). 但任何基域矩阵 W∈SF(A)⊂Md(Z2)W\in S_F(A)\subset M_d(\mathbb Z_2)，模 2MOK2^M O_K 后 θ\theta-系数为零；而 UM mod 2MOKU_M\bmod2^M O_K 的 θ\theta-系数在 2M−12^{M-1} 位为 J≠0J\ne0。故 UM≢W(mod2MOK) U_M\not\equiv W\pmod{2^M O_K} 对一切 W∈SF(A)W\in S_F(A) 都成立。于是该 A,UA,U 下不能取 N=MN=M，从而 Nmax⁡≤M−1. 3.3 全部 nj=1n_j=1 的情形：精确下降

若 n1=⋯=nr=1, n_1=\cdots=n_r=1, 则 HL=∏j=1rO1(OL)={±1}r H_L=\prod_{j=1}^r O_1(O_L)=\{\pm1\}^r 中每个元素都来自基域，且被 σμ\sigma_\mu 固定。若 SK(A)≠∅S_K(A)\ne\varnothing，取 U0∈SF(A)U_0\in S_F(A)（由同一可行性判准），则 SK(A)=U0{±1}r=SF(A)⊂GLd(Z2). 3.4 对给定 A,UA,U，何时可以取 N=MN=M

对具体的合法 AA 和 U∈SK(A),σμ(U)≡U(mod2MOK), U\in S_K(A),\qquad \sigma_\mu(U)\equiv U\pmod{2^M O_K}, 有 N=M  ⟺  ∃W∈SF(A) s.t. U≡W(mod2MOK). \boxed{ N=M \iff \exists W\in S_F(A)\ \text{s.t.}\ U\equiv W\pmod{2^M O_K}. } 等价地，把 UU 的固定类写成 U≡A0+2M−1θC(mod2MOK),A0∈CF,M(A), U\equiv A_0+2^{M-1}\theta C\pmod{2^M O_K}, \qquad A_0\in\mathcal C_{F,M}(A), 则 N=M  ⟺  C=0 且 A0∈RF,M(A). \boxed{ N=M \iff C=0 \ \text{且}\ A_0\in\mathcal R_{F,M}(A). } 若 C≠0C\ne0，则连模 2M2^M 的基域逼近都不存在，因此不可能精确下降；若 C=0C=0 但 A0∉RF,M(A)A_0\notin\mathcal R_{F,M}(A)，则该类只是形式上的固定类，不能提升为真正的基域正交解，仍不能取 N=MN=M。
