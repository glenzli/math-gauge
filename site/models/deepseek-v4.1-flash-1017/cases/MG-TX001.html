我们有下面这个想法，想尝试证明。

设 p≥3 是素数，r≥2 是整数，N=p^r。取 0≤a_1<a_2<a_3<N，假设 a_1、a_2、a_3 模 p 两两不同。再取不全为零的复数 c_1、c_2、c_3，令

P(z)=c_1z^{a_1}+c_2z^{a_2}+c_3z^{a_3}。

我们的想法是：在全部 N 次单位根中，满足 P(z)=0 的不同根至多有两个。

请尝试证明这个结论。

判定与主要理由

  • The identity drops the constant t-1. In fact G_t(y)-G_t(1)=sum_{k=1}^{t-1}(y^k-1). Already for permitted p=3,N=9,t=2 and y a nontrivial ninth root, its value is y-1, whereas the displayed sum is y. This is a local algebra error; the correct uniform S_k calculation already in the answer repairs the required case without new mathematics.

  • Two different roots of the same p-power order need not have a quotient of that same order. Take p=3,N=9,x=zeta_9,y=zeta_9^4: both have order 9, while x/y=zeta_9^6 has order 3, so the displayed equality of valuations is false. This assertion is not needed by the subsequent residue calculation, which only uses x,y == 1 mod P.
