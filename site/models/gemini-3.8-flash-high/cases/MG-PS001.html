提交来源

正常交卷；三种评分采用实际交付。

判定与主要理由

  • The asserted crossing start n/N_next->1 and crossing bound omit growth before crossing. In the actual a=3,b=2 construction, n~N_next/2 gives f^2(n)/n->6, exceeding the claimed bound3; the all-parameter root proof is not delivered.

  • The asserted positive boundary lower bound does not follow from its displayed growth condition. The actual map is increasing by a valid direct floor comparison, so this is a local independent false inequality, not a core false endorsement.
