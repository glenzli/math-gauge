  • 充分性（  ⟸  \impliedby）： 假设 H~∗(LK;Z)=0\tilde{H}_*(L_K; \mathbb{Z}) = 0：

    1. H~0(LK)=0\tilde{H}_0(L_K) = 0 保证了 ∣LK∣|L_K| 非空且路径连通。
    2. 根据 Seifert-van Kampen 定理，悬挂 Σ∣LK∣\Sigma |L_K| 是两个可缩锥沿路径连通空间 ∣LK∣|L_K| 的粘合，因此 π1(Σ∣LK∣)=0\pi_1(\Sigma |L_K|) = 0，即 Σ∣LK∣\Sigma |L_K| 单连通。
    3. 再次由悬挂同构，H~m(Σ∣LK∣;Z)≅H~m−1(∣LK∣;Z)=0\tilde{H}_m(\Sigma |L_K|; \mathbb{Z}) \cong \tilde{H}_{m-1}(|L_K|; \mathbb{Z}) = 0 对所有 m≥1m \ge 1 成立。
    4. 对单连通 CW 复形 Σ∣LK∣\Sigma |L_K|，应用 Hurewicz 定理：其所有同伦群全为平凡群，即 πm(Σ∣LK∣)=0\pi_m(\Sigma |L_K|) = 0（∀m≥1\forall m \ge 1）。
    5. 根据 Whitehead 定理，所有同伦群平凡的 CW 复形必同伦等价于单点，即 Σ∣LK∣≃∗\Sigma |L_K| \simeq *。

    故 X≃Σ∣LK∣≃∗X \simeq \Sigma |L_K| \simeq *，充要性获证。

S5 不提供子复形 B

判定结论

不必。当不再提供 BB 及其同伦条件时，∣K∣|K| 不一定同伦等价于非空有限复形的悬挂。

1. 满足全部前提的反例

取 K0K_0 为任一非空可缩有限单纯复形（例如单个单形 Δn\Delta^n 或单点 Δ0\Delta^0）。 令 K=K0⊔{v}K = K_0 \sqcup \{v\}，即在 K0K_0 外添加一个不与 K0K_0 中任何单形相连的孤立顶点 vv。

  • 验证前提： KK 是有限单纯复形，vv 是其顶点。 ∣K∣∖{v}=∣K0∣|K| \setminus \{v\} = |K_0|，按设定是非空可缩空间。满足前提。
  • 同伦型计算： ∣K∣=∣K0∣⊔{v}≃∗⊔∗≅S0.|K| = |K_0| \sqcup \{v\} \simeq * \sqcup * \cong S^0.
  • 为何不能表示为非空有限复形的悬挂： 对于任意非空拓扑空间 YY，其非约化悬挂 ΣY\Sigma Y 中，任意点 [y,t][y, t] 均有道路连通至锥顶 v1=[y,1]v_1 = [y, 1]，而任取 y0∈Yy_0 \in Y，路径 [y0,t][y_0, t]（t∈[−1,1]t \in [-1, 1]）连接了两端极点。因此只要 Y≠∅Y \ne \emptyset，ΣY\Sigma Y 必为路径连通空间（π0(ΣY)=0\pi_0(\Sigma Y) = 0）。 然而 ∣K∣≃S0|K| \simeq S^0 含有 2 个路径连通分支，绝不可能同伦等价于任何非空复形的悬挂。

2. 新增可能类型的完整分类

分类结论： 移去 BB 及其条件后，新增的可能同伦类型仅有唯一的一种： S0(即两点离散空间 ∗⊔∗).\mathbf{S^0} \quad (\text{即两点离散空间 } * \sqcup *).

分类证明：

设 KK 为有限复形，使得 ∣K∣∖{v}|K| \setminus \{v\} 非空可缩。 如前所述，∣K∣∖{v}|K| \setminus \{v\} 强形变收缩到有限子复形 ∣K∖v∣|K \setminus v|，故 ∣K∖v∣|K \setminus v| 非空可缩。 考查顶点 vv 的链环 LK=lkK(v)L_K = \mathrm{lk}_K(v)：

  • 情形 1：LK≠∅L_K \ne \emptyset： 此时 ∣K∣=∣K∖v∣∪LKC(LK)|K| = |K \setminus v| \cup_{L_K} C(L_K)。因 ∣K∖v∣≃∗|K \setminus v| \simeq *，由 S2 直接推出： ∣K∣≃Σ∣LK∣,|K| \simeq \Sigma |L_K|, 其中 LKL_K 为非空有限单纯复形。这属于原有的类型。
  • 情形 2：LK=∅L_K = \emptyset： LK=∅L_K = \emptyset 意味着 KK 中没有含 vv 的高维单形，即 vv 是 KK 的孤立顶点。 此时复形发生不交并分解：K=(K∖v)⊔{v}K = (K \setminus v) \sqcup \{v\}。 由于 ∣K∖v∣≃∗|K \setminus v| \simeq *，几何实现为： ∣K∣=∣K∖v∣⊔{v}≃∗⊔∗=S0.|K| = |K \setminus v| \sqcup \{v\} \simeq * \sqcup * = S^0. （注：若允许形式上取空集 ∅\emptyset 的非约化悬挂，Σ∅=S0\Sigma \emptyset = S^0，此即退化悬挂）。

因此，新增类型恰好且仅为 S0S^0。

S6 悬挂信息的逆向恢复

判定结论

否（由 Σ∣L1∣≃Σ∣L2∣\Sigma |L_1| \simeq \Sigma |L_2| 不能推出 ∣L1∣≃∣L2∣|L_1| \simeq |L_2|）。

完整反例与证明

1. 反例构造

  • 构造 L1L_1： 取庞加莱同调 3-球面 P3P^3（Poincaré homology 3-sphere）。P3P^3 是闭 3-流形，其基本群为 120 阶的双十二面体群 I∗=SL2(F5)≠0I^* = \mathrm{SL}_2(\mathbb{F}_5) \ne 0，其整同调群满足： H0(P3)=Z,H1(P3)=0,H2(P3)=0,H3(P3)=Z.H_0(P^3) = \mathbb{Z},\quad H_1(P^3) = 0,\quad H_2(P^3) = 0,\quad H_3(P^3) = \mathbb{Z}. 从 P3P^3 中挖去一个开 3-球 int(D3)\mathrm{int}(D^3)，得到带边紧致 3-流形： M=P3∖int(D3),∂M=S2.M = P^3 \setminus \mathrm{int}(D^3),\qquad \partial M = S^2. 由于 MM 是光滑/PL 流形，取其任一有限单纯三角剖分，记为 L1L_1。
  • 构造 L2L_2： 取单点复形 L2=Δ0L_2 = \Delta^0（单个 0-单形）。

L1L_1 与 L2L_2 显然均为非空有限单纯复形。

2. 性质验证

  1. 同调性质： 考虑将 D3D^3 沿 S2S^2 粘回 MM 得到 P3P^3 的 Mayer-Vietoris 序列： 0→H3(M)→H3(P3)→∂H2(S2)→H2(M)→H2(P3)=0.0 \to H_3(M) \to H_3(P^3) \xrightarrow{\partial} H_2(S^2) \to H_2(M) \to H_2(P^3) = 0. 由于连接同态 ∂:H3(P3)→H2(S2)\partial: H_3(P^3) \to H_2(S^2) 将基本类 [P3][P^3] 映为球面定向类 [S2][S^2]，是同构 Z→Z\mathbb{Z} \to \mathbb{Z}。 由此得： H3(M)=0,H2(M)=0.H_3(M) = 0,\qquad H_2(M) = 0. 又由 H1(S2)=0→H1(M)→H1(P3)=0H_1(S^2) = 0 \to H_1(M) \to H_1(P^3) = 0 知 H1(M)=0H_1(M) = 0。 显然 MM 连通，故 H~0(M)=0\tilde{H}_0(M) = 0。 因此 M=∣L1∣M = |L_1| 是整数无环空间： H~k(∣L1∣;Z)=0(∀k≥0).\tilde{H}_k(|L_1|; \mathbb{Z}) = 0 \quad (\forall k \ge 0).

  2. 基本群与底空间不等价性： 由于余维度为 3（∂D3=S2\partial D^3 = S^2 是单连通的），由 Seifert-van Kampen 定理，挖去开 3-球不改变基本群： π1(∣L1∣)≅π1(P3)≅I∗≠0.\pi_1(|L_1|) \cong \pi_1(P^3) \cong I^* \ne 0. 然而 ∣L2∣=∣Δ0∣={∗}|L_2| = |\Delta^0| = \{*\}，其基本群 π1(∣L2∣)=0\pi_1(|L_2|) = 0。 由于基本群是同伦不变量，两空间基本群不同构，故： ∣L1∣≄∣L2∣.|L_1| \not\simeq |L_2|.

  3. 悬挂同伦等价性：

    • 对于 L2L_2：Σ∣L2∣=Σ(∗)≅[−1,1]≃∗\Sigma |L_2| = \Sigma(*) \cong [-1, 1] \simeq * 为可缩空间。
    • 对于 L1L_1：
      • ∣L1∣|L_1| 是路径连通的有限复形，由 Seifert-van Kampen 定理，Σ∣L1∣\Sigma |L_1| 单连通，即 π1(Σ∣L1∣)=0\pi_1(\Sigma |L_1|) = 0。
      • 由悬挂同构定理，H~k(Σ∣L1∣;Z)≅H~k−1(∣L1∣;Z)=0\tilde{H}_k(\Sigma |L_1|; \mathbb{Z}) \cong \tilde{H}_{k-1}(|L_1|; \mathbb{Z}) = 0（∀k≥0\forall k \ge 0）。
      • 由 Hurewicz 定理，单连通且同调平凡的 CW 复形的所有同伦群全为零：πk(Σ∣L1∣)=0\pi_k(\Sigma |L_1|) = 0（∀k≥1\forall k \ge 1）。
      • 由 Whitehead 定理，Σ∣L1∣≃∗\Sigma |L_1| \simeq *。

    因此： Σ∣L1∣≃∗≃Σ∣L2∣.\Sigma |L_1| \simeq * \simeq \Sigma |L_2|.

综上，Σ∣L1∣≃Σ∣L2∣\Sigma |L_1| \simeq \Sigma |L_2| 成立，但 ∣L1∣≄∣L2∣|L_1| \not\simeq |L_2|。悬挂信息在逆向恢复时不可逆。
