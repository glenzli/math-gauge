  4. 对该无理方向 α∈J\alpha\in J 与 u0∈C0∞(T2)u_0\in C^\infty_0(\mathbb{T}^2)，计算得 Nαu0(y)=2πi(αq−p)e2πi(qy1−py2)=2πiq2ne2πi(qy1−py2),N_\alpha u_0(y) = 2\pi i(\alpha q - p)e^{2\pi i(q y_1 - p y_2)} = 2\pi i q\frac{\sqrt{2}}{n}e^{2\pi i(q y_1 - p y_2)}, 从而 C∥Nαu0∥Hs=2πCq2n⟨k0⟩s=2πCq2n(1+q2+p2)s/2<12<1=∥u0∥L2.C\|N_\alpha u_0\|_{H^s} = 2\pi C q\frac{\sqrt{2}}{n}\langle k_0\rangle^s = 2\pi C q\frac{\sqrt{2}}{n}(1+q^2+p^2)^{s/2} < \frac{1}{2} < 1 = \|u_0\|_{L^2}.

这违反了 ∥u0∥L2≤C∥Nαu0∥Hs\|u_0\|_{L^2}\le C\|N_\alpha u_0\|_{H^s}。由于 J,s,CJ,s,C 任意，满足题设的一致估计不存在。■\blacksquare

S6 一个具体方向的不可解数据

设 α=∑n=1∞10−n!\alpha = \sum_{n=1}^\infty 10^{-n!}。对每个整数 N≥1N\ge 1，记 qN:=10N!∈N,pN:=∑n=1N10N!−n!∈N.q_N := 10^{N!}\in\mathbb{N}, \qquad p_N := \sum_{n=1}^N 10^{N!-n!}\in\mathbb{N}.

1. 证明 α\alpha 无理

对任意整数 N≥1N\ge 1，将级数拆分为前 NN 项与余项： α−pNqN=∑n=N+1∞10−n!.\alpha - \frac{p_N}{q_N} = \sum_{n=N+1}^\infty 10^{-n!}. 因为当 n≥N+1n\ge N+1 时不同指标对应的阶乘 n!n! 严格递增且不小于 (N+1)!(N+1)!，故可用公比为 1/101/10 的几何级数控制余项： 0<α−pNqN≤∑j=(N+1)!∞10−j=10−(N+1)!1−110=109⋅10−(N+1)!.0 < \alpha - \frac{p_N}{q_N} \le \sum_{j=(N+1)!}^\infty 10^{-j} = \frac{10^{-(N+1)!}}{1-\frac{1}{10}} = \frac{10}{9}\cdot 10^{-(N+1)!}. 两边同乘 qN=10N!q_N=10^{N!}，利用 (N+1)!−N!=N⋅N!(N+1)!-N! = N\cdot N!，得关键小除数估计 0<αqN−pN≤109⋅10−N⋅N!(∀N≥1).(∗)0 < \alpha q_N - p_N \le \frac{10}{9}\cdot 10^{-N\cdot N!} \qquad (\forall N\ge 1). \tag{$\ast$}

假设 α∈Q\alpha\in\mathbb{Q}，写成 α=ab\alpha = \frac{a}{b}（a∈Z,b∈N,b≥1a\in\mathbb{Z},b\in\mathbb{N},b\ge 1）。则对任意 N≥1N\ge 1， αqN−pN=aqN−bpNb.\alpha q_N - p_N = \frac{a q_N - b p_N}{b}. 由 (∗)(\ast) 左端知 aqN−bpN>0a q_N - b p_N > 0；又 aqN−bpN∈Za q_N - b p_N\in\mathbb{Z}，故 aqN−bpN≥1a q_N - b p_N \ge 1，从而 αqN−pN≥1b\alpha q_N - p_N \ge \frac{1}{b} 对一切 N≥1N\ge 1 成立。但由 (∗)(\ast) 右端，当 N→∞N\to\infty 时 109⋅10−N⋅N!→0\frac{10}{9}\cdot 10^{-N\cdot N!}\to 0，取正整数 NN 使 10N⋅N!>109b10^{N\cdot N!} > \frac{10}{9}b 即得 1b≤αqN−pN<1b\frac{1}{b} \le \alpha q_N - p_N < \frac{1}{b}，矛盾！因此 α\alpha 是无理数。

2. 单一不可解光滑零均值数据 FF 的构造与证明

记整频率序列 k(N):=(qN,−pN)∈Z2k^{(N)} := (q_N,-p_N)\in\mathbb{Z}^2（N≥1N\ge 1），并定义同一个函数 F:T2→CF:\mathbb{T}^2\to\mathbb{C} 为 F(y):=∑N=1∞10−N⋅N!e2πi(qNy1−pNy2).F(y) := \sum_{N=1}^\infty 10^{-N\cdot N!} e^{2\pi i(q_N y_1 - p_N y_2)}.

第一步：证明 F∈C0∞(T2)F\in C^\infty_0(\mathbb{T}^2)

  • 光滑性：注意到 0<α=∑n=1∞10−n!<∑j=1∞10−j=19<10 < \alpha = \sum_{n=1}^\infty 10^{-n!} < \sum_{j=1}^\infty 10^{-j} = \frac{1}{9} < 1，故 0<pN<αqN<qN=10N!0 < p_N < \alpha q_N < q_N = 10^{N!}。对任意偏导阶数 a,b≥0a,b\ge 0（记 m=a+bm=a+b），考察形式逐项求导级数 ∑N=1∞10−N⋅N!(2πiqN)a(−2πipN)be2πi(qNy1−pNy2).\sum_{N=1}^\infty 10^{-N\cdot N!}(2\pi i q_N)^a(-2\pi i p_N)^b e^{2\pi i(q_N y_1 - p_N y_2)}. 其第 NN 项在 T2\mathbb{T}^2 上的一致绝对值上界满足 ∣10−N⋅N!(2πiqN)a(−2πipN)be2πi(qNy1−pNy2)∣≤(2π)mqNa+b10−N⋅N!=(2π)m10(m−N)N!.\left|10^{-N\cdot N!}(2\pi i q_N)^a(-2\pi i p_N)^b e^{2\pi i(q_N y_1 - p_N y_2)}\right| \le (2\pi)^m q_N^{a+b} 10^{-N\cdot N!} = (2\pi)^m 10^{(m-N)N!}. 当 N≥m+1N\ge m+1 时，(m−N)N!≤−N!≤−N(m-N)N!\le -N!\le -N，故尾和受几何级数 (2π)m∑N=m+1∞10−N<∞(2\pi)^m\sum_{N=m+1}^\infty 10^{-N}<\infty 控制。由 Weierstrass MM 判别法及一致收敛级数逐项求导定理，F∈C∞(T2)F\in C^\infty(\mathbb{T}^2)。
  • 零均值与 Fourier 系数：因级数一致收敛，可逐项积分。对每个 N≥1N\ge 1，qN=10N!≥10≠0q_N=10^{N!}\ge 10\neq 0，故 k(N)=(qN,−pN)≠(0,0)k^{(N)}=(q_N,-p_N)\neq (0,0)，从而 ∫T2F(y) dy=∑N=1∞10−N⋅N!∫T2e2πik(N)⋅y dy=0,\int_{\mathbb{T}^2}F(y)\,dy = \sum_{N=1}^\infty 10^{-N\cdot N!}\int_{\mathbb{T}^2}e^{2\pi i k^{(N)}\cdot y}\,dy = 0, 即 F∈C0∞(T2)F\in C^\infty_0(\mathbb{T}^2)。同时，因 q1<q2<⋯<qN<⋯q_1<q_2<\cdots<q_N<\cdots 严格递增，整频率 {k(N)}N=1∞\{k^{(N)}\}_{N=1}^\infty 两两互异，故由 {ek}k∈Z2\{e_k\}_{k\in\mathbb{Z}^2} 的正交归一性得 F^(k(N))=10−N⋅N!(∀N≥1).\widehat{F}(k^{(N)}) = 10^{-N\cdot N!} \qquad (\forall N\ge 1).
