故对有限 XX，一值不动记录能完整延拓当且仅当 p>0p>0；二值不动记录能完整延拓当且仅当它是某个 x∈XGx\in X^G 的点值记录；三值以上每条记录均唯一完整延拓。

超滤子扩张定理现在给出准确非空判准： R∞(X)G≠∅  ⟺  ∀F⊆G 有限,XF≠∅.(16) \boxed{ R_\infty(X)^G\ne\varnothing \iff \forall F\subseteq G\text{ 有限},\quad X^F\ne\varnothing. } \tag{16} 右边正保证这些集合构成真滤子底，因为 XF∩XE=XF∪EX^F\cap X^E=X^{F\cup E}；ZFC 下可扩张为超滤子。必要性由式 (13) 立即成立。等价地，每个有限生成子群都在 XX 上有固定点。取 F=∅F=\varnothing 已排除空底集。

点值固定记录的闭包为 η∞,X(XG)‾=XG^={U:XG∈U}≅Ult⁡(XG).(17) \boxed{ \overline{\eta_{\infty,X}(X^G)} =\widehat{X^G} =\{\mathcal U:X^G\in\mathcal U\} \cong\operatorname{Ult}(X^G). } \tag{17} 右边是包含这些点值记录的闭集。反过来，若 XG∈UX^G\in\mathcal U，则每个包含 U\mathcal U 的基本邻域 A^\widehat A 都满足 A∩XG≠∅A\cap X^G\ne\varnothing，故含有固定点的点值记录。这也证明了空集情形。

由此得到等式的准确判准： η∞,X(XG)‾=R∞(X)G  ⟺  ∃F⊆G 有限,XF=XG.(18) \boxed{ \overline{\eta_{\infty,X}(X^G)}=R_\infty(X)^G \iff \exists F\subseteq G\text{ 有限},\quad X^F=X^G. } \tag{18} 若存在这样的 FF，式 (13) 强制每个不变超滤子包含 XGX^G。若不存在，则每个 XF∖XGX^F\setminus X^G 都非空；集合族 {XF:F⊆G 有限}∪{X∖XG} \{X^F:F\subseteq G\text{ 有限}\}\cup\{X\setminus X^G\} 有有限交性质。扩张得到的不变超滤子不包含 XGX^G，从而不在式 (17) 的闭包中。

一个群和底集都可数的具体例子是 G=⨁n∈NZ/2,X=N×[2], G=\bigoplus_{n\in\mathbb N}\mathbb Z/2,\qquad X=\mathbb N\times[2], 作用定义为 g⋅(n,ε)=(n,ε+g(n)(mod2)).(20) g\cdot(n,\varepsilon)=(n,\varepsilon+g(n)\pmod2). \tag{20} 每个点都被对应坐标的生成元移动，故 XG=∅X^G=\varnothing。每个群元素只移动有限多个二点块，因此其固定点集余有限。

这里全部不动超滤子恰为 XX 上的非主超滤子。非主超滤子包含所有余有限集，因而由式 (12) 不变；反过来，不变超滤子包含每个二点块的补集，因而包含所有余有限集，不能是主超滤子。它们存在，因为 N\mathbb N 上的余有限真滤子可扩张为非主超滤子。

还可逐一参数化全部记录。每个超滤子恰选择一张片 N×{ε}\mathbb N\times\{\varepsilon\}，因此全部不动记录唯一对应于 (ε,V),ε∈[2],V∈N∗, (\varepsilon,\mathcal V),\qquad \varepsilon\in[2],\quad \mathcal V\in\mathbb N^*, 其中 N∗\mathbb N^* 是 N\mathbb N 上非主超滤子的 Stone 空间。对应记录为 rn(f)=唯一的 j∈[n]，使 {k:f(k,ε)=j}∈V(n≥1).(21) r_n(f)=\text{唯一的 }j\in[n]\text{，使 } \{k:f(k,\varepsilon)=j\}\in\mathcal V \qquad(n\ge1). \tag{21} r0r_0 唯一。由基本开闭集直接可见，这一参数化给出同胚 R∞(X)G≅[2]×N∗.(22) R_\infty(X)^G\cong[2]\times\mathbb N^*. \tag{22}
