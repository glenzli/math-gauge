MG-C003 v0.1.1 修订答卷：卷 1 第 3 章 Lean 形式化（第二版）

上一版确有一处缺陷：P20-01 的量词比原文弱。本版已修复，并另外补了三处正文对应。改后的完整项目编译无错误，全部 92 项仍为 complete。

修复的缺陷

  • P20-01（命题 3.16 后的反例）：原文的意思是，对任意有限正 τ，任取满足 0<a≤1、2a<τ 的 a，二点集 B={−a,a} 都构成反例。上一版 after316_counter 只证明了"存在这样的 a"。
    • 新增 after316_counter_forall，对所有这样的 a 证明 B⊆U、N(τ,B)=1、N(1/2,f(B))=2。
    • after316_counter（存在形式）和 after316_no_uniform_scale 改为由它推出。

新增的正文对应（原有结论都保留）

  • D06：原文的输入尺度只定义在非空子集上。新增同形结构 InputScaleNE、双向转换，以及 inputScale_correspondence，证明正文形式往返不变、两种形式在每个非空子集上取值一致。
  • P11-03（命题 3.8(ii)）：新增具体规范 d38 和 prop38_ii_concrete，写出原文的距离取值：d_i(a,b)=⊤，i≠j 时 d_j(a,b)=1。它对每个基点证明点态半径为 ⊤、统一半径为 ⊤，且 d_j(ϕa,ϕb)>0。prop38_ii 改为由它推出；新增 prop38_ii_not_implies，直接否定"统一半径为 ⊤ 就推出常值分量"。
  • P21-02（推论 3.17）：新增 cor317_cover_of_zero，从"整体输出零距"那一侧出发，同样得到输出覆盖数恰为 1。

其余声明与上一版逐字相同，只是新增内容插在其间。对齐表只改了 D06、D07、P11-03、P20-01、P21-02 五项。D07 补列了冻结声明 subfamily_pseudometric 和 subfamily_pseudometric_is_extended。

验证情况

  • lake env lean Main.lean 在 Lean 4.29.1 / mathlib 5e932f97… 下编译通过，没有错误和警告。
  • 重新编译 olean 后，对 OET3 下全部 377 个声明做了公理审计：只用到 propext、Classical.choice、Quot.sound。
  • 源码里没有 sorry、admit、axiom、native_decide、implemented_by。
  • 对齐表引用的 255 个声明名全部用 #check 确认存在。
  • 对齐表 92 个 ID 与清单顺序一致、无重复，依赖都在清单内。

仍有的不确定性

  • 有几处表示方式与原文写法不同，评审可能有不同看法：
    • 映射熵差用 Option EReal 表示，不良定时取 none。
    • 有限链用 ℕ → Operator、从 0 编号。
    • 零化矩阵写作 nullMatrix d ϕ U i j 对应 [N]_{ji}。
    • 阈值分类的定义本身不要求阈值有限且为正。引理 3.13 的结论用不到这个条件；其余用到阈值的命题都把它作为显式前提。
  • 部分定理保留了用不到的前提（如 hU : U ⊆ dom ϕ），只是为了与原文的前提一一对齐，不影响结论。
