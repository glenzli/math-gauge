我们有下面这个想法，想尝试证明。

设 a,b≥2 是整数，在 P={1,…,a}×{1,…,b} 上采用坐标偏序：

(i,j)≤(i′,j′) 当且仅当 i≤i′ 且 j≤j′。

反链是其中任意两个不同元素都不可比较的子集。对反链 A，令

I(A)={u∈P：存在 v∈A 使 u≤v}，

并令 R(A) 为 P\I(A) 的全部极小元素组成的反链。这个映射是 P 的全部反链集合上的一个置换。记 O 为它的任意一个轨道。

我们的想法是：每条轨道上的反链大小平均值都相同，具体为

(1/|O|)Σ_{A∈O}|A|=ab/(a+b)。

请尝试证明这个结论。

完整原答

结论：命题成立。 下面的证明只用 a,b≥1，用不到 a,b≥2。

思路： 把反链编码成长度 N=a+b、恰含 b 个 1 的 0/1 词。映射 R 对应于词的循环右移一位，而 |A| 等于词前 a 位之和。沿 N 步的完整移位周期求和，总和恰为 ab，再除以轨道长度即可。

记号： N=a+b，[n]={1,…,n}，[φ] 是 Iverson 括号（φ 真取 1，假取 0）。对反链 A，记 X(A)={i : ∃j,(i,j)∈A}，Y(A)={j : ∃i,(i,j)∈A}。

1. 反链的结构

引理 1. 设 A 是反链，k=|A|。

  • (a) A 可唯一写成 {(x_s,y_s) : 1≤s≤k}，其中 x_1<…<x_k，y_1>…>y_k。于是 X(A)={x_s}，Y(A)={y_s}，|X(A)|=|Y(A)|=k。
  • (b) A ↦ (X(A),Y(A)) 是从全体反链到 {(X,Y) : X⊆[a], Y⊆[b], |X|=|Y|} 的双射。

证明.

(a) A 中两个不同元素不能第一坐标相同，也不能第二坐标相同，否则它们可比较。把元素按第一坐标从小到大排成 (x_1,y_1),…,(x_k,y_k)。若 s<t，则 x_s<x_t。如果 y_s<y_t，就有 (x_s,y_s)≤(x_t,y_t)，矛盾，所以 y_s>y_t。

(b) 由 (a)，A 由 (X,Y) 决定：X 的第 s 小元素与 Y 的第 s 大元素配对。所以映射是单射。

反之，给定 |X|=|Y|=k，把 X 写成 x_1<…<x_k，把 Y 写成 y_1>…>y_k。则 {(x_s,y_s)} 是反链，因为 s<t 时 x_s<x_t 且 y_s>y_t，不可比。它的 X、Y 正是给定的集合，所以是满射。∎

编码. 对反链 A 定义 w=Φ(A)∈{0,1}^N：

  • w_p=[p∈X(A)]，1≤p≤a；
  • w_{a+q}=[q∉Y(A)]，1≤q≤b。

由引理 1 得到三条性质：

  • (E1) Φ 是单射。
  • (E2) w 中 1 的个数为 |X|+(b−|Y|)=b。
  • (E3) |A| = w_1+w_2+…+w_a。

2. R(A) 的显式描述

引理 2. 设 A={(x_s,y_s)}{s=1}^k 如引理 1(a)，约定 x_0=0，y{k+1}=0（k=0 时 A=∅）。令 c_s=(x_s+1, y_{s+1}+1)，0≤s≤k。则

R(A) = { c_s : 0≤s≤k, c_s∈P }。

证明. 记 U=P∖I(A)。(i,j)∈I(A) 当且仅当存在 t 使 i≤x_t 且 j≤y_t。所以

(2) (i,j)∈U ⇔ 对每个 t∈[1,k]，i>x_t 或 j>y_t。

(i) 若 c_s∈P，则 c_s∈U。 对 t≤s，有 x_t≤x_s<x_s+1。对 t≥s+1，有 y_t≤y_{s+1}<y_{s+1}+1。由 (2) 即得。

(ii) 若 c_s∈P，则 c_s 是 U 的极小元。 设 (i′,j′)∈U 且 i′≤x_s+1，j′≤y_{s+1}+1。要证 (i′,j′)=c_s。

第一坐标.

  • s=0 时，1≤i′≤x_0+1=1，所以 i′=1。
  • s≥1 时，假设 i′≤x_s。对 t=s 用 (2)，得 j′>y_s。又 y_s≥y_{s+1}+1（s=k 时 y_k≥1=y_{k+1}+1），所以 j′≥y_{s+1}+2，与 j′≤y_{s+1}+1 矛盾。故 i′≥x_s+1，即 i′=x_s+1。

第二坐标.

  • s=k 时，1≤j′≤y_{k+1}+1=1，所以 j′=1。
  • s≤k−1 时，假设 j′≤y_{s+1}。对 t=s+1 用 (2)，得 i′>x_{s+1}。但 i′≤x_s+1≤x_{s+1}，矛盾。故 j′=y_{s+1}+1。

(iii) U 的每个极小元都是某个 c_s。 设 (i,j)∈U 极小。令 s=#{t∈[1,k] : x_t<i}。由 x 严格递增，x_t<i 当且仅当 t≤s。于是 i≥x_s+1（s=0 时显然）。

  • 若 s<k，则 x_{s+1}≥i。对 t=s+1 用 (2)，得 j>y_{s+1}，即 j≥y_{s+1}+1。
  • 若 s=k，则 j≥1=y_{k+1}+1。

所以 (i,j) 在两个坐标上都 ≥ c_s。又 c_s 的坐标满足 1≤x_s+1≤i≤a 和 1≤y_{s+1}+1≤j≤b，故 c_s∈P。由 (i)，c_s∈U。由 (i,j) 的极小性，(i,j)=c_s。

(ii) 与 (iii) 合起来就是引理 2。∎

3. R 对应循环移位

令 σ:{0,1}^N→{0,1}^N，定义为 (σw)_1=w_N，(σw)p=w{p−1}（2≤p≤N）。

引理 3. 对每个反链 A，Φ(R(A)) = σ(Φ(A))。

证明. 设 X=X(A)，Y=Y(A)，B=R(A)，w=Φ(A)，w′=Φ(B)。先判断哪些 c_s 落在 P 内。

  • 当 1≤s≤k−1 时，x_s+1≤x_{s+1}≤a，且 y_{s+1}+1≤y_s≤b，所以 c_s∈P。
  • 当 s=0 时，c_0=(1,y_1+1)（k=0 时 y_1 即 y_{k+1}=0），第一坐标 1≤a。所以 c_0∈P ⇔ y_1<b ⇔ b∉Y。k=0 时 Y=∅，条件自动成立。
  • 当 s=k 时，c_k=(x_k+1,1)，第二坐标 1≤b。所以 c_k∈P ⇔ x_k<a ⇔ a∉X。k=0 时同样自动成立。

代入引理 2：

  • X(B)={x_s+1 : 0≤s≤k, c_s∈P}。s=0 项是 1，当且仅当 b∉Y 时出现；其余项是 x_s+1（1≤s≤k），要求 x_s<a。
  • Y(B)={y_{s+1}+1 : 0≤s≤k, c_s∈P}。s=k 项是 1，当且仅当 a∉X 时出现；其余项是 y_t+1（1≤t≤k），要求 y_t<b。

整理为

X(B) = {p∈[2,a] : p−1∈X} ∪ ({1} 若 b∉Y)， Y(B) = {q∈[2,b] : q−1∈Y} ∪ ({1} 若 a∉X)。

据此逐位比较 w′ 与 w：

  • 2≤p≤a：w′p=[p∈X(B)]=[p−1∈X]=w{p−1}。
  • p=1：w′1=[b∉Y]=w{a+b}=w_N。
  • 2≤q≤b：w′{a+q}=[q∉Y(B)]=[q−1∉Y]=w{a+q−1}。
  • q=1：w′_{a+1}=[1∉Y(B)]=[a∈X]=w_a。

所以 w′=(w_N,w_1,…,w_{N−1})=σw。∎

推论. 由引理 3 得 Φ(R^t A)=σ^tΦ(A)。因为 σ^N=id 且 Φ 是单射，所以 R^N=id。这也再次说明 R 是置换，并且每个轨道长度整除 N。

4. 轨道平均值

对 w∈{0,1}^N，把下标按 N 周期延拓：w_{r+N}=w_r（r∈ℤ）。则 (σ^t w)p = w{p−t}。

取任意反链 A，w=Φ(A)。由 (E3)，

|R^t(A)| = Σ_{p=1}^{a} (σ^t w)p = Σ{p=1}^{a} w_{p−t}。

对 t=0,…,N−1 求和并交换求和次序。固定 p 时，p−t 恰好跑遍模 N 的所有剩余类各一次，所以 Σ_t w_{p−t} = w_1+…+w_N = b（由 (E2)）。因此

(★) Σ_{t=0}^{N−1} |R^t(A)| = Σ_{p=1}^{a} b = ab。

现在设 O 是 A 所在的轨道，d=|O|。d 是满足 R^d(A)=A 的最小正整数，且由推论 d∣N。序列 |R^t(A)| 以 d 为周期，t↦R^t(A)（0≤t<d）是 {0,…,d−1} 到 O 的双射。所以

Σ_{t=0}^{N−1} |R^t(A)| = (N/d) Σ_{B∈O} |B|。

与 (★) 比较，Σ_{B∈O}|B| = d·ab/N，即

(1/|O|) Σ_{A∈O} |A| = ab/(a+b)。 ∎

核对

小例子 a=b=2. 此时 N=4。

  • 轨道 ∅ → {(1,1)} → {(1,2),(2,1)} → {(2,2)} → ∅，大小依次为 0,1,2,1，平均为 1=4/4。
  • 轨道 {(1,2)} → {(2,1)} → {(1,2)}，平均为 1。

程序核对. 对 1≤a,b≤6 的全部反链（a·b≤16 时另用暴力枚举 P 的全部子集交叉验证），我用程序核对了：

  • 反链数为 C(a+b,a)；
  • Φ∘R=σ∘Φ；
  • 引理 2 的显式公式及 X(B)、Y(B) 的公式；
  • 每条轨道长度整除 a+b，且平均值恰为 ab/(a+b)。

全部通过，无反例。
