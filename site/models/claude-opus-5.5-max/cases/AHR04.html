5. 无害差异（均为泛化或表述问题）

  • 核心定理更强。 去掉的附加条件只覆盖平凡的边界情形：j∉Iresj\notin I_{\rm res} 时左侧为空；τ=⊤\tau=\top 时右侧等于 UU；J=∅J=\emptyset 时两侧都等于 UU。
  • _text 包装中的附加假设只是标注。 它们以 have _ := … 形式出现，不参与证明。这不算错误，但它们在数学上是多余的。
  • 采样结构的约束未被使用。 正文要求 SS 有限、Sj⊆S∩U∩domϕ♮S_j\subseteq S\cap U\cap\mathrm{dom}\phi^\natural 并固定 δo\delta_o；Lean 对任意 sample、delta_o 都成立。推论只用到 Sq,j=Sj∩UqS_{q,j}=S_j\cap U_q，而 U⊆V∗⊆domϕ♮U\subseteq V^*\subseteq\mathrm{dom}\phi^\natural 已由 IsLipMatrix 推出。
  • ENNReal 约定。 阈值与矩阵元允许取 ⊤\top，约定 0⋅⊤=00\cdot\top=0。由于并的指标保证 Sq,j≠∅S_{q,j}\neq\emptyset，空下确界不会出现在左侧。
  • 网络类型一致。 网络用的是 FiniteOperatorNetwork，与正文一致；无环网络经 to_finite 后保持 U 和外延算子，同样被覆盖。
  • 证书存在性的预设一致。 Lq 是函数，对应正文"每条路径取定 Lq\mathbf L_q"的预设。若某条路径的受限 Lip 族为空（伪度量不分离时可能发生），正文的 Uq,jU_{q,j} 无定义，Lean 也给不出 hLq。这时可以改用逐路径定理 proxy_path_component_guarantee_error_bound，对有证书的路径取并。

6. 非空性与锐度（具体模型，已编译）

模型设定：

  • X=Option BoolX=\mathrm{Option\,Bool}，⊥=none\bot=\mathrm{none}，I=UnitI=\mathrm{Unit}。
  • 距离：d(x,y)=0d(x,y)=0（x=yx=y）；⊤\top（x≠yx\neq y 且其中之一为 none）；其余为 11。
  • ϕ=id\phi=\mathrm{id}，ϕ♮(some b)=some true\phi^\natural(\mathrm{some}\,b)=\mathrm{some\,true}。
  • N\mathcal N 取附件中的单节点网络，于是 U={some true,some false}U=\{\mathrm{some\,true},\mathrm{some\,false}\}，只有一条路径 q0q_0。
  • S={some true}S=\{\mathrm{some\,true}\}，δo=0\delta_o=0，V∗=UV^*=U，L∗=0\mathbf L^*=0，Lq0=1\mathbf L_{q_0}=1。

计算得 ε^q0=0\hat\varepsilon_{q_0}=0，D(some false;Sq0)=1D(\mathrm{some\,false};S_{q_0})=1，所以 some false∈Uq0(1)\mathrm{some\,false}\in U_{q_0}(1)。推论给出误差 ≤1\le1，而真实误差恰为 11。

由此可见：

  • 包装定理的全部假设（包括正文附加条件）可以同时满足，左侧非空，结论不是空真；
  • 该界在这一点可以取到。

若改用同样合法的 Lq0=2\mathbf L_{q_0}=2，该点不再属于 Uq0(1)U_{q_0}(1)，但真实误差仍 ≤1\le1。这说明包含关系一般只是单向的，正文也只断言了包含。另外用 I=BoolI=\mathrm{Bool}、两个分量各取不同样本，验证了联合分支。

-- open: ch_01_foundations, ch_05_operator_networks, ch_12_…, ch_14_empirical_network_fitting
theorem path_evaluable_eq (N : FiniteOperatorNetwork X bot V) (sample : I → Set X)
    (q : N.ReachablePath) :
    path_evaluable_components N sample q =
      {j | j ∈ evaluable_components sample ∧ (path_component_sample N sample q j).Nonempty} := by
  ext j
  exact ⟨fun h => ⟨path_evaluable_subset_evaluable_components N sample q h, h⟩, fun h => h.2⟩

theorem joint_eq_iInter (d : I → X → X → ENNReal) (A : I → I → ENNReal)
    (N : FiniteOperatorNetwork X bot V) (sample : I → Set X) (q : N.ReachablePath)
    (J : Set I) (hJ : J.Nonempty) (eps tau : I → ENNReal) :
    path_joint_empirical_guarantee_domain d A N sample q J eps tau =
      ⋂ j ∈ J, path_component_empirical_guarantee_domain d A N sample q j (eps j) (tau j) := by
  ext x; simp only [Set.mem_iInter]
  constructor
  · rintro ⟨hxU, hx⟩ j hj; exact ⟨hxU, hx j hj⟩
  · intro hx; rcases hJ with ⟨j₀, hj₀⟩; exact ⟨(hx j₀ hj₀).1, fun j hj => (hx j hj).2⟩

theorem hpathV_iff (N : FiniteOperatorNetwork X bot V) (Vstar : Set X) :
    (∀ q : N.ReachablePath, N.path_domain q.nodes ⊆ Vstar) ↔ N.U ⊆ Vstar := by
  constructor
  · intro h x hx
    rw [← N.reachable_path_domains_cover] at hx
    rcases Set.mem_iUnion.mp hx with ⟨q, hq⟩; exact h q hq
  · intro h q x hx; exact h (N.path_domain_subset_source hx)

theorem U_sub_dom (N : FiniteOperatorNetwork X bot V) (proxy : Operator X bot)
    (hrep : N.represents proxy) : N.U ⊆ dom proxy := by
  intro x hx
  have h1 : x ∈ dom N.extensional_operator := by rw [N.dom_extensional_operator_eq]; exact hx
  change proxy.func x ≠ bot; rw [← hrep x hx]; exact h1

3. 证明链（源码已证明）

正文的证明是：xx 属于某个 Uq,j(τj)U_{q,j}(\tau_j)，于是由 h-4b5219aa3a3bbdad 得到该分量的误差界；联合形式对每个 j∈Jj\in J 应用同一结论。

Lean 的证明逐步对应：

  1. 从左侧取出 qq、j∈Ires(q)j\in I_{\rm res}(q) 以及 xx 的成员关系。
  2. 由 path_domain_subset_source 得 x∈Ux\in U。
  3. 由 proxy_path_component_guarantee_error_bound（h-4b5219aa3a3bbdad，path_guarantee_domains.lean:152）得误差界。它由以下几步组成：
    • path_local_empirical_upper（:54）：在 UqU_q 上给出 dj(cqx,ϕ♮x)≤D+ε^q,jd_j(c_qx,\phi^\natural x)\le D+\hat\varepsilon_{q,j}。内部先用 empirical_residual_upper_certificate 得到残差证书，再用 empirical_target_perturbation_upper_point（h-f16da76e4331b725，structural_priors.lean:60）完成"三角不等式 + 两个 Lip 证书 + 同一锚点取下确界"。
    • 代入保证域条件，得到 ≤τj\le\tau_j。
    • path_chain_eq_represented_proxy_on_path（path_sampling.lean:220）把 cq(x)c_q(x) 换成 ϕ(x)\phi(x)。
  4. 联合形式经 path_joint_guarantee_error_bound（:210）对每个 j∈Jj\in J 走同一条链。

4. 需要自行补充的桥接

以下内容源码没有单独陈述，我已在临时文件中编译验证：

  • B1：Ires(q)={j∈Ires:Sq,j≠∅}I_{\rm res}(q)=\{j\in I_{\rm res}:S_{q,j}\neq\emptyset\} 等于 path_evaluable_components。理由：Sq,j⊆SjS_{q,j}\subseteq S_j，所以 Sq,j≠∅⇒Sj≠∅S_{q,j}\ne\emptyset\Rightarrow S_j\ne\emptyset；源码 path_evaluable_subset_evaluable_components（path_sampling.lean:103）给出了这一方向。

5. 无害差异（均为泛化或表述问题）

  • 核心定理更强。 去掉的附加条件只覆盖平凡的边界情形：j∉Iresj\notin I_{\rm res} 时左侧为空；τ=⊤\tau=\top 时右侧等于 UU；J=∅J=\emptyset 时两侧都等于 UU。
  • _text 包装中的附加假设只是标注。 它们以 have _ := … 形式出现，不参与证明。这不算错误，但它们在数学上是多余的。
  • 采样结构的约束未被使用。 正文要求 SS 有限、Sj⊆S∩U∩domϕ♮S_j\subseteq S\cap U\cap\mathrm{dom}\phi^\natural 并固定 δo\delta_o；Lean 对任意 sample、delta_o 都成立。推论只用到 Sq,j=Sj∩UqS_{q,j}=S_j\cap U_q，而 U⊆V∗⊆domϕ♮U\subseteq V^*\subseteq\mathrm{dom}\phi^\natural 已由 IsLipMatrix 推出。
  • ENNReal 约定。 阈值与矩阵元允许取 ⊤\top，约定 0⋅⊤=00\cdot\top=0。由于并的指标保证 Sq,j≠∅S_{q,j}\neq\emptyset，空下确界不会出现在左侧。
  • 网络类型一致。 网络用的是 FiniteOperatorNetwork，与正文一致；无环网络经 to_finite 后保持 U 和外延算子，同样被覆盖。
  • 证书存在性的预设一致。 Lq 是函数，对应正文"每条路径取定 Lq\mathbf L_q"的预设。若某条路径的受限 Lip 族为空（伪度量不分离时可能发生），正文的 Uq,jU_{q,j} 无定义，Lean 也给不出 hLq。这时可以改用逐路径定理 proxy_path_component_guarantee_error_bound，对有证书的路径取并。

6. 非空性与锐度（具体模型，已编译）

模型设定：

  • X=Option BoolX=\mathrm{Option\,Bool}，⊥=none\bot=\mathrm{none}，I=UnitI=\mathrm{Unit}。
  • 距离：d(x,y)=0d(x,y)=0（x=yx=y）；⊤\top（x≠yx\neq y 且其中之一为 none）；其余为 11。
  • ϕ=id\phi=\mathrm{id}，ϕ♮(some b)=some true\phi^\natural(\mathrm{some}\,b)=\mathrm{some\,true}。
  • N\mathcal N 取附件中的单节点网络，于是 U={some true,some false}U=\{\mathrm{some\,true},\mathrm{some\,false}\}，只有一条路径 q0q_0。
  • S={some true}S=\{\mathrm{some\,true}\}，δo=0\delta_o=0，V∗=UV^*=U，L∗=0\mathbf L^*=0，Lq0=1\mathbf L_{q_0}=1。

计算得 ε^q0=0\hat\varepsilon_{q_0}=0，D(some false;Sq0)=1D(\mathrm{some\,false};S_{q_0})=1，所以 some false∈Uq0(1)\mathrm{some\,false}\in U_{q_0}(1)。推论给出误差 ≤1\le1，而真实误差恰为 11。

由此可见：

  • 包装定理的全部假设（包括正文附加条件）可以同时满足，左侧非空，结论不是空真；
  • 该界在这一点可以取到。

若改用同样合法的 Lq0=2\mathbf L_{q_0}=2，该点不再属于 Uq0(1)U_{q_0}(1)，但真实误差仍 ≤1\le1。这说明包含关系一般只是单向的，正文也只断言了包含。另外用 I=BoolI=\mathrm{Bool}、两个分量各取不同样本，验证了联合分支。

-- open: ch_01_foundations, ch_05_operator_networks, ch_12_…, ch_14_empirical_network_fitting
theorem path_evaluable_eq (N : FiniteOperatorNetwork X bot V) (sample : I → Set X)
    (q : N.ReachablePath) :
    path_evaluable_components N sample q =
      {j | j ∈ evaluable_components sample ∧ (path_component_sample N sample q j).Nonempty} := by
  ext j
  exact ⟨fun h => ⟨path_evaluable_subset_evaluable_components N sample q h, h⟩, fun h => h.2⟩

theorem joint_eq_iInter (d : I → X → X → ENNReal) (A : I → I → ENNReal)
    (N : FiniteOperatorNetwork X bot V) (sample : I → Set X) (q : N.ReachablePath)
    (J : Set I) (hJ : J.Nonempty) (eps tau : I → ENNReal) :
    path_joint_empirical_guarantee_domain d A N sample q J eps tau =
      ⋂ j ∈ J, path_component_empirical_guarantee_domain d A N sample q j (eps j) (tau j) := by
  ext x; simp only [Set.mem_iInter]
  constructor
  · rintro ⟨hxU, hx⟩ j hj; exact ⟨hxU, hx j hj⟩
  · intro hx; rcases hJ with ⟨j₀, hj₀⟩; exact ⟨(hx j₀ hj₀).1, fun j hj => (hx j hj).2⟩

theorem hpathV_iff (N : FiniteOperatorNetwork X bot V) (Vstar : Set X) :
    (∀ q : N.ReachablePath, N.path_domain q.nodes ⊆ Vstar) ↔ N.U ⊆ Vstar := by
  constructor
  · intro h x hx
    rw [← N.reachable_path_domains_cover] at hx
    rcases Set.mem_iUnion.mp hx with ⟨q, hq⟩; exact h q hq
  · intro h q x hx; exact h (N.path_domain_subset_source hx)

theorem U_sub_dom (N : FiniteOperatorNetwork X bot V) (proxy : Operator X bot)
    (hrep : N.represents proxy) : N.U ⊆ dom proxy := by
  intro x hx
  have h1 : x ∈ dom N.extensional_operator := by rw [N.dom_extensional_operator_eq]; exact hx
  change proxy.func x ≠ bot; rw [← hrep x hx]; exact h1
