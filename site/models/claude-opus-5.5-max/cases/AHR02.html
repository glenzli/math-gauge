二、不足：路径链 Lip 证书的量词范围

2.1 差异

正文需要的前提是：

∀q∈P:j∈Ires(q) ⟹ Lq∈L(cq)∣Uq\forall q\in\mathcal P:\quad j\in I_{\mathrm{res}}(q)\ \Longrightarrow\ \mathbf L_q\in\mathscr L(c_q)\big|_{U_q}

联合形式中把条件换成 J⊆Ires(q)J\subseteq I_{\mathrm{res}}(q)。源码则要求对全部可达路径成立。源码证明里其实只对见证路径用到了 hLq q，所以这个全称量词只是陈述时写宽了，数学上并不需要。

2.2 为什么这是实质性的加强

  • 证书集合可能为空。 ENNReal 中 ⊤⋅0=0\top\cdot0=0。若 x,y∈Uqx,y\in U_q 对所有 ii 都有 di(x,y)=0d_i(x,y)=0，则对任何矩阵都有 ∑iLi→jdi(x,y)=0\sum_i L_{i\to j}d_i(x,y)=0。所以只要 cqc_q 把这样一对全分量零距的点送到 djd_j 距离为正的点对，就有 L(cq)∣Uq=∅\mathscr L(c_q)|_{U_q}=\emptyset。
  • 理论本身采用同一约定。 例如 h-28ceee0bc7dbdab0“无穷传播系数强制对应局部误差归零”只在 ⊤⋅0=0\top\cdot0=0 下才说得通。
  • 这种情况确实会出现。 扩展规范空间只要求伪度量，允许不分离；gauge_space.lean 中专门定义了 IsNonSeparating。

2.4 缺口的确切范围

  • 何时源码版够用。 若每条不在并集指标中的路径链都在其路径域上保持全分量零距关系（规范族分离时自动成立），则全 ⊤\top 矩阵就是它的 Lip 证书（附录 B top_matrix_is_lip）。此时对无关路径填 ⊤\top：令 Lq q := if j ∈ I_res(q) then L_q else ⊤，并集不变，源码定理即可使用。
  • 缺口出现的条件。 规范族不分离，且某条无采样路径的路径链不保持零距关系。

三、补齐方式

定理改写。 只改 hLq 的量词范围：

  • 分量形式：hLq : ∀ q, j ∈ path_evaluable_components N sample q → IsLipMatrix d (N.path_chain q.nodes) (N.path_domain q.nodes) (Lq q)
  • 联合形式：hLq : ∀ q, J ⊆ path_evaluable_components N sample q → …
  • _text 版：hLq : ∀ q, (j ∈ … ∨ J ⊆ …) → …

证明中把 hLq q 换成 hLq q hj（或 hLq q hJ）即可。原定理是补齐版的特例，传入 fun q _ => hLq q 就得到。

等价性。 Lq 仍是全函数；它在指标集外的取值不进入并集，所以补齐版与“只在指标路径上给出的依赖证书族”完全等价。

备选做法。 也可以不改原定理，直接由单路径引理推出正文推论，证明只有三行。

  • 理论本身采用同一约定。 例如 h-28ceee0bc7dbdab0“无穷传播系数强制对应局部误差归零”只在 ⊤⋅0=0\top\cdot0=0 下才说得通。

2.4 缺口的确切范围

  • 何时源码版够用。 若每条不在并集指标中的路径链都在其路径域上保持全分量零距关系（规范族分离时自动成立），则全 ⊤\top 矩阵就是它的 Lip 证书（附录 B top_matrix_is_lip）。此时对无关路径填 ⊤\top：令 Lq q := if j ∈ I_res(q) then L_q else ⊤，并集不变，源码定理即可使用。
  • 缺口出现的条件。 规范族不分离，且某条无采样路径的路径链不保持零距关系。

三、补齐方式

定理改写。 只改 hLq 的量词范围：

  • 分量形式：hLq : ∀ q, j ∈ path_evaluable_components N sample q → IsLipMatrix d (N.path_chain q.nodes) (N.path_domain q.nodes) (Lq q)
  • 联合形式：hLq : ∀ q, J ⊆ path_evaluable_components N sample q → …
  • _text 版：hLq : ∀ q, (j ∈ … ∨ J ⊆ …) → …

证明中把 hLq q 换成 hLq q hj（或 hLq q hJ）即可。原定理是补齐版的特例，传入 fun q _ => hLq q 就得到。

等价性。 Lq 仍是全函数；它在指标集外的取值不进入并集，所以补齐版与“只在指标路径上给出的依赖证书族”完全等价。

备选做法。 也可以不改原定理，直接由单路径引理推出正文推论，证明只有三行。
