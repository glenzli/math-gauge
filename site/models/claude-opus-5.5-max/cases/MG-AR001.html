S2 正确。

  • p 良定：取 i,j 的上界 k，得 p_i(x_i)=p_k(x_k)=p_j(x_j)。答卷未声称 p 满射，这是对的。

  • 自然性：p′v=up 给出 p′*v*=u_p_，取逆即得；并有 Φ′v=(∏v_j)Φ。

S3 正确。 ker p_n=(t)/(tⁿ⁺¹) 为 nil，共同设定成立。L≅k[[t]]，tᵐ 在第 m 层非零，故 t 不幂零。这与 S2 一致：D_J(k[[t]]) 与 D_J(k) 都等同于“在 J 中选一点”，J=∅ 时都空。

二、S6 第二问的问题

问题 1（实质错误）：“各层幂等提升唯一 ⟹ 极限幂等提升存在且唯一｜已证明｜S2”

答卷把 (B) 存在与 (C) 唯一列为两个概念，因此前件只有 C。这样读，该蕴含为假。

反例：任取非空有向 I，令 R_i=ℤ，ρ_ij=id，S=ℤ/6，p_i 为约化。ℤ 只有幂等元 0、1，它们在 ℤ/6 中的像不同，故各层提升至多一个。但 3∈ℤ/6 幂等（9≡3），在 L=ℤ 中没有幂等提升。

S2 实际证明的是：各层存在且唯一 ⟹ 极限存在且唯一，其中层上存在性来自 S1。“拼接”必须先有各层的 ẽ_{j,i}。答卷在 S3 中写过“存在且仅存在唯一”，与此行不一致。

影响：第二问正是要区分这些条件，此处“已证明”的归类错误。S2 的证明本身不受影响。修正方法是在前件加上“存在且”。

问题 2（方向混淆）：“极限核逐元素幂零 ⟹ 极限幂等提升唯一｜不必要”

“不必要”不是这个箭头的真值。S3 说明的是逆向不成立：C 成立而 D 不成立。所写箭头本身的情况是：

  • L 交换时为真：两提升之差在 ker p 中幂零，S1 唯一性一段逐字适用，且不需要 p 满射。
  • 不要求交换时为假：把 S6 的 q 作成常值塔，ker p 平方为零，但 (1,0) 有多个提升。

影响：一条可证的蕴含没有得到判定，读者还可能误读为不成立。

问题 3（条件遗漏）：“各层过渡满射 + 各层元素提升 ⟹ 极限元素提升｜已证明｜S4”

S4 只证明了可数塔（或有可数共尾链的情形），证明依赖沿 ℕ 递归。去掉这一条件后命题为假，即使再要求环交换、核平方为零。反例如下：

  1. 取 I=ω₁，S=ℚ[x]。递归取有限到一函数 e_α:α→ℕ，使 α<β 时 e_β|α 与 e_α 只差有限点：e_{α+1}=e_α∪{(α,0)}；极限 α 取 0=α₀<α₁<…→α，在 [α_n,α_{n+1}) 上令 e_α=max(e_{α_{n+1}},n)。
  2. 令 G_α 为 α 上取值于 ℚ 的有限支撑函数，R_α=S⋉G_α，乘法同 S5，p_α(a,g)=a。
  3. 令 c_{αβ}=e_β|α−e_α∈G_α，ρ_{αβ}(a,g)=(a, g|α+a′(0)c_{αβ})。由 c_{βγ}|α+c_{αβ}=c_{αγ} 得逆系，乘性计算同 S5。ρ_{αβ} 满射：取 h−a′(0)c_{αβ} 的零延拓。
  4. 若 x 有原像 (x,g_α)，则 g_α+e_α 粘成 F:ω₁→ℚ，且 F|α−e_α 有限支撑。ℚ 可数，故 F 有不可数纤维，于是存在 α 使该纤维与 α 的交无限，e_α 在无限集上取常值，与有限到一矛盾。

影响：S4 本身不受影响，但总结表必须写明“可数塔”。

问题 4（覆盖不全）

表中缺少以下所要求的关系：

  • 反方向 A ⟹̸ B、A ⟹̸ C。表中只有 “B∧C ⟹̸ A”，也没有指出 S4 对幂等元没有任何推论。
  • D ⟹̸ A。S5 的例子 ker p=0，答卷未注意到。
  • 共同设定下 A 与 D 相互独立（见第三节）。

  1. 取 I=ω₁，S=ℚ[x]。递归取有限到一函数 e_α:α→ℕ，使 α<β 时 e_β|α 与 e_α 只差有限点：e_{α+1}=e_α∪{(α,0)}；极限 α 取 0=α₀<α₁<…→α，在 [α_n,α_{n+1}) 上令 e_α=max(e_{α_{n+1}},n)。
  2. 令 G_α 为 α 上取值于 ℚ 的有限支撑函数，R_α=S⋉G_α，乘法同 S5，p_α(a,g)=a。
  3. 令 c_{αβ}=e_β|α−e_α∈G_α，ρ_{αβ}(a,g)=(a, g|α+a′(0)c_{αβ})。由 c_{βγ}|α+c_{αβ}=c_{αγ} 得逆系，乘性计算同 S5。ρ_{αβ} 满射：取 h−a′(0)c_{αβ} 的零延拓。
  4. 若 x 有原像 (x,g_α)，则 g_α+e_α 粘成 F:ω₁→ℚ，且 F|α−e_α 有限支撑。ℚ 可数，故 F 有不可数纤维，于是存在 α 使该纤维与 α 的交无限，e_α 在无限集上取常值，与有限到一矛盾。

影响：S4 本身不受影响，但总结表必须写明“可数塔”。

问题 4（覆盖不全）

表中缺少以下所要求的关系：

  • 反方向 A ⟹̸ B、A ⟹̸ C。表中只有 “B∧C ⟹̸ A”，也没有指出 S4 对幂等元没有任何推论。
  • D ⟹̸ A。S5 的例子 ker p=0，答卷未注意到。
  • 共同设定下 A 与 D 相互独立（见第三节）。

三、修正后的整理

命题 状态 依据
R 交换、ker q nil、q 满 ⟹ 单层幂等提升存在且唯一 已证 S1（唯一性不用满射）
各层存在且唯一 ⟹ 极限 B∧C 已证 S2
各层 C ⟹ 极限 C 成立 投影到各层
可数塔、过渡满、p₁ 满 ⟹ A 已证 S4
L 交换且 D ⟹ C 成立 S1 唯一性段
L 交换且 A∧D ⟹ B 成立 S1 构造用于 p
各层 C ⟹ 极限 B 假 常值系统 ℤ→ℤ/6
B∧C∧D ⟹ A 假 S5
各层 nil ⟹ D；A∧B∧C ⟹ D 假 S3
A ⟹ B 假 常值塔 ℤ→ℤ/6（满足 S4 条件）
A∧D ⟹ C（不要求交换） 假 S6 的常值塔
过渡满且 p_i 满 ⟹ A（不可数 I） 假 问题 3 的 ω₁ 例

共同设定下 B、C 恒成立，而 A、D 的四种真值组合都出现：

例子 A D
常值系统 k→k 真 真
S3 真 假
S5 假 真
S3 与 S5 的积（S=k×k[x]） 假 假

因此在共同设定下，A、D 之间没有任何蕴含，由 B、C 也推不出 A 或 D。这也说明 S1 不能直接用于 p:L→S（p 可能不满，ker p 可能非 nil），S2 必须逐层论证。

四、不影响结论的小省略

  • S2 第 4 部分未写 v 落入 L′：ρ′_ij(u_jx_j)=u_iρ_ij(x_j)=u_ix_i。
  • S4 不在 S2 的设定内，应单独说明 p(x):=p_n(x_n) 与 n 无关（由 p_nρ_n=p_{n+1}）。
  • S5 只给相邻过渡，应说明 ρ_ij 取复合，p_iρ_ij=p_j 由归纳得到；结合律只是断言，但直接展开成立。
  • S3 中“S2 的证明仅依赖各层 nil”说得过强，还用到了 R_i 交换（S6 的反例说明不可省）和 p_i 满射。
  • S6 表中“一般的多项式元素无法提升”不够精确：可提升的恰为 a′(0)=0 的 a。lim¹ 的说法正确，但只是未证明的旁注。
  • S6 中“若域 k 至少含两个元素”是空条件。
