复核结论

上一版的定义、陈述和证明都没有发现数学错误。缺口在"表示对应须给出证明"这一要求上：有几处表示只有文字说明，没有对应的定理。本轮只做增量修补。与上一版逐行 diff，只有插入，删除 0 行，原有声明一个都没有改动或删除。

新增的定理

  1. CH03-P02-02（有限复合链）： 上一版用 ℕ → Operator 的前 n 项表示有限族，只有文字说明，没有证明。本轮新增：
    • chainComp_eq_prod、chainComp_eq_OperatorChain：证明 chainComp 就是按复合顺序取的幺半群乘积，并与冻结的 OperatorChain 一致。
    • finSeq、finSeq_of_lt、chainComp_finSeq：把有限族 φ : Fin n → Operator 延拓为序列，证明其复合恰为 φ_n ∘ ⋯ ∘ φ_1。
    • prop32_ii_fin：直接对 Fin n 有限族陈述 (ii)。
  2. CH03-P09-02/03（纤维包含链）： 新增 fiber_chain_fin、fiber_chain_fin_strict，直接对 Fin (m+1) 族 φ_0,…,φ_m 陈述。
  3. CH03-D03： 新增 fiberGE_iff_Fib_subset，证明正文定义后那句话："φA 的零测距纤维分划细于或等于 φB 的分划"。
  4. CH03-D02： 新增 Fib_eq_empty_of_pos：当目标与 φ(U) 中每一点都有正距离时，纤维为空（这是定义段里的说明）。
  5. CH03-P20-01： 新增 remark316_no_scale，把"不存在正有限输入尺度，使覆盖不等式对所有 B ⊆ U 同时成立"写成显式的否定命题。
  6. CH03-P21-01： 新增 cor317_type，对应推论 3.17 后关于 Type 两项的说明。
  7. CH03-P29-05： 新增 D3_ball：在 D={0,2} 中，半径 r∈(0,2] 的开球与 D 之交只含基点，即正零化半径来自两点间隙。
  8. alignment.json： 把上述声明加入对应条目，并更新 representation 字段。依赖仍从编译环境中的实际常量引用计算；本轮只有 D03 新增了对 D07 的依赖。
