本轮复核结论

上一轮交付需要整体重交，原因有两个：

  • 字节不一致： 上一轮答卷中的 Main.lean 与工作区里实际编译通过的文件并非逐字节一致。至少空行数量不同，例如文件头之后。所以上一轮"已编译"的结论只对工作区文件成立，不能直接推到答卷文本上。本轮提交的文件全文就是最后验证的那份文件。
  • 对齐缺陷： 逐条对照原文与义务清单，发现下列缺陷，均已修复。

修复的缺陷

  1. CH03-P20-01： 原文是"任取 0<a≤1、2a<τ"，即对所有这样的 a 成立。上一轮只对 a=min(1,τ/4) 证明了存在性。
    • 新增 remark316_forall，对所有满足条件的 a 全称证明 B={−a,a}⊆U、N(τ,B)=1、f(B)={0,1}、N(1/2,f(B))=2。
    • remark316（存在这样的 a）改由它推出。
  2. CH03-P13-01/02： 原文要的是可取到的最小值，上一轮只给了下确界形式。新增 prop310_pointwise_min 与 prop310_uniform_min，直接给出取到最小值的分量 j。
  3. CH03-P16-01： 新增 lemma313_exclusive，显式证明四种阈值组合两两互斥。
  4. 映射熵差的陈述（P22-01、P24-02、P25-02、P28-02、P30-02）：由 ∃ h, … 改为"EntropyDiffDomain 成立 ∧ ∀ h, …"，避免被读成更弱的命题。
  5. 构造合法性：
    • 习题 3.4 的四个输入域显式加上 D.Nonempty。
    • 换位反例加上 U ⊆ dom swap。
    • 七点反例加上 U ⊆ dom ϕ。
  6. 否定性全称命题（remark_reverse_fails、prop33_ii、prop38_ii）：量化范围限定为有限非空指标集 [Fintype I] [Nonempty I]，即原文设定，所得否定更强。
  7. 补齐表示对应的证明：
    • subfamily_pseudometric_eq_max：d_J 等于取得到的 max。
    • nullRadius_of_admRadii_empty：sup ∅ = 0 的约定。
    • InputScaleFamily.ofNonempty、ofNonempty_eq、restrict_mono：尺度函数只定义在非空子集上，与本结构互相对应。
    • prop316_ii_empty：命题 3.16 中 B=∅ 的边界。
    • cor317_cover_of_radius：推论 3.17 从统一半径一侧直接得出覆盖数为 1。
  8. 对齐表依赖： 不再手写，改为从编译环境中追踪每个声明实际引用的常量后计算。上一轮手写的依赖有遗漏，例如 D04 依赖 D07、P07-03 依赖 D03/P07-01。共用的辅助引理归到 D01/D07，避免产生虚假依赖。

  • 全部 610 个 OETCh03.* 常量（含自动生成的辅助常量）只依赖 propext、Classical.choice、Quot.sound。
  • 源码中没有 sorry、admit、axiom、native_decide、implemented_by、extern、unsafe；只导入冻结的 formal_oet 模块。

复核结论

上一版的定义、陈述和证明都没有发现数学错误。缺口在"表示对应须给出证明"这一要求上：有几处表示只有文字说明，没有对应的定理。本轮只做增量修补。与上一版逐行 diff，只有插入，删除 0 行，原有声明一个都没有改动或删除。

新增的定理

  1. CH03-P02-02（有限复合链）： 上一版用 ℕ → Operator 的前 n 项表示有限族，只有文字说明，没有证明。本轮新增：
    • chainComp_eq_prod、chainComp_eq_OperatorChain：证明 chainComp 就是按复合顺序取的幺半群乘积，并与冻结的 OperatorChain 一致。
    • finSeq、finSeq_of_lt、chainComp_finSeq：把有限族 φ : Fin n → Operator 延拓为序列，证明其复合恰为 φ_n ∘ ⋯ ∘ φ_1。
    • prop32_ii_fin：直接对 Fin n 有限族陈述 (ii)。
  2. CH03-P09-02/03（纤维包含链）： 新增 fiber_chain_fin、fiber_chain_fin_strict，直接对 Fin (m+1) 族 φ_0,…,φ_m 陈述。
  3. CH03-D03： 新增 fiberGE_iff_Fib_subset，证明正文定义后那句话："φA 的零测距纤维分划细于或等于 φB 的分划"。
  4. CH03-D02： 新增 Fib_eq_empty_of_pos：当目标与 φ(U) 中每一点都有正距离时，纤维为空（这是定义段里的说明）。
  5. CH03-P20-01： 新增 remark316_no_scale，把"不存在正有限输入尺度，使覆盖不等式对所有 B ⊆ U 同时成立"写成显式的否定命题。
  6. CH03-P21-01： 新增 cor317_type，对应推论 3.17 后关于 Type 两项的说明。
  7. CH03-P29-05： 新增 D3_ball：在 D={0,2} 中，半径 r∈(0,2] 的开球与 D 之交只含基点，即正零化半径来自两点间隙。
  8. alignment.json： 把上述声明加入对应条目，并更新 representation 字段。依赖仍从编译环境中的实际常量引用计算；本轮只有 D03 新增了对 D07 的依赖。

  • 全部 625 个 OETCh03.* 常量（含自动生成的辅助常量）只依赖 propext、Classical.choice、Quot.sound。
  • 源码中没有 sorry、admit、axiom、native_decide、implemented_by、extern、unsafe。
  • alignment.json 的 92 个 ID 与清单顺序一致、无重复，全部为 complete；列出的 322 个声明条目（319 个不同名）都存在于编译出的模块中，所有依赖 ID 都合法。
  • 冻结背景文件、source/、obligations.json 均未改动。

仍有的不确定性（都是表示层面的选择，不影响证明）

  • ℝ⊔{⊥} 用 Option ℝ 表示，none 为 ⊥。
  • 具体精度写成 ENNReal.ofReal，另行证明它们等于 3/2 和 7/4。
  • 命题 3.6(iii) 的单分量情形用一般的标量伪度量 δ 表述，另附 Subsingleton I 的矩阵版本。
  • 部分定理去掉了不需要的前提，比原文更强。
