5. Derivation of the Dissipation Bound: f(Φt(z))≤e−2tf(z)f(\Phi_t(z)) \le e^{-2t}f(z)

Along any trajectory z(t)=Φt(z)z(t) = \Phi_t(z), the energy dissipation rate is: ddtf(z(t))=−∥∇f(z(t))∥2.\frac{d}{dt} f(z(t)) = -\|\nabla f(z(t))\|^2. Part 2: Proximal Certificate and Firm Nonexpansiveness

1. Statement of the Proximal Certificate

Let r:Rd→(−∞,+∞]r: \mathbb{R}^d \to (-\infty, +\infty] be a proper, lower-semicontinuous (l.s.c.), convex function. Under the convention: proxr(z)=arg⁡min⁡v∈Rd{r(v)+12∥v−z∥2},\text{prox}_r(z) = \arg\min_{v \in \mathbb{R}^d} \left\{ r(v) + \frac{1}{2}\|v - z\|^2 \right\}, let p=T(z)=proxr(z)p = T(z) = \text{prox}_r(z). Then for every u∈dom ru \in \text{dom } r: r(p)+12∥p−z∥2+12∥u−p∥2≤r(u)+12∥u−z∥2.r(p) + \frac{1}{2}\|p - z\|^2 + \frac{1}{2}\|u - p\|^2 \le r(u) + \frac{1}{2}\|u - z\|^2.

2. Proof of the Certificate

The objective function ψ(v)=r(v)+12∥v−z∥2\psi(v) = r(v) + \frac{1}{2}\|v - z\|^2 is 1-strongly convex and proper l.s.c., ensuring that the minimizer pp is unique.

By Fermat's rule for convex optimization, 0∈∂ψ(p)0 \in \partial \psi(p). Because the quadratic term 12∥⋅−z∥2\frac{1}{2}\|\cdot - z\|^2 is continuously differentiable with gradient p−zp - z, the subdifferential sum rule applies: 0∈∂r(p)+(p−z)  ⟺  z−p∈∂r(p).0 \in \partial r(p) + (p - z) \iff z - p \in \partial r(p). By definition of the Fenchel subdifferential of rr at pp, for all u∈dom ru \in \text{dom } r: r(u)≥r(p)+⟨z−p,u−p⟩.(3)r(u) \ge r(p) + \langle z - p, u - p \rangle. \qquad (3) We now rewrite the inner product ⟨z−p,u−p⟩\langle z - p, u - p \rangle using the Euclidean polarization identity: ∥u−z∥2=∥(u−p)+(p−z)∥2=∥u−p∥2+∥p−z∥2+2⟨u−p,p−z⟩.\|u - z\|^2 = \|(u - p) + (p - z)\|^2 = \|u - p\|^2 + \|p - z\|^2 + 2\langle u - p, p - z \rangle. Rearranging gives: ⟨z−p,u−p⟩=−⟨p−z,u−p⟩=12∥u−z∥2−12∥p−z∥2−12∥u−p∥2.\langle z - p, u - p \rangle = -\langle p - z, u - p \rangle = \frac{1}{2}\|u - z\|^2 - \frac{1}{2}\|p - z\|^2 - \frac{1}{2}\|u - p\|^2. Substituting this identity into (3): r(u)≥r(p)+12∥u−z∥2−12∥p−z∥2−12∥u−p∥2.r(u) \ge r(p) + \frac{1}{2}\|u - z\|^2 - \frac{1}{2}\|p - z\|^2 - \frac{1}{2}\|u - p\|^2. Rearranging terms yields the desired certificate: r(p)+12∥p−z∥2+12∥u−p∥2≤r(u)+12∥u−z∥2.■r(p) + \frac{1}{2}\|p - z\|^2 + \frac{1}{2}\|u - p\|^2 \le r(u) + \frac{1}{2}\|u - z\|^2. \qquad \blacksquare

3. Derivation of Firm Nonexpansiveness

Let z1,z2∈Rdz_1, z_2 \in \mathbb{R}^d, and define p1=T(z1)=proxr(z1)p_1 = T(z_1) = \text{prox}_r(z_1) and p2=T(z2)=proxr(z2)p_2 = T(z_2) = \text{prox}_r(z_2). Since p1,p2∈dom rp_1, p_2 \in \text{dom } r:

  1. Apply the certificate for (z1,p1)(z_1, p_1) with test point u=p2u = p_2: r(p1)+12∥p1−z1∥2+12∥p2−p1∥2≤r(p2)+12∥p2−z1∥2.(4)r(p_1) + \frac{1}{2}\|p_1 - z_1\|^2 + \frac{1}{2}\|p_2 - p_1\|^2 \le r(p_2) + \frac{1}{2}\|p_2 - z_1\|^2. \qquad (4)
  2. Apply the certificate for (z2,p2)(z_2, p_2) with test point u=p1u = p_1: r(p2)+12∥p2−z2∥2+12∥p1−p2∥2≤r(p1)+12∥p1−z2∥2.(5)r(p_2) + \frac{1}{2}\|p_2 - z_2\|^2 + \frac{1}{2}\|p_1 - p_2\|^2 \le r(p_1) + \frac{1}{2}\|p_1 - z_2\|^2. \qquad (5)

Adding inequalities (4) and (5), the potential values r(p1)r(p_1) and r(p2)r(p_2) cancel: ∥p1−p2∥2+12∥p1−z1∥2+12∥p2−z2∥2≤12∥p2−z1∥2+12∥p1−z2∥2.(6)\|p_1 - p_2\|^2 + \frac{1}{2}\|p_1 - z_1\|^2 + \frac{1}{2}\|p_2 - z_2\|^2 \le \frac{1}{2}\|p_2 - z_1\|^2 + \frac{1}{2}\|p_1 - z_2\|^2. \qquad (6) Expanding the cross-terms on the right-hand side: ∥p2−z1∥2=∥(p2−p1)+(p1−z1)∥2=∥p1−p2∥2+∥p1−z1∥2+2⟨p2−p1,p1−z1⟩,\|p_2 - z_1\|^2 = \|(p_2 - p_1) + (p_1 - z_1)\|^2 = \|p_1 - p_2\|^2 + \|p_1 - z_1\|^2 + 2\langle p_2 - p_1, p_1 - z_1 \rangle, ∥p1−z2∥2=∥(p1−p2)+(p2−z2)∥2=∥p1−p2∥2+∥p2−z2∥2+2⟨p1−p2,p2−z2⟩.\|p_1 - z_2\|^2 = \|(p_1 - p_2) + (p_2 - z_2)\|^2 = \|p_1 - p_2\|^2 + \|p_2 - z_2\|^2 + 2\langle p_1 - p_2, p_2 - z_2 \rangle. Summing these two expansions and dividing by 2: 12∥p2−z1∥2+12∥p1−z2∥2=∥p1−p2∥2+12∥p1−z1∥2+12∥p2−z2∥2+⟨p1−p2,(p2−z2)−(p1−z1)⟩.\frac{1}{2}\|p_2 - z_1\|^2 + \frac{1}{2}\|p_1 - z_2\|^2 = \|p_1 - p_2\|^2 + \frac{1}{2}\|p_1 - z_1\|^2 + \frac{1}{2}\|p_2 - z_2\|^2 + \langle p_1 - p_2, (p_2 - z_2) - (p_1 - z_1) \rangle. Substituting this expression into the right-hand side of (6) and canceling identical terms on both sides gives: 0≤⟨p1−p2,(p2−z2)−(p1−z1)⟩=⟨p1−p2,(z1−p1)−(z2−p2)⟩.0 \le \langle p_1 - p_2, (p_2 - z_2) - (p_1 - z_1) \rangle = \langle p_1 - p_2, (z_1 - p_1) - (z_2 - p_2) \rangle. Rewriting the inner product: ⟨p1−p2,(z1−z2)−(p1−p2)⟩≥0  ⟺  ∥p1−p2∥2≤⟨p1−p2,z1−z2⟩.\langle p_1 - p_2, (z_1 - z_2) - (p_1 - p_2) \rangle \ge 0 \iff \|p_1 - p_2\|^2 \le \langle p_1 - p_2, z_1 - z_2 \rangle. This is the characterization of firm nonexpansiveness.

Equivalently, it can be written as: ∥T(z1)−T(z2)∥2+∥(I−T)(z1)−(I−T)(z2)∥2≤∥z1−z2∥2,\|T(z_1) - T(z_2)\|^2 + \|(I - T)(z_1) - (I - T)(z_2)\|^2 \le \|z_1 - z_2\|^2, which immediately implies nonexpansiveness (Lipschitz continuity with constant 1): ∥T(z1)−T(z2)∥≤∥z1−z2∥.■\|T(z_1) - T(z_2)\| \le \|z_1 - z_2\|. \qquad \blacksquare

Part 3: Deployment Description (Methods Section Paragraph)

Continuous Denoising Dynamics and Multi-Block Stacking. Each autonomous denoising block implements the exact continuous-time flow operator Tτ=ΦτT_\tau = \Phi_\tau of the gradient system z˙=−∇f(z)\dot{z} = -\nabla f(z) over a transit duration τ>0\tau > 0, where the potential f(z)=12(x2+2y2)+14(x+y)4f(z) = \frac{1}{2}(x^2+2y^2) + \frac{1}{4}(x+y)^4 is uniformly 1-strongly convex. Consequently, each block provides a certified contractive denoising guarantee: for any states z,w∈R2z, w \in \mathbb{R}^2, ∥Tτ(z)−Tτ(w)∥≤e−τ∥z−w∥\|T_\tau(z) - T_\tau(w)\| \le e^{-\tau}\|z - w\|, while strictly dissipating the energy via f(Tτ(z))≤e−2τf(z)f(T_\tau(z)) \le e^{-2\tau}f(z). Deploying a depth-nn cascade Zn=Tτn(Z0)Z_n = T_\tau^n(Z_0) exploits the continuous semigroup property Φτn=Φnτ\Phi_\tau^n = \Phi_{n\tau}, meaning an nn-block stack corresponds exactly to a continuous evolution of total transit time t=nτt = n\tau. This guarantees exponential convergence toward the unique ground-state equilibrium z∗=(0,0)z^* = (0, 0) with ∥Zn∥≤e−nτ∥Z0∥\|Z_n\| \le e^{-n\tau}\|Z_0\| and f(Zn)≤e−2nτf(Z0)f(Z_n) \le e^{-2n\tau}f(Z_0), completely bypassing discretization errors or numerical instabilities.

Distinction from Proximal Discretization. It is mathematically essential to distinguish the flow transit time τ\tau from the weighting parameter in proximal regularization. In standard proximal formulations proxγf(z)=arg⁡min⁡u{γf(u)+12∥u−z∥2}\text{prox}_{\gamma f}(z) = \arg\min_u \{\gamma f(u) + \frac{1}{2}\|u - z\|^2\} (which corresponds to an implicit Euler step), γ\gamma acts as a static trade-off coefficient balancing energy minimization against Euclidean displacement, yielding only firm nonexpansiveness (Lip≤1\text{Lip} \le 1). In our architecture, the coefficient 12\frac{1}{2} is fixed by definition, and the block is not an implicit Euler step (Tτ≠proxτfT_\tau \ne \text{prox}_{\tau f}). Instead, τ\tau represents the continuous physical transit time along the trajectory curve z˙=−∇f(z)\dot{z} = -\nabla f(z), translating directly into an exponential contractivity modulus e−τ<1e^{-\tau} < 1 that compounds strictly multiplicatively across layers.
