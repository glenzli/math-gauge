一、结论

设 p≥3p \ge 3 是素数，r≥2r \ge 2 是整数，N=prN = p^r。取 0≤a1<a2<a3<N0 \le a_1 < a_2 < a_3 < N，且 a1,a2,a3(modp)a_1, a_2, a_3 \pmod p 两两不同。对于任意不全为零的复数 c1,c2,c3c_1, c_2, c_3，多项式 P(z)=c1za1+c2za2+c3za3P(z) = c_1 z^{a_1} + c_2 z^{a_2} + c_3 z^{a_3} 在全部 NN 次单位根中，满足 P(z)=0P(z) = 0 的不同根至多有两个。且该上界 22 是紧的（最优的）。

二、核心引理

证明： 因为 N=prN = p^r，而素数 p∤dp \nmid d，故 gcd⁡(d,p)=1\gcd(d, p) = 1，从而 gcd⁡(d,pr)=gcd⁡(d,N)=1\gcd(d, p^r) = \gcd(d, N) = 1。 在阶为 NN 的有限循环群 μN\mu_N 中，当指数 dd 与阶数 NN 互素时，幂映射 ϕd\phi_d 的核为： ker⁡(ϕd)={z∈μN:zd=1}={1}.\ker(\phi_d) = \{ z \in \mu_N : z^d = 1 \} = \{ 1 \}. 因此 ϕd\phi_d 是单同态；又因为 μN\mu_N 是有限集，单射必为双射（自同构）。 所以若 ξ∉μN\xi \notin \mu_N，无解；若 ξ∈μN\xi \in \mu_N，恰有 11 个解。总之至多有 11 个解。 ■\blacksquare

五、题设条件的必要性解析

  1. 为什么需要 p≥3p \ge 3？ 若 p=2p = 2，模 2 的剩余类只有 {0,1}\{0, 1\} 两个。根据抽屉原理，任意三个整数中必有两个模 2 同余，因此根本不存在模 pp 两两不同的三个数 a1,a2,a3a_1, a_2, a_3。p≥3p \ge 3 是保证题设非空的必要条件。

  2. 为什么需要 a1,a2,a3(modp)a_1, a_2, a_3 \pmod p 两两不同？ 如果允许其中有两个数模 pp 同余，结论将不成立： 例如取 p=3,r=2,N=9p = 3, r = 2, N = 9。 若取 a1=0,a2=3,a3=4a_1 = 0, a_2 = 3, a_3 = 4（此时 a1≡a2≡0(mod3)a_1 \equiv a_2 \equiv 0 \pmod 3），取 c3=0,c1=−1,c2=1c_3 = 0, c_1 = -1, c_2 = 1，则： P(z)=z3−1=0.P(z) = z^3 - 1 = 0. 由于 gcd⁡(3,9)=3\gcd(3, 9) = 3，方程 z3=1z^3 = 1 在 μ9\mu_9 中有 33 个根：{1,e2πi/3,e4πi/3}⊂μ9\{1, e^{2\pi i / 3}, e^{4\pi i / 3}\} \subset \mu_9，打破了“至多两个根”的结论。 因此，要求 ai(modp)a_i \pmod p 两两不同，本质上排除了任何两项指数差被 pp 整除的可能，确保了单射性的成立。
