一、总体判断

所给 Lean 实现没有完全准确、完整地覆盖附件数学正文中的“节点域加细”定义（#h-eddd1f2d0a9d3528）及该情形下的“网络加细保持外延等价”（#h-012f4ba72aeb3f20）。

附件源码实际上将这一数学范围拆分到了两个彼此独立、尚未桥接的模块中，二者在准确性和完整性上表现明显不同：

  1. 构造性实现（formal_oet/vol_01/ch_05_operator_networks/domain_refinement_construction.lean 与 network_presentation.lean）：

    • NodePartitionData →\to P.presentation →\to P.network := P.presentation.prune 这一套对象构造本身在数学上是准确的，忠实实现了节点域有限非空分划、受限子算子、入口分配、四类边域交集、补集终止域以及按 #h-ced8c7236326e104 删去不可达子节点与关联边，并已正确证明路径投影保持与外延算子相等（network_extensional_eq）。
    • 但其显式规格验证与结论封装不完整：除删冗余前的自环路由引理 self_loop_choice_iff 外，未显式证明构造结果 P.network 满足正文的入口片公式、四类边域交集公式、终止域公式及保留节点集合刻画，也未将其桥接到 NodeDomainRefinement 或封装为 LocalEquivalent、ExtensionalEquivalent、represents、evaluation_depth 等结论。

  2. 关系型定义与命题实现（formal_oet/vol_01/ch_05_operator_networks/network_refinement.lean）：

    • 存在实质性定义缺陷（欠约束 / 过宽）：NodeDomainRefinement 中的字段 choice_projection 仅对有效输出像 (N'.node_op v).func '' N'.node_actual_input_domain v 施加路由投影约束，对所有未被输入域 UU 到达的节点输出 N'.node_image v \ (N'.node_op v).func '' N'.node_actual_input_domain v 完全不加限制。这导致 NodeDomainRefinement 放行大量不符合正文节点域加细定义的伪加细网络（可在未到达输出上凭空伪造自环/环路、删除或重定向与被加细节点 β\beta 完全无关的边、破坏无环性及固定分划下加细结果在重命名意义下的唯一性）。
    • 虽然在该过宽的关系前提下，refinement_preserves_local_equivalence 与 refinement_preserves_representation 的证明在逻辑上有效，但作为正文“节点域加细”定义的形式化规格是不准确的；且 network_refinement.lean 与 domain_refinement_construction.lean 没有任何相互导入或等价桥接定理，同时未将节点域加细提升到对象空间 NetworkObject 层。

二、逐项对照审阅（正文要求 vs. Lean 实现）

以下按 source.md 中 #h-eddd1f2d0a9d3528（节点域加细）与 #h-012f4ba72aeb3f20（节点域加细情形下保持外延等价）的逐条要件核对。

1. 底网络对象、目标节点 β\beta 与非空输入域约定

  • 正文要求：设 N\mathcal N 为（有限）算子网络，选取被加细节点 β∈V\beta \in V；正文约定凡对网络输入域使用 ≡U\equiv_U 均默认 U≠∅U \neq \emptyset，空网络 ⊥net\bot_{\mathrm{net}} 无节点，不存在节点域加细。
  • Lean 实现与依据：
    • NodePartitionData (N : FiniteOperatorNetwork X bot V) (target : V) 与 NodeDomainRefinement N N'（含 target : V）均作用在一般有限算子网络 FiniteOperatorNetwork 上（允许有向闭路与自环，不限于无环 OperatorNetwork），与正文一致。
    • 由 N.node_reachable target : ∃ x : {x // x ∈ N.U}, target ∈ N.path_of x，只要存在 target : V，就自动蕴含 N.U.Nonempty，从而自然排除空网络并满足 U≠∅U \neq \emptyset 约定。
  • 评判：准确。

2. 节点定义域有限非空分划与子局域算子

  • 正文要求：将 Uβ=dom⁡(fβ)U_\beta = \operatorname{dom}(f_\beta) 替换为有限非空分划 Uβ=⨆a=1qUβ,aU_\beta = \bigsqcup_{a=1}^q U_{\beta,a}；对每个 aa 选取 fβ,a∈Xopf_{\beta,a} \in \mathcal X_{\mathrm{op}} 满足 dom⁡(fβ,a)=Uβ,a\operatorname{dom}(f_{\beta,a}) = U_{\beta,a} 且 fβ,a≡Uβ,afβf_{\beta,a} \equiv_{U_{\beta,a}} f_\beta；正文指出 fβ,af_{\beta,a} 恰好是 fβ∣Uβ,af_\beta|_{U_{\beta,a}}。
  • Lean 实现与依据：
    • domain_refinement_construction.lean 中 NodePartitionData 包含 count、count_pos : 0 < count、piece : Fin count → Set X、nonempty、disjoint、cover : (⋃ a, piece a) = N.node_dom target、local_op、local_domain、local_eq，并证明 local_op_eq_restrict : P.local_op a = restrict_operator (N.node_op target) (P.piece a)。
    • network_refinement.lean 中 NodeDomainRefinement 具有完全对应的字段（part_count、part_count_pos、piece、piece_nonempty、piece_disjoint、piece_cover、local_factor、local_domain、local_equiv）。
    • 注：0 < count 实际上可由 cover 与 N.node_dom_nonempty target 推出，显式保留作字段无害且与 q≥1q \ge 1 一致（二者均允许平凡分划 q=1q=1）。
  • 评判：准确且完整。

3. 节点替换与删去不可达子节点（@h-ced8c7236326e104）

  • 正文要求：用子节点 βa\beta_a 替换 β\beta，其余节点 γ≠β\gamma \neq \beta 及其局域算子不变；加细后若产生不被任何输入轨迹经过的子节点，按 #h-ced8c7236326e104 删除这些节点及其关联边，保留其余局域算子、转移域和入口片。
  • Lean 实现与依据：
    • 在 domain_refinement_construction.lean 中：删冗余前以 P.Label := {v : V // v ≠ target} ⊕ Fin P.count 为节点集，构造 P.presentation : FiniteNetworkPresentation X bot P.Label，再令 P.network := P.presentation.prune（调用 network_presentation.lean 中基于 Reached v := ∃ x : N.U, v ∈ N.path_of x 的裁剪构造）。在 P.network 中，所有原非目标节点 .inl γ 实际上均可被到达而保留，.inr a 被保留当且仅当满足 NodePieceReached N target P.piece a。但 domain_refinement_construction.lean 未显式证明这两条可达性刻画引理。
    • 在 network_refinement.lean 中：NodeDomainRefinement 通过 source : V' → ({β : V // β ≠ target} ⊕ Fin part_count)、source_injective、old_node_present、piece_node_present_iff_reached（使用 NodePieceReached）、old_node_op_compat 与 piece_node_op_compat，精确刻画了删去冗余节点后节点集与节点算子的同构（至多差重命名）。

  • 评判：节点集与算子替换的刻画准确，但构造侧缺少对 P.presentation.Reached 的显式刻画定理。

4. 入口输入片规则与空入口片省略

  • 正文要求：若 β\beta 为入口节点，则子节点入口输入片为 Uβin∩Uβ,aU_\beta^{\mathrm{in}} \cap U_{\beta,a}；其他节点入口输入片不变；空入口片省略。
  • Lean 实现与依据：
    • 编码约定：FiniteOperatorNetwork 以函数 entry : U → V 诱导 entry_domain β := {x | ∃ hx : x ∈ U, entry ⟨x, hx⟩ = β}，空 entry_domain 表示非入口节点（transition_graph_import.lean 与 network_identity.lean 已确认这一等价编码），与“空入口片省略”一致。
    • 在 domain_refinement_construction.lean 中：P.presentation.entry x := P.lift_label (N.entry x) x.val，删冗余后 P.network.entry 保持同一映射。在数学上对保留节点确有 P.network.entry_domain ⟨.inl γ, _⟩ = N.entry_domain γ 与 P.network.entry_domain ⟨.inr a, _⟩ = N.entry_domain target ∩ P.piece a（且被删除分块的该交集必为空），但源码未将这些入口片等式写成定理证明。
    • 在 network_refinement.lean 中：NodeDomainRefinement.entry_projection 要求 node_domain_projection target source (N'.entry x) = N.entry (transport_network_input same_input_domain x)。结合 N'.entry_mem、piece_disjoint、source_injective 与 local_domain，可以严格推出：

      • 若 source v = .inr a，则 N'.entry_domain v = N.entry_domain target ∩ piece a。 因此 entry_projection 作为入口条件在逻辑上是充分且必要（准确）的，但源码同样未显式证出上述入口片公式。
  • 评判：逻辑上准确，但显式入口片刻画定理缺失。

6. 命题 #h-012f4ba72aeb3f20（节点域加细保持外延等价）

  • 正文要求：若 N′\mathcal N' 由 N\mathcal N 经一次节点域加细（含删去冗余节点）得到，则 ϕN′≡UϕN\phi_{\mathcal N'} \equiv_U \phi_{\mathcal N}（因二者在 UU 外均取 ⊥\bot，等价于 ϕN′=ϕN\phi_{\mathcal N'} = \phi_{\mathcal N} 或 N′∼opN\mathcal N' \sim_{\mathrm{op}} \mathcal N）；证明同时给出了路径重着色对应、轨迹长度不变（r′=r≤ℓ(N)r' = r \le \ell(\mathcal N)）及新数据经删冗余后确为有限算子网络。
  • Lean 实现与依据：
    • 构造侧（domain_refinement_construction.lean）：已证 P.network 是合法 FiniteOperatorNetwork，并已证 network_path_labels、network_path_projection 与 network_extensional_eq : P.network.extensional_operator = N.extensional_operator。由于 P.network.U = N.U 按定义成立，外延局部等价 ϕN′≡UϕN\phi_{\mathcal N'} \equiv_U \phi_{\mathcal N}、ExtensionalEquivalent P.network N、represents 保持及 evaluation_depth 不变均为直接推论，但源码未显式封装这些结论。
    • 关系侧（network_refinement.lean）：已证 NodeDomainRefinement.node_eval_eq、terminal_projection、path_projection、eval_projected、NetworkRefinement.path_eval_eq、refinement_preserves_local_equivalence（LocalEquivalent N'.extensional_operator N.extensional_operator N.U）和 refinement_preserves_representation（N.represents φ → NetworkRefinement N N' → N'.represents φ）。
    • 存在的结构性缺口：

      2. 结论封装不完全统一：network_refinement.lean 导入了 effective_equivalence.lean（其中定义了 FiniteOperatorNetwork.ExtensionalEquivalent），但未显式给出 ExtensionalEquivalent N' N、N'.extensional_operator = N.extensional_operator 与 N'.evaluation_depth = N.evaluation_depth 的定理；此外，文件末尾的 IrreducibleRepresentative 定义在对象空间 NetworkObject X bot 的 RefinementRule 上，但节点域加细本身没有经 NonemptyOperatorNetwork.encode 提升至 NetworkObject 层。

三、核心缺陷的数学影响与可复核反例

NodeDomainRefinement.choice_projection 的欠约束虽然不影响 refinement_preserves_local_equivalence 的真值（因为外延求值只查询有效输出像上的路由），但它使得 NodeDomainRefinement 严重偏离正文定义，产生以下具体数学后果：

  1. 违反正文四类边域交集公式与“不与 β\beta 关联的边保持不变”的规定；
  2. 违反终止域补集公式；
  3. 破坏无环性保持：原网络是无环网络（甚至无边），按 NodeDomainRefinement 却可“加细”出含自环或有向闭路的循环网络；
  4. 破坏加细结果的唯一性（模节点重命名）：固定 N\mathcal N、目标节点 β\beta 与分划 {Uβ,a}\{U_{\beta,a}\} 后，正文唯一决定加细后的网络数据（PresentationData / NetworkObject 至多差编号），但 NodeDomainRefinement 允许无数个彼此非同构的 N' 均满足该关系。
