逐阶段核查

S1：正确

  • 唯一性： ε = ẽ₁(1−ẽ₂) = ẽ₁δ 是幂等元，且 ε^m = ẽ₁^m δ^m = 0，所以 ε = 0。对称地可得 ẽ₁ = ẽ₁ẽ₂ = ẽ₂。论证正确。这里只用到交换性和 δ 幂零，没有用到 q 满射。

  • 构造： E_n(X) 的整系数性质成立。两条关键事实：

    • E_n − X ∈ (X)∩(1−X) = (X(1−X))。两个理想互素，所以交等于乘积。
    • E_n(1−E_n) ∈ (X^n(1−X)^n)。它和 ((X²−X)^n) 只差符号 (−1)^n，是同一个理想。

    我用 sympy 对 n = 1,…,6 在 ℤ[X] 中做多项式除法，两条整除关系都成立。指数 n 可以随 x 变化，也没有假设 2 可逆，符合题目要求。

S2：正确

  • p 与指标无关： 用有向性取共同上界 k，再用 p_iρ_ik = p_k，论证完整。
  • J = ∅： 由 1 ∈ ker p_i 幂零推出 R_i = 0，进而 L = 0，讨论正确。
  • J ≠ ∅：
    • 单射：逐层用 S1 的唯一性。
    • 满射：先逐层取唯一提升，再用唯一性推出 ρ_ik(ẽ_{j,k}) = ẽ_{j,i}，所以拼成的元组相容。
    • 正交性和单位和：用“0 和 1 分别是 0 和 1_S 的唯一幂等提升”得到，正确。
  • Φ/Ψ 互逆： ẽ_k = (1−ẽ_j)ẽ_k 对 k ≠ j 成立，计算正确。J = ∅ 时 L = 0，公式同样适用。
  • 自然性： 由 p′*v* = u_p_ 和 p_, p′_ 都是双射，得到 v_p_⁻¹ = p′*⁻¹u*，推导正确。商同态构成的方块交换也正确。
  • 小省略： 没有写出 v 的像落在 L′ 中。只需一行：ρ′_ij(u_j(x_j)) = u_iρ_ij(x_j) = u_i(x_i)。

S3：正确

  • L ≅ k[[t]]，ker p = t·k[[t]]。t^m 在 R_m 中的分量非零，所以 t 不幂零，结论“否”正确。
  • “与 S2 一致”的说明也成立：S2 只用到各层核逐元素幂零，从未断言极限核幂零；而且 k[[t]] 与 k 都只有平凡幂等元。

S4：正确

  • 先选 x₁ ∈ p₁⁻¹(s)，再依次选 x_{n+1} ∈ ρ_n⁻¹(x_n)。由 p_{n+1}(x_{n+1}) = p_n(x_n) = s 归纳成立。DC 在 ZFC 内可用。
  • 证明确实没有用到交换性或 nil 核。实际上只需要 p₁ 满射和各 ρ_n 满射。
  • 小省略： 没有说明 p(x) := p₁(x₁) 与“任取层”的定义一致。这由 p_nρ_n = p_{n+1} 直接可得。

S5：正确（已逐项核验）

  • R_n 的构造： R_n = k[x] ⋉ k[t] 是平凡扩张，x 在 k[t] 上作用为 0，所以它是含幺交换环，核 0×k[t] 平方为零。
  • ρ_n 是环同态： a ↦ a′(0) 是关于“在 0 处取值”的导子。乘法条件 (a₁a₂)′(0) = a₁′(0)a₂(0) + a₁(0)a₂′(0) 成立。我用 sympy 随机抽样检验了 ρ_n 的乘法性和 R_n 的结合律，均通过。
  • 相容性： p_nρ_n = p_{n+1} 成立。复合得到的 ρ_ij 自动满足共同设定，答卷没有明说，属小省略。
  • 不满射： 若 x 有原像，则 P_n = 1 + tP_{n+1}，从而 P₁ 的每个系数都是 1，与多项式只有有限项非零矛盾。论证正确。
  • 补充两点：
    • 像恰为 {a : a′(0) = 0}。
    • ρ_n 不满射，这与 S4 一致。
  • 答卷提到的 lim¹ 阻碍也成立：核系统是 (k[t], ·t)，元素 (1,1,…) 不在映射 (P_n) ↦ (P_n − tP_{n+1}) 的像中。

S6 第一部分：正确

  • 在上三角矩阵环中，X_b = [[1,b],[0,0]] 满足 X_b² = X_b，且 q(X_b) = (1,0)。严格上三角理想 I 满足 I² = 0。
  • 所以提升不唯一，结论正确。
  • “若 k 至少含两个元素”是多余条件：域本来就有 0 ≠ 1。不影响结论。

有问题的地方（都在 S6 汇总表）

  1. 第 7 行把蕴含方向弄混了（实质性错误）。

    • 该行写的是“极限核逐元素幂零 ⟹ 极限幂等提升唯一”，结论栏是“不必要”。
    • 实际上这个蕴含可以由已有结果证明：L 是交换环族乘积的子环，所以 L 交换；S1 的唯一性论证只用到交换性和“差在核中且幂零”，不需要满射。因此若 ker p 逐元素幂零，提升到 L 的幂等元就唯一。
    • 答卷用 S3 加 S2 实际说明的是逆命题“极限幂等提升唯一 ⟹ 极限核逐元素幂零”不成立。这一点本身是对的。
    • 表格没有把正命题记为已证明，又把逆命题的反例填进正命题这一行，回答“哪些蕴含已证明、哪些不能推出”时出现了误归类。
    • 应改为两行：
      • 正命题：已证明，依据是 S1 的唯一性论证。
      • 逆命题：不成立，依据是 S3 与 S2 的对比。

  2. 第 3 行的前提不完整（表述不严谨）。

    • 该行写“各层幂等提升唯一 ⟹ 极限幂等提升存在且唯一”。但只有唯一性（至多一个）推不出存在性。
    • S2 的满射部分用的是各层提升存在且唯一，其中存在性来自 S1，需要 p_i 满射加核 nil。
    • 一般反例：单层 ℤ → ℤ/6。这里幂等提升至多一个，但 3 没有幂等提升。这个例子不满足共同设定，所以在共同设定内该行结论不受影响。

  3. 小遗漏。 S1 的存在性蕴含“元素提升 + 交换 + 核逐元素幂零 ⟹ 幂等提升存在”没有单列成一行。第 1 行只写了唯一性，结论栏写的是“已证明”，但只在说明里提到构造。
