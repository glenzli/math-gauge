S1

判定： pass

审核说明： 非负与有限点由f直接传递；有限端点用epsilon近似纤维原像和凸组合，包含+infinity及0/1端点。纤维分层取inf不要求最优点取到。

S2

判定： pass

审核说明： q_F有限连续泛函坐标连续；有限下确界a的闭集A_n在同一紧C_(a+1)中递减且非空，FIP取得最优点。所有实c的次水平集等于紧集的连续像，有限维Hausdorff下闭；另给实高度epi闭的局部开邻域证明。

S3

判定： pass

审核说明： 每个A_F在同一非空紧C_c内闭且非空；取K为任意有限多个F之和，由记录兼容性得到FIP。交点实现全记录且f<=c；Hausdorff局部凸空间E连续对偶的Hahn–Banach分离给唯一性。未加Banach、自反或可数性。

S4

判定： pass

审核说明： 定义bar(u)为实高度上图闭包，处理空/闭射线竖直纤维及竞争者两种infinity值。G=sup_F bar(g_F)q_F非负闭凸且<=f，观测扩大单调性由最大闭下界得。用P_F的上图投影闭包等于epi(bar(g_F))，再对原闭凸epi(f)的外点用几何Hahn–Banach分离（phi,b），选F=span(phi)得到G与闭上图包络完全相同。该合法更短表示不需强迫分离系数b>0，且对所有允许improper竞争h用上图包含论证最大性。

S5

判定： pass

审核说明： 给出C={s>=0,t>=0,st>=1}，连续不等式保证闭，与正域1/s上图的同一性保证凸；其指标成本非负proper闭凸。第一坐标投影成本0于s>0、其余infinity，真实极限点(0,0)缺失证明非闭。

S6

判定： pass

审核说明： 由epi包络恒等式证明G=f当且仅当f闭。p=inf_r bar(g_K)非负凸且由x0有有限点，bar(g_F)<=p<=g_F，双最大性夹逼得bar(p)=bar(g_F)。沿S5取K=Eprime得p(0)=infinity而bar(g_F)(0)=0，证明外层闭化不可省。
