一、逐项核查依据

S1：正确

  • 解集维数。 齐次解空间是 S0=W⊥\mathcal S_0=W^\perp。标准点积在 kIk^I 上非退化，所以对任意域都有 dim⁡W⊥=∣I∣−dim⁡W\dim W^\perp=|I|-\dim W，包括 F2\mathbb F_2 这种存在迷向向量的情形。这只是秩–零度定理，不需要 W∩W⊥=0W\cap W^\perp=0。系统相容，所以 S≠∅\mathcal S\neq\varnothing，从而 dim⁡S=∣I∣−dim⁡W\dim\mathcal S=|I|-\dim W。
  • 纤维维数。 非空纤维是 Fy=x+V0\mathcal F_y=x+V_0，其中 V0=W⊥∩UA⊥=(W+UA)⊥V_0=W^\perp\cap U_A^\perp=(W+U_A)^\perp，维数为 ∣I∣−dim⁡(W+UA)|I|-\dim(W+U_A)。附注里的另一种写法与此相等，因为 dim⁡(W+UA)=dim⁡W+∣A∣−dim⁡(W∩UA)\dim(W+U_A)=\dim W+|A|-\dim(W\cap U_A)。
  • 延拓判据。
    • 必要性是直接计算。
    • 充分性：限制映射 T:W⊥→kAT:W^\perp\to k^A 的伴随是 T∗(u)=ιA(u)+W∈kI/W≅(W⊥)∗T^*(u)=\iota_A(u)+W\in k^I/W\cong(W^\perp)^*，所以 ker⁡T∗≅W∩UA\ker T^*\cong W\cap U_A。
    • 再用 Im⁡T=(ker⁡T∗)⊥\operatorname{Im}T=(\ker T^*)^\perp：包含关系显然；两边维数相等，因为 rank⁡T=rank⁡T∗=∣A∣−dim⁡ker⁡T∗\operatorname{rank}T=\operatorname{rank}T^*=|A|-\dim\ker T^*。
    • 答卷还说明了 β(w)=w⋅x0\beta(w)=w\cdot x_0，与 ww 的表示方式无关。
    • 这一部分没有问题。

S2：正确

  • 三个计数是：解数 q∣I∣−dim⁡Wq^{|I|-\dim W}，可实现坐标数 qdim⁡(W+UA)−dim⁡Wq^{\dim(W+U_A)-\dim W}，每个可实现坐标的完成数 q∣I∣−dim⁡(W+UA)q^{|I|-\dim(W+U_A)}。
  • 所有非空纤维大小相同，所以用除法求可实现坐标数是合法的。
  • 公式只用了题目允许的量。

S3：正确

  • 非空与紧。 kIk^I 由 Tychonoff 定理紧且 Hausdorff。每个 fjf_j 只依赖 supp⁡aj\operatorname{supp}a_j 上有限个坐标，所以连续，单方程解集 Sj\mathcal S_j 闭。这族闭集有有限交性质，所以 S≠∅\mathcal S\neq\varnothing；S\mathcal S 是紧空间的闭子集，所以紧。
  • 全不连通。 答卷引用了"全不连通空间的乘积及其子空间仍全不连通"，这是正确的。也可以直接论证：两个不同的解在某个坐标 ii 上取值不同，柱集 {xi=t}\{x_i=t\} 既开又闭，把它们分开。
  • 像闭。 πA(S)\pi_A(\mathcal S) 是紧集在 Hausdorff 空间中的像，所以闭。
  • 元素刻画。 闭集族 {Sj}j∈J∪{Ki}i∈A\{\mathcal S_j\}_{j\in J}\cup\{K_i\}_{i\in A} 的有限交性质恰好就是题设条件。FF 或 BB 为空的情形也包含在"任意有限子集"之内。由紧性，全交非空。

S4：判定"成立"正确，核心构造正确

  • 对偶。 kI≅(k(I))∗k^I\cong(k^{(I)})^*，对应为 x↦⟨⋅,x⟩x\mapsto\langle\cdot,x\rangle，因为线性泛函由它在基 eie_i 上的取值自由决定。
  • β\beta 良定。 同一个 ww 的两种表示之差是某个有限集 FF 上的线性关系。FF 上的有限子系统有解，所以对应常数的组合为 00。
  • 整体解。 用 Zorn 引理把 WW 的基扩充为 k(I)k^{(I)} 的基，令 β~\tilde\beta 在新增基向量上取 00，再令 xi∗=β~(ei)x^*_i=\tilde\beta(e_i)。于是 ⟨aj,x∗⟩=β~(aj)=bj\langle a_j,x^*\rangle=\tilde\beta(a_j)=b_j。在 ZFC 中合法。
  • 解集。 S=x∗+W∘={x:⟨w,x⟩=β(w) ∀w∈W}\mathcal S=x^*+W^\circ=\{x:\langle w,x\rangle=\beta(w)\ \forall w\in W\}，正确（验证见 G3）。
  • 像定理。 在 W+UAW+U_A 上把 β\beta 与 γy\gamma_y 粘合。良定性恰好用到"两者在 W∩UAW\cap U_A 上一致"这一条件，然后延拓到全空间。正确。
  • 纤维。 纤维为 x+(W+UA)∘x+(W+U_A)^\circ，其中 (W+UA)∘=W∘∩UA∘(W+U_A)^\circ=W^\circ\cap U_A^\circ，UA∘={v:v∣A=0}U_A^\circ=\{v:v|_A=0\}。正确。
  • 分类表。 三行的条件全部正确，但证明有缺口，见 G1。

S5：判定"否"正确

  • 反例为 x1=1x_1=1，xj−1−xj=0x_{j-1}-x_j=0（j≥2j\ge2）。
  • 对非空有限的 FF，取 1[1,max⁡F]∈k(N)\mathbf 1_{[1,\max F]}\in k^{(\mathbb N)}，它满足 FF 中的每一行。F=∅F=\varnothing 时取 00 即可（G5）。
  • 全系统在 kNk^{\mathbb N} 中的唯一解是全 1 序列，它不在 k(N)k^{(\mathbb N)} 中。
  • 这个反例对任意域都成立。

S6：判定"闭"正确

  • 由 S4 的像定理，πA(S)=⋂w∈W∩UACw\pi_A(\mathcal S)=\bigcap_{w\in W\cap U_A}C_w。
  • 每个 ww 的支撑有限且含于 AA，所以每个 CwC_w 只是有限个坐标上的条件，是既开又闭的柱集；任意多个闭集的交仍是闭集。
  • 这里没有用到紧性。当 kk 无限且 I≠∅I\neq\varnothing 时，kIk^I 不紧：开覆盖 {x:xi0=t}t∈k\{x:x_{i_0}=t\}_{t\in k} 没有有限子覆盖。S\mathcal S 也可以不紧，例如 J=∅J=\varnothing。所以 S3 的方法搬不过来，但结论仍然成立。
  • 给出的方程描述确实只涉及有限个坐标，并且由 (aj,bj)(a_j,b_j) 决定。

G1 的补法。

单射   ⟺  W+UA=k(I)\iff W+U_A=k^{(I)}：

  • (⇐\Leftarrow) 记 M=W+UAM=W+U_A。若 M=k(I)M=k^{(I)}，则对任意 z∈M∘z\in M^\circ 有 zi=⟨ei,z⟩=0z_i=\langle e_i,z\rangle=0，所以 M∘=0M^\circ=0。由 §4，每个纤维都是单点。
  • (⇒\Rightarrow) 若 M≠k(I)M\neq k^{(I)}：
    1. 取 v0∉Mv_0\notin M，把 MM 的一组基添上 v0v_0，再扩充为 k(I)k^{(I)} 的基。
    2. 令线性泛函 φ\varphi 在 v0v_0 上取 11，在其余基向量上取 00；令 zi=φ(ei)z_i=\varphi(e_i)。
    3. 则 z∈M∘=W∘∩UA∘z\in M^\circ=W^\circ\cap U_A^\circ，且 ⟨v0,z⟩=1\langle v_0,z\rangle=1，所以 z≠0z\neq0。
    4. 任取 x∈Sx\in\mathcal S（S4 §1 已证 S≠∅\mathcal S\neq\varnothing），则 x+z∈Sx+z\in\mathcal S 且 (x+z)∣A=x∣A(x+z)|_A=x|_A，所以 πA\pi_A 不是单射。

满射   ⟺  W∩UA=0\iff W\cap U_A=0：

  • (⇐\Leftarrow) 由像定理，条件只剩 w=0w=0 一条，自动成立。
  • (⇒\Rightarrow) 若有 0≠w∈W∩UA0\neq w\in W\cap U_A：
    1. 取 i0∈Ai_0\in A 使 wi0≠0w_{i_0}\neq0。
    2. 令 y=t δi0y=t\,\delta_{i_0}，其中 t=(β(w)+1)/wi0t=(\beta(w)+1)/w_{i_0}。
    3. 则 ∑i∈Awiyi=β(w)+1≠β(w)\sum_{i\in A}w_iy_i=\beta(w)+1\neq\beta(w)，由像定理 y∉πA(S)y\notin\pi_A(\mathcal S)。

G2：措辞问题。 满射行的"意义"栏写的是"方程系中不存在支撑全在 AA 内的非平凡线性组合"。如果"非平凡"指系数不全为零，那么行线性相关时这句话是错的。

  • 反例：I={1,2}I=\{1,2\}，a1=a2=e1a_1=a_2=e_1，b1=b2=1b_1=b_2=1，A={2}A=\{2\}。
  • 此时 a1−a2=0a_1-a_2=0 是非平凡组合，支撑为空集，当然含于 AA。
  • 但 W∩UA=span⁡(e1)∩span⁡(e2)=0W\cap U_A=\operatorname{span}(e_1)\cap\operatorname{span}(e_2)=0，而且 πA\pi_A 确实是满射：x1=1x_1=1，x2x_2 任意。本轮机检也确认了这一点。
  • 应改为"WW 中不存在支撑含于 AA 的非零向量"。
  • 中间栏的形式条件 W∩UA={0}W\cap U_A=\{0\} 本身是对的。

G3：两处直接验证。

  • §2 的 S={x:⟨w,x⟩=β(w) ∀w∈W}=x∗+W∘\mathcal S=\{x:\langle w,x\rangle=\beta(w)\ \forall w\in W\}=x^*+W^\circ：
    • "⊇"：取 w=ajw=a_j；
    • "⊆"：对有限组合 w=∑cjajw=\sum c_ja_j 用线性；
    • 第二个等号：两边同时减去 x∗x^*。
  • §4 的纤维：对 x,x′∈Sx,x'\in\mathcal S，二者 AA-限制相同   ⟺  x′−x∈W∘∩UA∘\iff x'-x\in W^\circ\cap U_A^\circ。又因为和的零化子等于零化子的交，W∘∩UA∘=(W+UA)∘W^\circ\cap U_A^\circ=(W+U_A)^\circ。

G4：互不冗余。 断言为真，证明如下：

  1. {wλ}\{w_\lambda\} 在 k(A)k^{(A)} 中线性无关，把它扩充为 k(A)k^{(A)} 的基，取第 μ\mu 个对偶泛函，得到 z∈kAz\in k^A，满足 ⟨wλ,z⟩=δλμ\langle w_\lambda,z\rangle=\delta_{\lambda\mu}。
  2. 取 y0∈πA(S)y_0\in\pi_A(\mathcal S)（非空）。
  3. 则 y0+zy_0+z 满足除第 μ\mu 个以外的全部方程，但不满足第 μ\mu 个。所以没有哪个基方程能由其余方程推出。

可选补强（不算错误）。

(a) 方向空间：

  • S\mathcal S 的方向空间是 W∘≅(k(I)/W)∗W^\circ\cong(k^{(I)}/W)^*。
  • 像的方向空间是 πA(W∘)=(W∩UA)⊥≅(k(A)/(W∩UA))∗\pi_A(W^\circ)=(W\cap U_A)^\perp\cong(k^{(A)}/(W\cap U_A))^*。这是把像定理用于齐次系统得到的。
  • 纤维的方向空间是 (W+UA)∘≅(k(I)/(W+UA))∗(W+U_A)^\circ\cong(k^{(I)}/(W+U_A))^*。
  • 三者构成正合列 0→(W+UA)∘→W∘→πA(W∩UA)⊥→00\to(W+U_A)^\circ\to W^\circ\xrightarrow{\pi_A}(W\cap U_A)^\perp\to0。有限情形下，它给出的正是 S1/S2 的维数。

(b) 数据的忠实性：

  • 结论：W={v∈k(I):⟨v,⋅⟩W=\{v\in k^{(I)}:\langle v,\cdot\rangle 在 S\mathcal S 上取常值}\}，并且 β(v)\beta(v) 就是这个常值。
  • 证明：对 v∉Wv\notin W，用 G1 的构造（取 M=WM=W）得到 z∈W∘z\in W^\circ，使 ⟨v,z⟩=1\langle v,z\rangle=1。于是 ⟨v,x+z⟩≠⟨v,x⟩\langle v,x+z\rangle\neq\langle v,x\rangle，vv 在 S\mathcal S 上不是常值。
  • 推论：非空解集与数据对 (W,β∈W∗)(W,\beta\in W^*) 一一对应，而且每一对都能实现（取 WW 的一组基作为行）。
  • 如果把题目里的"分类"读作"解集按代数数据分类"，就应补上这一条。答卷采用的读法是"πA\pi_A 的单射/满射分类"，也是合理的。

三、对 current-check 的核查

论据 1（扩充系统）：正确。

  • kk 离散时，kAk^A 的基本开邻域就是有限坐标柱集 [B,y∗∣B][B,y^*|_B]。所以 y∗y^* 在闭包中，当且仅当对每个有限 B⊆AB\subseteq A 都存在 x∈Sx\in\mathcal S 使 x∣B=y∗∣Bx|_B=y^*|_B。
  • 扩充系统的行指标集是 J⊔AJ\sqcup A，所有行都有限支撑，而且每个有限子系统都可解，所以 S4 给出整体解。
  • 附带的推论：同样的论证说明，S3 的"有限可实现性"刻画对任意域都成立，不必假设 kk 有限。

论据 2：正确，与 S6 的论证相同。

论据 3（线性紧性）：在所引定理成立的前提下正确。 它用到三条事实：

  • (i) kk 离散时 kIk^I 线性紧。这是线性紧空间的乘积定理，Lefschetz 引入线性紧概念时给出的标准结果；具体章节号我没有核对。
  • (ii) 线性紧空间中的闭线性簇是线性紧的；线性紧集在连续仿射映射下的像仍是线性紧的。
  • (iii) 在 Hausdorff 的线性拓扑空间里，线性紧的线性簇是闭的。

(iii) 可以直接证明：

  1. 设 v∈L‾v\in\overline L。对每个开子空间 UU，(v+U)∩L(v+U)\cap L 是 LL 的非空闭线性簇；这里用到开子空间同时也是闭的。
  2. 开子空间的有限交仍是开子空间，所以这族集合有有限交性质。
  3. 由线性紧性，存在 ℓ\ell 属于所有 (v+U)∩L(v+U)\cap L，于是 ℓ−v∈⋂U={0}‾={0}\ell-v\in\bigcap U=\overline{\{0\}}=\{0\}，即 v=ℓ∈Lv=\ell\in L。

另外要说明，论据 3 并不是独立于 S4 的新证据，因为 kIk^I 的线性紧性与 S4 的存在定理本质上等价：

  • kIk^I 的闭子空间 CC 恰好等于 (C⊥)∘(C_\perp)^\circ，其中 C⊥={v∈k(I):⟨v,C⟩=0}C_\perp=\{v\in k^{(I)}:\langle v,C\rangle=0\}。理由：若 x∉Cx\notin C，由闭性存在有限 BB 使 x∣B∉πB(C)x|_B\notin\pi_B(C)；在有限维空间 kBk^B 中取 vv 零化 πB(C)\pi_B(C) 且 v⋅x∣B≠0v\cdot x|_B\neq0，再把 vv 零延拓到 k(I)k^{(I)} 即可。
  • 因此，一族具有有限交性质的闭线性簇，就是一个每个有限子系统都可解的有限支撑方程组，S4 给出它们的公共点。

存在的问题：

  • "S1–S6 无任何漏洞""无可辩驳的数学确定性"这一总括断言不成立，见 G1、G4。
  • Bourbaki《Algèbre》Ch. II §7 这一出处无法离线核实；三条论据都不依赖它。
  • "Hahn–Banach"这个叫法不严格。这里只需要代数上的线性泛函延拓（基扩充，在 ZFC 中由 Zorn 引理得到），不涉及半范数控制，而一般域上本来也没有序结构。"基扩充公理"应称为基扩充定理。
  • "闭仿射子空间为线性紧子空间"应改称"线性簇"。
  • "拓扑拓扑"是笔误。
  • 维持 KEEP 的决定就结论而言是对的，但应同时补上 G1。

import itertools as it, random

def rank(rows, p):
    M, r = [list(x) for x in rows], 0
    for c in range(len(M[0]) if M else 0):
        piv = next((i for i in range(r, len(M)) if M[i][c] % p), None)
        if piv is None: continue
        M[r], M[piv] = M[piv], M[r]
        inv = pow(M[r][c], p - 2, p); M[r] = [v * inv % p for v in M[r]]
        for i in range(len(M)):
            if i != r and M[i][c] % p:
                f = M[i][c]; M[i] = [(a - f * b) % p for a, b in zip(M[i], M[r])]
        r += 1
    return r

def check(p, n, rows, b, A):
    dot = lambda u, v: sum(x * y for x, y in zip(u, v)) % p
    pts = list(it.product(range(p), repeat=n))
    S = [x for x in pts if all(dot(r, x) == c for r, c in zip(rows, b))]
    if not S: return None
    dW = rank(rows, p); dWU = rank(rows + [[int(k == i) for k in range(n)] for i in A], p)
    beta, ok = {}, True                      # beta(sum c_j a_j) = sum c_j b_j; well-definedness checked
    for c in it.product(range(p), repeat=len(rows)):
        w = tuple(sum(cj * r[i] for cj, r in zip(c, rows)) % p for i in range(n))
        v = sum(cj * bj for cj, bj in zip(c, b)) % p
        ok &= beta.setdefault(w, v) == v
    WU = [w for w in beta if all(w[i] == 0 for i in range(n) if i not in A)]   # W ∩ U_A
    dWcU = rank([list(w) for w in WU], p)
    img = {}
    for x in S: img.setdefault(tuple(x[i] for i in A), []).append(x)
    ys = list(it.product(range(p), repeat=len(A)))
    ev = lambda w, y: sum(w[i] * t for i, t in zip(A, y)) % p
    ok &= len(S) == p ** (n - dW) and len(img) == p ** (dWU - dW)               # S2
    ok &= all(len(f) == p ** (n - dWU) for f in img.values()) and dWU == dW + len(A) - dWcU
    ok &= all((y in img) == all(ev(w, y) == beta[w] for w in WU) for y in ys)  # S1 / S4 image
    inj, surj = all(len(f) == 1 for f in img.values()), len(img) == p ** len(A)
    ok &= inj == (dWU == n) and surj == (dWcU == 0)                             # S4 table
    basis = []
    for w in WU:
        if rank([list(u) for u in basis + [w]], p) > len(basis): basis.append(w)
    for mu in range(len(basis)):                                                # S6 non-redundancy
        ok &= any(ev(basis[mu], y) != beta[basis[mu]] and
                  all(ev(w, y) == beta[w] for l, w in enumerate(basis) if l != mu) for y in ys)
    img0 = {tuple(x[i] for i in A) for x in pts if all(dot(r, x) == 0 for r in rows)}
    ok &= img0 == {y for y in ys if all(ev(w, y) == 0 for w in WU)}             # pi_A(W^perp) = (W∩U_A)^perp
    return ok, inj, surj

def run(p, trials, maxI, maxJ, seed):
    rng, st = random.Random(seed), dict(tests=0, fails=0, inj=0, surj=0)
    while st['tests'] < trials:
        n, m = rng.randint(1, maxI), rng.randint(0, maxJ)
        rows = [[rng.randrange(p) for _ in range(n)] for _ in range(m)]
        if m >= 2 and rng.random() < 0.3: rows[1] = list(rows[0])               # force dependent rows
        x0 = [rng.randrange(p) for _ in range(n)]
        b = [sum(a * x for a, x in zip(r, x0)) % p for r in rows]
        if rng.random() < 0.5: b = [rng.randrange(p) for _ in rows]             # random rhs, kept if consistent
        res = check(p, n, rows, b, [i for i in range(n) if rng.random() < 0.5])
        if res is None: continue
        st['tests'] += 1; st['fails'] += not res[0]; st['inj'] += res[1]; st['surj'] += res[2]
    return st
