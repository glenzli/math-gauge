S1

判定： pass

审核说明： 逐Fourier系数给有限频带唯一逆，有限非零小除数最小值存在，单频模式达到精确H^r逆范数，r任意实数。

S2

判定： pass

审核说明： 逆乘子多项式增长保持Fourier快速衰减并给各阶导数绝对一致收敛；u_N为实际截断，平方逐项估计覆盖r任意实与q>=0且常数/阶数正确。

S3

判定： pass

审核说明： 实际逆乘子差包含两个方向的除数，各>=delta且|k1|<=N，H^r逐项估计给指定常数，不将有限频带条件升级为全频率。

S4

判定： pass

审核说明： 精确gamma_s>0充要判据和最优常数由单频及求和双向得到；连分数标准误差/第二类最佳逼近以明确形式用于全部无理alpha，sup q_next/q^s给全部损失和临界端点。无有限损失时构造一个光滑F迫使无限多解系数为1，证明满射性必要性。二次共轭非零整数界给s=1达到，tau>=1排除更小；m+4分部积分后二维可和余项给全部C^m估计。

S5

判定： pass

审核说明： 任意候选J内选有理p/q，以同一个非零频率和J内趋向它的无理alpha_j，右端范数趋零而左端1，反驳每个有限s,C的共同估计。

S6

判定： pass

审核说明： 阶乘十进部分和尾界与有理差下界证明给定alpha无理；单个F的各阶导数绝对一致收敛，频率互异且任一解对应系数全为1，违反L2平方可和，满足同一光滑零均值右端要求。
