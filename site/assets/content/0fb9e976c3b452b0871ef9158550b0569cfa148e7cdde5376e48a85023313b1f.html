一、逐项核查

记 V = k^{(I)}，并把 k^I 与 V*（V 的代数对偶）对应起来：x ↦ (v ↦ Σ v_i x_i)，这是有限和。

S1：正确

  • 解集维数：齐次解空间是 W^⊥。k^I 上的标准配对非退化（特征 p 时也成立），所以 dim W^⊥ = |I| − dim W。原系统相容，因此 S 是 W^⊥ 的一个陪集。

  • 纤维维数：x|_A = 0 当且仅当 x ∈ U_A^⊥，所以方向空间是 W^⊥ ∩ U_A^⊥ = (W+U_A)^⊥，维数为 |I| − dim(W+U_A)。由 dim U_A = |A|，备注中的另一种写法也成立。A = ∅ 时退化为解集本身，结论一致。

  • β(w) 与表示 w = Σc_j a_j 的选取无关：任取特解 x₀，有 Σc_j b_j = w·x₀。答卷给出的正是这个论证。

  • 必要性：用 supp w ⊆ A 直接计算，正确。

  • 充分性：设 T: W^⊥ → k^A 为限制映射。

    • 对 v ∈ W^⊥，有 (T*u)(v) = ι_A(u)·v。
    • 有限维时 (W^⊥)^⊥ = W，于是 (W^⊥)* ≅ k^I/W，从而 T*(u) = ι_A(u)+W，ker T* ≅ W∩U_A。
    • 由 Im T = (ker T*)^⊥ 得到判据；z·u 的计算用到了 supp w ⊆ A。

    论证完整。

S2：正确

三个公式是：

  • 解数 |S| = q^{|I|−dim W}；
  • 每个可实现坐标的完成数为 q^{|I|−dim(W+U_A)}；
  • 可实现坐标数为 q^{dim(W+U_A)−dim W}。

所有非空纤维大小相同，所以"总数 ÷ 纤维大小"成立。公式只用到题目允许的量（以及 q）。

S3：正确

  • 非空且紧：Tychonoff 定理给出 k^I 紧且 Hausdorff。每个 f_j 只依赖有限个坐标，因而连续，S_j = f_j^{-1}(b_j) 是闭集。题设给出有限交性质，所以 S 非空；S 是紧空间的闭子集，所以紧。
  • 全不连通：连通集在每个坐标上的投影是离散空间 k 中的连通集，只能是单点。所以乘积空间全不连通，子空间继承这一性质。
  • π_A(S) 闭：紧集的连续像在 Hausdorff 空间 k^A 中是紧集，因而闭。
  • 元素刻画：闭集族 {S_j}{j∈J} ∪ {K_i = π_i^{-1}(y_i)}{i∈A} 的有限交性质，恰好就是"任意有限行集 F 与任意有限 B ⊆ A 同时可实现"。由紧性得到全交非空，两个方向都正确。

S4：判定与主要证明正确，分类表缺证明

  • β 良定义：有限关系 Σ_{F}c_j a_j = 0 与有限子系统的解 x^{(F)} 配对，得到 Σc_j b_j = 0，这是有限和，有效。不同表示之差是有限关系，所以 β ∈ W* 良定义。

  • 整体解：在 ZFC 中把 W 的基扩充为 V 的基（Zorn 引理），得到 β̃ 且 β̃|_W = β。令 x*_i = β̃(e_i)，则 Σa_j(i)x*_i = β̃(a_j) = b_j，正确。

  • S = x* + W° = {x : ⟨w,x⟩ = β(w), ∀w∈W}：两种写法等价，因为 ⟨w,x−x*⟩ = ⟨w,x⟩ − β(w)。答卷没有写出这一步，属于平凡省略。

  • 像定理：

    • "⊆" 方向用 supp w ⊆ A 即得。
    • "⊇" 方向：γ_y 在 U_A = k^{(A)} 上是有限和，因而良定义。β 与 γ_y 在 W∩U_A 上一致，所以 ψ 在 W+U_A 上良定义。把 ψ 延拓到 V（基扩充），取 x_i = Φ(e_i) 即得所需的解。

    所用数据 W、β、W∩U_A 都只由 (a_j, b_j) 决定，符合题意。

  • 纤维：纤维是 x + W°∩U_A° = x + (W+U_A)°，正确。

  • 分类表：三条结论都正确，但没有证明（补证见第三节）。另有一处措辞不严谨："不存在支撑全在 A 内的非平凡线性组合"若按字面理解，会把结果为 0 的行间关系（其支撑是 ∅ ⊆ A）也算进去，变成"各行线性无关"，这不是正确条件。正确条件就是表中写的 W∩U_A = {0}。

S5：正确

反例为 x₁ = 1，x_{j−1} − x_j = 0（j ≥ 2），对任意域都成立。

  • 每行有限支撑。
  • 非空有限集 F 有有限支撑解 1_{[1, max F]}，逐行验证无误。答卷没有提空集 F，但此时取 x = 0 即可，可以忽略。
  • 全系统在 k^ℕ 中的唯一解是全 1 序列，不是有限支撑的。

S6：正确

  • 每个 w ∈ W∩U_A ⊆ k^{(I)} 的支撑都是有限集，所以 C_w = {y : Σw_i y_i = β(w)} 是有限坐标上的条件。在离散拓扑下它是 clopen 柱集。
  • 由像定理，π_A(S) = ⋂_w C_w 是闭集之交，因而闭。论证不依赖 |k|。
  • 答卷说可以只取 W∩U_A 一组基上的方程。这些方程与全部方程等价，由线性即得，答卷没有写出。
  • "互不冗余"这一断言成立，但答卷没有证明。证明如下：对基中某个 λ₀，在 W∩U_A 上定义 β′，令它在 w_{λ₀} 处取 β(w_{λ₀})+1、在其余基元处取 β 的值；把 β′ 延拓到 U_A = k^{(A)}，再令 y_i = β′(e_i)。这个 y 满足其余所有方程，但不满足第 λ₀ 个。
  • 这些省略都不影响 S6 的结论。

三、补证：S4 分类表

引理：若 M 是 V = k^{(I)} 的真子空间，则 M° ≠ 0。

证明：取 v ∉ M，把 M 的一组基并上 v 扩充为 V 的基（Zorn 引理）。令线性泛函 φ 在 v 上取 1、在其余基元上取 0，再令 x_i = φ(e_i)。则 x ∈ M° 且 ⟨v,x⟩ = 1，所以 x ≠ 0。∎

下面始终用到 S ≠ ∅（S4 第 1 节）。

  • 单射 ⇔ W+U_A = V：
    • 非空纤维都是 (W+U_A)° 的陪集，所以 π_A|_S 是单射当且仅当 (W+U_A)° = 0。
    • 若 W+U_A = V，则 (W+U_A)° = V° = 0。
    • 若 W+U_A ≠ V，由引理 (W+U_A)° ≠ 0，不是单射。
  • 满射 ⇔ W∩U_A = 0：
    • 若 W∩U_A = 0，像定理中的条件是空的，所以 π_A(S) = k^A。
    • 若存在 0 ≠ w ∈ W∩U_A，取 i₀ ∈ A 使 w_{i₀} ≠ 0（w 的支撑在 A 内）。先任意给定 y 在 A∖{i₀} 上的取值，再选 y_{i₀} 使 Σw_i y_i ≠ β(w)。这样的 y 不在像中。
  • 双射 ⇔ W ⊕ U_A = V：就是上面两条同时成立。此时 π_A|_S 是双射仿射映射，即仿射同构。

四、可选补充（不算答卷缺陷）

题目说的"分类"具体指什么并不明确，答卷的分类表是一种合理理解。下面这段内容答卷没有写，也可以作为 S2 计数在任意维情形的类比；我不把它算作扣分项。

基本事实：对子空间 M ⊆ V，有典范同构 M° ≅ (V/M)*。若 B 是 V/M 的一组基，则 (V/M)* ≅ k^B，所以 |M°| = |k|^{dim(V/M)}（基数幂）。

三个方向空间：

  • S：它是 W° ≅ (V/W)* 的陪集。

  • 非空纤维：它是 (W+U_A)° ≅ (V/(W+U_A))* 的陪集。

  • 像 π_A(S)：π_A(S) = π_A(x*) + π_A(W°)。把像定理用于齐次系统，得到

    π_A(W°) = {z ∈ k^A : Σw_i z_i = 0, ∀w ∈ W∩U_A} ≅ (U_A/(W∩U_A))* ≅ ((W+U_A)/W)*。

正合列：0 → (W+U_A)° → W° → π_A(W°) → 0。这里 W° → π_A(W°) 是限制映射 π_A，其核为 W°∩U_A° = (W+U_A)°。

取有限情形：dim V/W = |I| − dim W，dim V/(W+U_A) = |I| − dim(W+U_A)，dim (W+U_A)/W = dim(W+U_A) − dim W，恰好还原 S2 的三个公式。
