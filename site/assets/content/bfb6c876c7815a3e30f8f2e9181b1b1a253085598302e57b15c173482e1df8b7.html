二、仍有的不确定性

尽管项目在固定工具链下零误差通过内核检查并覆盖全部 92 项义务，从形式化建模与外部评审视角仍存在以下属于“等价表示选择”层面的不确定性：

  1. 宇宙层级特化（Type vs Type u）：为与冻结背景模块（如 [operator_space.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/formal_oet/vol_01/ch_01_foundations/operator_space.lean) 和 [metric_entropy.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/formal_oet/vol_01/ch_01_foundations/metric_entropy.lean) 中固定在 Type 上的 Operator、covering_number、metric_entropy）无缝对接，本章声明统一采用 {X I : Type} 而非宇宙多态 {X : Type u} {I : Type v}。在基准测试与教材具体空间（有限集、R⊔{⊥}\mathbb{R} \sqcup \{\bot\} 等）下二者完全兼容，但若外部调用方在更高宇宙层级 Type (u+1) 上实例化则需额外升降级包装。
  2. 算子链与预序方向的索引/序约定：
    • 命题 3.2(ii)（[Sec1_ComponentPartition.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/Ch03/Sec1_ComponentPartition.lean#L176-L284)）用 0-指标序列 ϕ : ℕ → Operator X bot 与 ⋃ m < n 表示原文 1-指标有限链 cn=ϕn∘⋯∘ϕ1c_n = \phi_n \circ \cdots \circ \phi_1 与 ⋃m=1n\bigcup_{m=1}^n（下标平移 mlean=mtext−1m_{\text{lean}} = m_{\text{text}} - 1，零步基例 c0=idXc_0 = \mathrm{id}_{\mathcal{X}} 完全一致）。
    • 纤维预序（[Defs.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/Ch03/Defs.lean#L215-L226)）直接按原文定义为二元关系 FiberGe d U ϕA ϕB（即 ϕA⪰fiber,UϕB\phi_A \succeq_{\mathrm{fiber}, U} \phi_B），而在绑定 Mathlib 的 Preorder 类型类（以 ≤ 为原语）时采用标准对偶 a ≤ b := FiberGe d U b.1 a.1；相关定理均直接以 FiberGe 与 relZero 表述以避免方向歧义。
