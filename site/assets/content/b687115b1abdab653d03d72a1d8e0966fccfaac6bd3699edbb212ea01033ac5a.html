S1

判定： pass

审核说明： 有限非零频带乘子2πi(αk₁+k₂)均非零，实际逐模除法给双侧逆。Hʳ对角正交使范数恰为1/(2π min|dα(k)|)，有限非空频带上最小正值取得，并由单频达到。没有外推N一致界。

S2

判定： pass

审核说明： 算术下界给u的全部Hᵗ范数有限，开头Cauchy–Schwarz与二维〈k〉⁻⁴可和论证保证每阶导数级数绝对一致收敛，实际光滑。零模为0且无理乘子给唯一性。u_N即u频带截断，尾部〈k〉⁻q≤(1+N²)⁻q/2，逐项平方后给精确题定常数，含q=0与负r。

S3

判定： pass

审核说明： 逆乘子差分母为两个各自小除数的乘积，绝对值≤|α−β|N/δ²，再乘1/(2π)，同权正交求和给任意r的题定估计。δ/N仅在固定频带使用。

S4

判定： pass

审核说明： 精确允许集D_s>0，单频必要和逐项充分及最优常数均证明；并与inf_q qˢ dist(qα,Z)>0等价。λ为log小除数的limsup，超临界/次临界及端点统一下界逐项处理；有限λ等价有限阶下界。满射充分援S2；必要构造同一个F=Σ2πi dα(k_j)e_kj，选|dα(k_j)|〈k_j〉ʲ<2⁻ʲ使全导数一致收敛，任何解系数恒1违背Bessel，因此量词桥完整。二次方向用共轭乘积非零整数给1阶下界，鸽巢λ≥1排除s<1，端点取到。分部积分m+4给系数〈k〉⁻m−4，乘逆损失和m导数后〈k〉⁻3二维可和，常数独立F。额外连分数端点不取到例合法但非必答。

S5

判定： pass

审核说明： 对任意候选开区间J选其内有理p/q，再取仍在J的无理α_j趋于该有理。固定k=(q,−p)与u=e_k使L²范数1、Hˢ像范数2πq|α_j−p/q|〈k〉ˢ→0，反驳任意有限共同C和有限s。每个参数始终无理，不否定固定二次方向的正确估计。

S6

判定： pass

审核说明： 给Q_n=10^{n!}、整数P_n与正尾R_n<2Q_n^{-n−1}，有理数最小差1/(bQ_n)矛盾证无理。实际单一F=ΣQ_n^{-n} e_(Q_n,−P_n)，频率互异且P_n<Q_n；任意m阶尾项≤const Q_n^{m−n}，n≥m+2可求和，故光滑零均值。小除数<2Q_n^{-n}，任何解在全部这些频率系数>1/(4π)，由Bessel不可能L²，故无光滑解。此有效替代路线只需非衰减，不必参考中系数发散。
