结论： Lean 实现的结论部分正确，与正文一致，但不算完全覆盖正文命题。原因在前提：Lean 要求代理网络的每一条可达路径都带一个 Lip 证书 hLq : ∀ q : N.ReachablePath, IsLipMatrix …。正文只要求出现在并集指标集里的路径（j∈Ires(q)j\in I_{\rm res}(q) 或 J⊆Ires(q)J\subseteq I_{\rm res}(q)）带证书。当度量族非分离时，可以构造出正文适用、Lean 定理无法调用的例子。补齐只需把这个前提改成条件形式，证明几乎不用改。

3. 不足：全路径 Lip 证书前提（可复核反例）

结论： 正文中 Lq\mathbf L_q 是在"设 q∈Pq\in\mathcal P、j∈Ires(q)j\in I_{\rm res}(q)"之后才选取的，推论的并集也只经过这些 qq。Lean 却要求对所有可达路径给出 IsLipMatrix。

为什么这不是平凡条件： 即使矩阵允许取 ⊤\top，在 UqU_q 上存在 Lip 矩阵也等价于路径链 cqc_q 保持全分量零距关系：若对所有 ii 都有 di(x,y)=0d_i(x,y)=0，则对所有 jj 必须有 dj(cqx,cqy)=0d_j(c_qx,c_qy)=0。我已在本地用 Lean 证明这个等价，充分性方向取全 ⊤\top 矩阵即可。

  • 在分离的度量族下这个条件自动成立。此时可以给不在指标集里的路径填上全 ⊤\top 矩阵，Lean 版与正文等价。
  • 在非分离的度量族下（gauge_space 中明确允许这种情形，见 IsNonSeparating）就可能失败。

反例：

  • 空间： X={⊥,a,b,c}X=\{\bot,a,b,c\}，I={∗}I=\{*\}；d(a,b)=0d(a,b)=0，d(a,c)=d(b,c)=1d(a,c)=d(b,c)=1，d(x,⊥)=+∞d(x,\bot)=+\infty（x≠⊥x\ne\bot）。这是一个扩展伪度量。
  • 网络： 两个节点。
    • ψ1\psi_1：c↦cc\mapsto c，其余点映到 ⊥\bot。
    • ψ2\psi_2：a↦aa\mapsto a，b↦cb\mapsto c，其余点映到 ⊥\bot。
    • 入口：c→β1c\to\beta_1，a,b→β2a,b\to\beta_2；输出一律终止。
    • 于是 U={a,b,c}U=\{a,b,c\}，两条路径为 q1=(β1)q_1=(\beta_1)，Uq1={c}U_{q_1}=\{c\}；q2=(β2)q_2=(\beta_2)，Uq2={a,b}U_{q_2}=\{a,b\}。
  • 其余数据： 代理 ϕ=ϕN\phi=\phi_{\mathcal N}；目标 ϕ♮=id\phi^\natural=\mathrm{id}；V∗=UV^*=U，L∗=1\mathbf L^*=1；采样 S∗={c}S_*=\{c\}；δo=0\delta_o=0。
  • 正文一侧： Ires(q1)={∗}I_{\rm res}(q_1)=\{*\}，Ires(q2)=∅I_{\rm res}(q_2)=\emptyset，所以正文只需要 Lq1\mathbf L_{q_1}，取 00 就合法。推论成立且不空洞：c∈Uq1,∗(0)c\in U_{q_1,*}(0)，并且 d(ϕc,c)=0d(\phi c,c)=0。
  • Lean 一侧： hLq 还要求 q2q_2 的 Lip 矩阵，需要 1=d(ψ2a,ψ2b)≤∑iLi→∗ di(a,b)=L⋅0=01=d(\psi_2a,\psi_2b)\le \sum_i L_{i\to *}\,d_i(a,b)=L\cdot 0=0（在 ENNReal 中 ⊤⋅0=0\top\cdot0=0），这不可能成立。因此 Lean 推论在这个例子中无法调用。

我在本地 Lean 中验证了这个反例的各个部分（original_hLq_unsatisfiable、text_hLq_satisfiable、text_conclusion_nonvacuous），公理同样只有三条标准公理。这些是我补充的验证，未提交到源码中。

4. 补齐方式

把前提改成条件形式，证明只需改成调用 hLq q hj。以下版本我已在本地编译通过：

theorem path_component_guarantee_union_subset_proxy_error_weak
    … (hUV : N.U ⊆ Vstar)
    (hLq : ∀ q : N.ReachablePath, j ∈ path_evaluable_components N sample q →
      IsLipMatrix d (N.path_chain q.nodes) (N.path_domain q.nodes) (Lq q))
    (hLstar : TargetLipEnvelopeCertificate d target Vstar Lstar) :
    {x | ∃ q, j ∈ path_evaluable_components N sample q ∧ x ∈ …} ⊆
      {x | x ∈ N.U ∧ d j (proxy.func x) (target.func x) ≤ tau} := by
  rintro x ⟨q, hj, hxq⟩
  exact ⟨N.path_domain_subset_source hxq.1,
    proxy_path_component_guarantee_error_bound d hd target proxy N sample delta_o q
      Vstar (Lq q) Lstar j tau hrep
      (fun _ hy => hUV (N.path_domain_subset_source hy)) (hLq q hj) hLstar hj hxq⟩

联合形式相同，只把条件换成 J ⊆ path_evaluable_components N sample q → …，并调用 proxy_path_joint_guarantee_error_bound。新的弱前提版本可推出原版本，所以原版本是它的特例。另一种做法是保留原陈述，但说明它只对应"每条路径都已固定 Lip 证书族"这种更强的读法。

总结：

  • 推论的结论（两条包含式）、所有对象的定义和证明链都已在源码中正确证明。
  • 缺口只在 Lip 证书前提的作用范围；只有在度量族非分离、且某条不在指标集中的路径链不保持零距关系时才会出现。
  • 按第 4 节改写后即可完整覆盖正文。
