  • 正确部分：S1、S2、S3、S4、S5 和 S6 第一问的结论与证明都正确。只有几处一行即可补齐的省略，见第四节。

一、核验通过的部分

S1 正确。

  • 唯一性：δ=ẽ₁−ẽ₂ 属于 ker q，故幂零。由交换性，ε=ẽ₁(1−ẽ₂)=ẽ₁δ 是幂等元，且 εᵐ=ẽ₁δᵐ=0。所以 ε=0。对称地 ẽ₂(1−ẽ₁)=0，于是 ẽ₁=ẽ₁ẽ₂=ẽ₂。这一段没有用到 q 满射。
  • 存在性：
    • E_n 的每一项含 Xᵏ（k≥n）。1−E_n 的每一项含 (1−X)^{2n−1−k}，指数至少为 n。所以 E_n(1−E_n)∈((X²−X)ⁿ)。
    • E_n 模 X 同余于 0，模 1−X 同余于 1。又 (X)+(1−X)=ℤ[X]，所以 (X)∩(1−X)=(X²−X)，从而 E_n−X∈(X²−X)。
    • 用求值同态 ℤ[X]→R 代入 x，得到 ẽ 幂等且 q(ẽ)=e。
  • 题目的附加要求都满足：n 在取定 x 之后才选，不需要统一的幂零指数；系数在 ℤ 中，不需要 2 可逆；结果与 x、n 的选取无关，这由唯一性得到。
  • 补充（不影响 S1）：存在性的计算只发生在交换子环 ℤ[x] 中，ker q 是双边理想。所以对非交换环、nil 理想，存在性同样成立；只有唯一性需要交换性。这一点与 S6 有关。

S2 正确。

  • p 良定：取 i、j 的公共上界 k，则 p_i(x_i)=p_iρ_ik(x_k)=p_k(x_k)=p_j(x_j)。p=p_i∘π_i 是含幺环同态。答卷没有声称 p 满射，这是对的（见 S5）。
  • J=∅：D_∅(R) 非空当且仅当 1=0。
    • S=0 时，1∈ker p_i 幂零，故各 R_i=0，L=0。
    • S≠0 时，p(1)=1≠0，故 L≠0。
    • 两边同时为单点或同时为空。
  • J≠∅：
    • 单射：由各层 S1 的唯一性得到。
    • 满射：ρ_ik(ẽ_{j,k}) 是 R_i 中 e_j 的幂等提升，由唯一性等于 ẽ_{j,i}，所以各层自动相容，不需要选择。
    • 正交与单位和：ẽ_{j,i}ẽ_{k,i} 是提升 0 的幂等元（这里用了交换性），故为 0。E_i 是提升 1 的幂等元，故为 1。
  • Φ、Ψ 互逆：关键在于 k≠j 时 ẽ_k=(1−ẽ_j)ẽ_k∈(1−ẽ_j)L，而 ẽ_j≡1。J=∅ 时 L=0，空积是零环，公式依然成立。
  • 自然性：由 p′v=up 得 p′*v=u_p_，取逆即 v_(p_)⁻¹=(p′_)⁻¹u_*。又 v(1−ẽ_j)=1−ẽ′_j，所以 (∏v_j)∘Φ=Φ′∘v。

S3 正确。

  • ker p_n=(t)/(tⁿ⁺¹) 是幂零理想，满足共同设定。
  • L≅k[[t]]。元组 (t mod tⁿ⁺¹)_n 的 m 次方在第 m 层等于 tᵐ≠0，所以 t∈ker p 不幂零。
  • 与 S2 一致：k[[t]] 和 k 都只有幂等元 0、1，D_J 都由"恰有一个分量为 1"的元组组成（J=∅ 时都为空），p_* 是双射。S2 从未断言 ker p 是 nil 的。

S4 正确。 由 p₁ 满射取 x₁，再由 ρ_n 满射递归取 x_{n+1}∈ρ_n⁻¹(x_n)（依赖选择公理），自动有 p_{n+1}(x_{n+1})=p_n(x_n)=s。证明没有用到交换性或 nil 核，与题意相符。

S5 正确，反例成立。

  • 设定成立：
    • R_n=k[x]⋉k[t]（k[t] 经 a↦a(0) 成为 k[x]-模）是交换含幺环。
    • ker p_n 平方为零。
    • ρ_n 的乘性正好归结为 (ab)′(0)=a′(0)b(0)+a(0)b′(0)。
    • p_nρ_n=p_{n+1}。
  • x 无原像：若 x 有原像，则 P_n=1+tP_{n+1}，于是 P₁ 的所有系数都是 1，与多项式矛盾。
  • 补充：用同样方法可以算出整个 L。
    • a′(0)=c≠0 时同样矛盾。
    • a′(0)=0 时 P_n=tP_{n+1}，P_n 被所有 t^N 整除，所以 P_n=0。
    • 因此 L≅k[x²,x³]，p 就是包含映射，ker p=0。
    • 另外 ρ_n 不满射：(x,0) 不在像中，因为 1+tP≠0。这与 S4 不冲突。

S6 第一问正确。 取上三角矩阵环 T，I=kE₁₂，则 I²=0，T/I≅k×k。X_b=E₁₁+bE₁₂ 满足 X_b²=X_b 且 q(X_b)=(1,0)；b=0 和 b=1 给出两个不同的提升。

二、S6 第二问的问题

问题 1：字面为假的蕴含被标为"已证明"

原表这一行："各层幂等提升唯一 ⟹ 极限幂等提升存在且唯一｜已证明｜S2"。

按答卷自己的划分，前件只有各层的 C，结论却是极限上的 B∧C。这个命题按字面为假。

反例：任取非空有向 I，令 R_i=ℤ，ρ_ij=id，S=ℤ/6，p_i 为约化，则 L≅ℤ。

  • ℤ 的幂等元只有 0、1，它们在 ℤ/6 中的像不同，所以各层 C 成立。
  • 但 3∈ℤ/6 是幂等元（9≡3），在 L=ℤ 中没有幂等原像，所以极限上 B 不成立。
  • 这个例子不满足 nil 条件，它说明的正是：只有"唯一"推不出"存在"。

S2 实际证明的是"各层存在且唯一 ⟹ 极限存在且唯一"，各层的存在性来自 S1 的构造。答卷解释中"唯一性迫使相容"的机制是对的，但拼接之前必须先有各层的 ẽ_{j,i}。答卷在 S3 里写的是"存在且仅存在唯一"，与这一行不一致。

影响：在共同设定内，各层 B、C 都由 S1 自动成立，所以这一行若只限于共同设定，不会造成错误后果。但 S6 第二问的任务正是区分存在与唯一，而这一行实际上把"唯一 ⟹ 存在"列成了已证明，所以归类有误。修正方法是在前件中加上"存在且"。S2 本身不受影响。

问题 2：所写箭头没有判定，理由针对的是反方向

原表这一行："极限核逐元素幂零 ⟹ 极限幂等提升唯一｜不必要｜S3 与 S2 对比"。

给出的理由本身正确：S3 中 C 成立而 D 不成立。但它说明的是 C ⟹̸ D，也就是 D 不是 C 的必要条件。所写箭头 D⟹C 本身的真假没有判定：

  • L 交换时成立。共同设定下 L 是交换环之积的子环，必然交换。两个提升之差落在 ker p 中，因而幂零，S1 唯一性那一段可以逐字搬用，也不需要 p 满射。
  • 不要求交换时不成立。把 S6 的 q 做成常值塔，则 L=T，ker p=I 平方为零，但 (1,0) 有多个提升。

影响：一条可以证明的蕴含没有被判定；标注"不必要"还容易被误读成"不成立"。

问题 3：漏掉了"可数"这个条件

原表这一行："各层过渡满射 + 各层元素提升 ⟹ 极限元素提升｜已证明｜S4"。

S4 证明的是可数塔，证明靠沿 ℕ 递归选取。如果 I 有可数共尾子集，可以取一条共尾递增链，极限不变，S4 依然适用。但对一般有向 I（S2 的设定）去掉可数性，命题就是假的，即使同时要求交换、核平方为零。

ω₁ 反例。 取 I=ω₁，它是良序集，因而有向。

(a) 构造协调的函数序列。 递归构造 e_α: α→ℕ，要求每个函数有限对一（每个值的原像有限）；并且 β<α 时，e_α|β 与 e_β 只在有限个点上不同，记作 =*。

  • e₀=∅。
  • 后继步：e_{α+1}=e_α∪{(α,0)}，两条要求显然保持。
  • 极限步：α 可数，取 0=α₀<α₁<⋯ 共尾于 α，在 [α_n, α_{n+1}) 上令 e_α=max(e_{α_{n+1}}, n)。
    • 有限对一：值 m 只可能出现在 n≤m 的有限个区间里，每个区间内又只出现在 e_{α_{n+1}}≤m 的有限个点上。
    • 协调：对 β<α，取 N 使 β<α_N。当 n<N 时，在 [α_n, α_{n+1}) 上由归纳假设 e_{α_{n+1}}=*e_{α_N}；而取 max 只在 e_{α_{n+1}}<n 的有限个点上改变取值。合并有限个区间得 e_α|α_N=*e_{α_N}，所以 e_α|β=*e_{α_N}|β=*e_β。

(b) 构造环系统。

  • 定义：
    • S=ℚ[x]。
    • G_α 为 α 上有限支撑的 ℚ 值函数，经 a↦a(0) 成为 S-模。
    • R_α=S⋉G_α，乘法 (a,g)(b,h)=(ab, a(0)h+b(0)g)，p_α(a,g)=a。
    • 令 c_{αβ}=e_β|α−e_α∈G_α，ρ_{αβ}(a,g)=(a, g|α+a′(0)c_{αβ})。
  • 验证：
    • 由 c_{βγ}|α+c_{αβ}=c_{αγ} 和 c_{αα}=0，这是一个逆系。
    • 乘性的计算与 S5 相同：a↦a′(0) 满足 Leibniz 律，限制映射是线性的。
    • p_αρ_{αβ}=p_β；ker p_α 平方为零；R_α 交换；p_α 满射。
    • ρ_{αβ} 满射：取 h−a′(0)c_{αβ} 的零延拓即可。
  • 所以这个系统满足共同设定和 S4 的全部条件，唯独不可数。

(c) x 不可提升。

  • 设 (x, g_α)_α∈L，则相容条件就是 (g_β+e_β)|α=g_α+e_α。
  • 于是各 g_α+e_α 粘合成一个 F: ω₁→ℚ，且 F|α−e_α=g_α 有限支撑。
  • ℚ 可数，所以 F 有一个不可数纤维 A=F⁻¹(q)。取 A 的前 ω 个元素，令 α 为它们的上确界（<ω₁），则 A∩α 无限。
  • 在 A∩α 上 e_α=q−g_α，除有限个点外都取常值 q，与 e_α 有限对一矛盾。若 q∉ℕ，则 g_α 在无限集上非零，同样矛盾。
  • 所以 p 不满射。

影响：S4 本身正确。答卷说明里"依序选取"暗含了可数性，但表中命题须写明"可数塔（或 I 有可数共尾子集）"。

问题 4：整理不完整（遗漏，不算错误）

以下关系用现有材料就能判定，表中没有列出：

  • A ⟹̸ B 与 A ⟹̸ C。
    • 常值塔 ℤ→ℤ/6 满足 S4 的全部条件，A 成立而 B 不成立。
    • 常值塔 k×k→k（第一投影）中，1 有两个幂等原像 (1,0) 和 (1,1)，所以 C 不成立。
    • 也就是说，S4 对幂等元不提供任何信息。表中只列了 B∧C ⟹̸ A 这一个方向。

  • A∧D ⟹ B，且不需要交换性。 这就是把 S1 的构造直接用于 p。所以在 S6 的情形下，失效的只是唯一性，存在性仍然成立。
  • 共同设定下 A 与 D 相互独立，见第三节。
