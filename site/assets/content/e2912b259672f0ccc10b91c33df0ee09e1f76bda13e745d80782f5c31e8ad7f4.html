    • 正文（[source.md](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane1-20261114-v5/attempts/AHR04/physical-1/session/work/source.md#L110-L116)）对非空 JJ 定义 Uq,J(τ):=⋂j∈JUq,j(τj)U_{q,J}(\boldsymbol\tau) := \bigcap_{j \in J} U_{q,j}(\tau_j)；Lean（[path_guarantee_domains.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane1-20261114-v5/attempts/AHR04/physical-1/session/work/formal_oet/vol_03/ch_14_empirical_network_fitting/path_guarantee_domains.lean#L39-L46)）定义为 {x | x ∈ N.path_domain q.nodes ∧ ∀ j ∈ J, ... ≤ tau j}。
    • 原因与差异：在 Lean 的 Set X 中，当 J=∅J = \emptyset 时，⋂ j ∈ ∅, U_{q,j}(τ_j) = Set.univ，其中包含吸收元 bot ∉ N.U，会导致省略 J.Nonempty 的第 553 行定理不成立；因此源码采用概括式是有意为之的安全编码。在正文的 hJ_nonempty : J.Nonempty 假设下，两者外延恒等。
    • 补齐方式：补充桥接引理，证明在 hJ : J.Nonempty 下 path_joint_empirical_guarantee_domain ... = ⋂ j ∈ J, path_component_empirical_guarantee_domain ...。
  2. 存在量词并集 vs. 指标并集 ⋃，以及全函数参数化：
    • 源码用 {x | ∃ q : N.ReachablePath, P q ∧ x ∈ ...} 表示 ⋃q∈P,P(q)(⋯ )\bigcup_{q \in \mathcal P, P(q)} (\cdots)，可通过 Set.ext 与 Set.mem_iUnion₂ 一步互转；tau : I → ENNReal 与 Lq : N.ReachablePath → I → I → ENNReal 定义为全函数而非子类型函数，由于 ENNReal 非空（含 0）且定理从未读取作用域外的指标，不损失任何一般性。
  3. 正文标题“全局拟合含义”与第 7 章 InFittingBall 的衔接：
    • 正文结论以显式集合包含给出，同时标题指向代理算子在并集域上的全局拟合保证。第 7 章已在 [fitting_ball.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane1-20261114-v5/attempts/AHR04/physical-1/session/work/formal_oet/vol_02/ch_07_fitting_foundations/fitting_ball.lean#L35-L41) 定义了 InFittingBall d target proxy U J eps（要求 U ⊆ dom target、U ⊆ dom proxy、∀ j ∈ J, eps j ≠ ⊤ 及 d j (target.func x) (proxy.func x) ≤ eps j）。
    • 补齐方式：结合 hrep（蕴含 N.U ⊆ dom proxy）、hpathV + hLstar.lip_matrix.1（蕴含 N.U ⊆ dom target）、(hd j).symm（对称性转换 proxy/target 顺序）及 htau_finite，即可将联合并集结论直接升级为 InFittingBall d target proxy union_domain J tau。
