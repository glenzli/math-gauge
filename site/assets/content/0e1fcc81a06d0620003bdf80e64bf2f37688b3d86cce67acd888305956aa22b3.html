S1

判定： pass

审核说明： 按 Fourier 模逐系数除以非零乘子，有限非空频带的最小小除数给确切算子范数，达到最小值的单模实际取等。

S2

判定： pass

审核说明： 分部积分及二维导数级数绝对一致收敛给实际光滑解，实 r 与 q≥0 的截断估计按模平方求和，常数和幂次准确。

S3

判定： pass

审核说明： 由两个逆乘子的差得到正确乘积分母，使用固定频带及两边共同 δ，把逐模界直接转成 H^r 范数界。

S4

判定： pass

审核说明： 用单模与逐模和证明全部允许损失的充要判据，再用一个光滑坏右端证无多项式界时不满射。连分数的相邻基及误差比较证明端点刻画；二次方向的 q 递推给一阶恰取到，保留二维可和性证明 C^(m+4)→C^m。

S5

判定： pass

审核说明： 任意给定邻域取有理共振点及收敛到它的无理参数列，固定实际单模令右范数趋零，严格否定统一 s、C。

S6

判定： pass

审核说明： 阶乘截断的正误差趋零否定有理性；用同一列频率把小除数本身作为系数构造一个光滑零均值 F，任何解被迫有无限多 Fourier 系数为1，故连 L² 解也不存在。
