# MG-GF108　参考答案与判卷

数学自查完成；人工复核待完成。本文件是私有判卷材料，不进入候选投影。新扩展义务的 Lean 核验以本组 `contract.json` 和实际新增编译记录为准，旧题的编译证据不能覆盖本组新增义务。

采用逐阶段判卷：每一阶段须满足所有 required_evidence 且不触发任一关键错误；数学分数、语义对齐、Lean 编译分别记录。完整有效的替代论证、等价表示及不同正确 Mathlib API 均可接受。某一步的错误可以影响依赖它的后续结论，但后续独立有效的重新证明仍按本阶段证据给分。整组 pass 必须各阶段均通过。

## S1　正且有下界的权重

v_n≥1 给 v_n>0，逐点消去非零 v_n 得两个逆等式，分配律给线性。因 |v_n|=v_n，v_n^r|v_n f_n|=v_n^(r+1)|f_n|，直接给同 C 估计。Rapid 在第 r+1 阶选择 C≥0 后得到输出第 r 阶。

必需证据：证明 T_v、S_v 互逆及 S_v 线性；证明精确加权恒等式和一阶同常数控制；证明 Rapid_v(f)→Rapid_v(S_v f)。

关键错误：不保留给定 C；仅证明某个固定 r 或有限支撑情形。

## S2　原权重的完整目标

w_n≥1，S1 全部适用。两个逆与线性在所有序列成立；若 T_w u=f，施加 S_w 并用 S_w T_w=id 得 u=S_w f，所以唯一性也不受 Rapid 限制。Rapid 是另一个保持性质。估计输入准确为 Control_w(r+1,C,f)，输出为 Control_w(r,C,S_w f)。这完整保留原题的最弱条件目标。

必需证据：特化 S1 到 w；证明 T_w u=f 的唯一解为 S_w f；保持一阶而非二阶输入并输出全部原目标。

关键错误：仍要求 InputControl 原二阶接口；把唯一性只限于 Rapid 解。

## S3　取消统一正下界

四项均仍成立。互逆只用每个 v_n 非零，绝对值恒等式只用逐点正性；Rapid 保持只从 r+1 阶取常数，未用阶数单调性。不得附带声称 T_v 也保持 Rapid_v：例如 v_n=1/(n+1)，常值 f=1 满足 Rapid_v（每阶取 C=1），T_v f=n+1 不满足第 0 阶有界，因此非 Rapid_v。这一补充界定证明范围，不是本阶段主结论的反例。

必需证据：判断 S1 的互逆、线性、一阶估计及 S_v 的 Rapid 保持是否仍成立；指出每个证明实际所用的正性范围；不额外声称 T_v 必保持 Rapid_v。

关键错误：误用控制阶数单调性来要求 v≥1；在无下界时增加未要求且可能假的 T_v 保持结论。

## S4　允许零权重的逆问题

不是。实数中 u_n0/0=0，所以若 f_n0=1，任何 u 都不能满足 T_v u=f，S_v f 也不是其解。若 f=0，则 u=0 与仅在 n0 取 1 的尖峰都经 T_v 变成 0，解不唯一。于是 S_v T_v 在该尖峰处输出 0 而非 1。非负权重的加权乘法恒等式仍可成立，但不提供除法的可逆性。

必需证据：判断双侧逆是否仍成立；给出零位置和具体序列否定至少一个逆等式；解释存在性、唯一性失效的不同表现。

关键错误：把乘法恒等式成立误当成除法可逆；忽略 Lean 中除以零的值。

## S5　常数为零的原估计端点

成立。w_n^r>0，而 0≤w_n^r|f_n|≤0，所以 |f_n|=0，逐点 f_n=0。于是 Sf=0，目标控制为 0≤0。该结论是 C=0 的端点；正 C 时尖峰可使零阶输出任意大，不能据此推一般零损失。

必需证据：证明 f=0；证明 Control_w(r,0,S_w f)，无需增加阶数；解释端点不推出一般 C 的零损失估计。

关键错误：把 v 有零点的 S4 结论继承到原 w；从 C=0 的特殊情况推广任意正 C。

## S6　修复原接口并实现扩展

原 InputControl=Control(r+2,C,f) 必须改为精确一阶，或删除该别名直接接收 Control(r+1,C,f)；Result 的估计字段保留原结论，构造使用乘法恒等式。逆、唯一与线性不应被削弱。扩展引理以 v>0 为互逆/正权估计的充分条件；S1 由 ≥1 推正性，S3 直接调用较弱引理，S4 单独构造零点尖峰，S5 逐点用严格正权重消去。标准答案应将这四种范围写在不同定理参数中，不能靠全局强假设隐匿变化。

必需证据：提交 Core.lean、Multiplier.lean、Candidate.lean、Extensions.lean；原候选完整恢复一阶同 C 估计及其它原目标；Extensions 完整实现 S1、S3、S4、S5 的结论及反例；实际共同编译与公理审计。

关键错误：将 InputControl 只改名而仍含 r+2；在全文件默认 v≥1 导致 S3 名不副实；靠假设可逆来规避零点反例。
