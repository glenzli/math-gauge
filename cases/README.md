材料已具数学参考、逐项判准、来源及AI审核记录；全部为 **draft / human pending**。`draft` 是待人工审定的生命周期状态。当前没有候选模型答卷或通过率。

题面与附件由共享runner按 `case.json` 显式投影；本目录、分类、参考、评分和审核记录均为出题侧材料。
