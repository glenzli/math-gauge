# 参考结论

第一断言成立。取 L∈C(V)，每对 x,y∈U 都属于 V，故同一矩阵的每条上界仍成立，
所以 L∈C(U)。这里固定并沿用同一个见证矩阵。□

第二断言不成立。取 I={1}、X={a,b,⊥}，非吸收部分采用离散距离 1，
吸收距离为 ∞。令 φ(a)=φ(b)=a，φ(⊥)=⊥，U={a}、V={a,b}。
所有非负标量都是两域上的合法证书，故 L_U=[2]、L_V=[1] 都合法，但 2≤1 为假。
反例的伪度量公理由离散距离及隔离吸收元直接验证。□

## 边界核对

第一个包含不是“最优证书存在”的结论，不允许把证书族的包含偷换为任意选择的数值比较。
第二断言甚至在有限值、有限集合和严格子域上失败。
