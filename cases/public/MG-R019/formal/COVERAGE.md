# MG-R019 actual-object formal coverage

The version 0.4.0 target is true and has two structural stages. `UltrafilterAlgebras.lean` begins with an actual map `Ultrafilter X → X` and exactly the two supplied equations. It constructs a topology on the same X, proves compactness and Hausdorffness, identifies the exact convergence relation, proves both object round trips, and identifies every map. The critical closed-kernel proof uses no topology on X. `ProfiniteReflection.lean` then constructs the actual universal profinite quotient and identifies its exact finite algebra observation fibres.

The finite skeleton and arbitrary finite universes are both covered: the reverse implication uses only the `Fin n` tests (in fact a two-value test), whereas the forward implication and factorization theorem handle every finite A in every universe. Consequently equality on the skeletal tests forces equality on all finite algebra observations. Conversely equality on all finite observations includes the skeletal tests. This is the exact all-finite-set criterion of the task, without replacing it by an unrelated model.
