# 出题设计（不向候选提供）

本稿是 MG-R020 相关矩阵题的第四个本地诊断版本，版本 0.4.0 不代表正式 suite 或 Release 的变更。保留正秩坐标块、Z2 上原始交换对称输入、模 2O 接近单位及原始同时分块目标。

本轮改为比较两个全分歧二次扩张 Q2(i)、Q2(sqrt2)。它们具有相同的剩余次数、分歧指数以及总计数、固定点计数，却在模4的固定矩阵类描述上不同。Q2(i) 中固定类的基域系数部分可以只属于 C 而不属于 R；Q2(sqrt2) 没有这一额外模4耦合。固定有限类可以是真解截断，却不能延长为下一层仍固定的类。由此产生最优的一位近似下降损失。

候选只见原始结构、域、集合定义和三个最终交付目标。题面未提供：幂等精确化、第一阶障碍、Artin–Schreier、列范数多一位判据、固定环展开、模4异常、图的度数耦合、Cayley 或二项式修正、最优损失的答案及证明顺序。三项是交付范围，不是解法步骤。必要的域和理想定义不能作为提示删除。

用户追加要求隐藏题内解题思路后，作者在冻结前逐句审核 task.md；所有方法、异常提醒及路线解释只留在本文件、reference.md 和 rubric.json。不是用隐藏评分要求增加难度：最终目标、所有量词和精度范围均在候选题面明示。

作者参考可按十个依赖环节组织，但不声称证明至少十步，更不按是否沿作者路线评分。新题只有一个相关数学家族；一次实考不能证明模型的一般能力上限。
