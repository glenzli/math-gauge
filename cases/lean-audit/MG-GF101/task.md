# MG-GF101　商环塔、幂零性与分离条件

版本 0.1.1。

设 R 是任意交换含幺环，A、B、I 是其理想，q_B:R→R/B 是商映射。对 n∈ℕ 令 Q_n=R/I^(n+1)，q_n:R→Q_n，J_n=q_n(I)。若 m≤n，令 ρ_mn:Q_n→Q_m 为商映射诱导的环同态。理想的 0 次幂按单位理想处理；允许零环、零理想和单位理想。
附件 Core、Transfer、Candidate 中的 `SourceData I` 含某个 e∈ℕ 及 `I^e=⊥`；文件中的其余定义以源码为准。本组须审查其对题面数学命题的覆盖范围。

逐阶段提交答案。后续可以引用已经证明的结论，但须明确引用的是哪条结论，并核对它的全部条件。判断题须先给结论；成立时给证明，不成立时给出满足本阶段全部条件的反例。每个阶段均须作答。

本组交付逐阶段书面论证、源码语义审计及题面要求的数学修复路线；无需提交新增或修复后的 Lean 源码。

固定环境：Lean 4.29.1（提交 `f72c35b3f637c8c6571d353742168ab66cc22c00`），Mathlib 提交 `5e932f97dd25535344f80f9dd8da3aab83df0fe6`。附件仅包含下列输入文件：`Core.lean`, `Transfer.lean`, `Candidate.lean`。

## S1　商映射下的幂零判据

证明对任意 r∈ℕ，(q_B(A))^r=0 当且仅当 A^r⊆B。说明该等价在 r=0 时的含义。

## S2　任意理想的有限层

在以上最一般条件下证明 J_n^(n+1)=0、ρ_mn(J_n)=J_m，以及 l≤m≤n 时 ρ_lm∘ρ_mn=ρ_ln。须说明所有映射存在的理由。

## S3　过渡映射的核

证明 ρ_mn 满射并计算其核。进一步给出 ρ_mn 是环同构的关于 R 中两个理想的充要条件。

## S4　统一有限层界

现已知存在一个固定 N，使每一层都满足 J_n^N=0。判断这是否必然推出 I 是幂零理想。

## S5　分离条件下的统一次数

再假设 ⋂_{n∈ℕ} I^(n+1)=0。判断并论证：对每个固定 N，条件“所有 n 均有 J_n^N=0”等价于“I^N=0”。

## S6　完整输入的语义审计

以 S2 为目标，审计附件的全部声明。给出每一项目标的覆盖结论、所需假设及结论强度；若有差距，给出严格的数学修复路线。另说明 S4、S5 是否改变对原目标的审计结果。
