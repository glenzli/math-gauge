# MG-GF109　参考答案与判卷

数学自查完成；人工复核待完成。本文件是私有判卷材料，不进入候选投影。新扩展义务的 Lean 核验以本组 `contract.json` 和实际新增编译记录为准，旧题的编译证据不能覆盖本组新增义务。

采用逐阶段判卷：每一阶段须满足所有 required_evidence 且不触发任一关键错误；数学分数、语义对齐、Lean 编译分别记录。完整有效的替代论证、等价表示及不同正确 Mathlib API 均可接受。某一步的错误可以影响依赖它的后续结论，但后续独立有效的重新证明仍按本阶段证据给分。整组 pass 必须各阶段均通过。

## S1　精确记录下的安全核

T_(n+1)⊆T_n。若前 |B|+1 次都严格下降，就使非负基数从 |B| 至少下降 |B|+1 次，矛盾；一旦相邻相等，由递推后续恒等，故 T_|B|=T_(|B|+1)，得到固定点式。若 x 安全，安全轨迹始终在 A，精确记录可逐次应用，q(f^n x)=g^n(qx) 都在 B，所以 qx∈每个 T_n，特别 T。若 qx∈T，固定点式与精确记录使 q(f^n x)∈T⊆B 归纳成立，所以 x 安全。K⊆A 由 n=0，f(K)⊆K 由移位；任何 S⊆A 且 f(S)⊆S 的点所有迭代仍在 S，所以 S⊆K。

必需证据：证明 T_n 在 |B| 步稳定且 T={y∈B:g(y)∈T}；证明 K=q⁻¹(T)；证明 K 为包含于 A 的最大 f 前向不变集。

关键错误：将精确条件只验证第一步而不使用安全轨迹保证后续仍在 A；把最大不变集定义改成单步留在 A。

## S2　允许停留的原条件

不成立。取 X=Y={0,1}，B={0}，q=id，f=id，g 恒取 1。对 x=0 有 q(fx)=q(x)，故弱条件成立。K={0}，而 T_1={y∈{0}:g(y)∈{0}}=∅，|B|=1 所以 T=∅。精确条件在 x=0 要求 0=1，不成立。这就是旧题最弱条件下的否定核心。

必需证据：判断 K=q⁻¹(T) 是否仍成立；逐项验证弱条件、K 和 T 的有限反例；明确反例并未满足精确记录条件。

关键错误：默认每个停留最终结束；只说不交换却不展示错误结论。

## S3　弱条件下保留的方向与最大性

若 qx∈T，则 qx∈B，可用弱条件；q(fx) 或等于 qx∈T，或等于 g(qx)∈T。因此 q⁻¹(T) 在 f 下前向不变且含于 A，归纳得到安全性。任意 K 的定义直接给 K⊆A 和移位不变性。若 S⊆A 且前向不变，归纳 f^n x∈S⊆A 对 x∈S 的所有 n 成立，故 S⊆K。后半完全不依赖 q 与 g 的一步关系。

必需证据：证明 q⁻¹(T)⊆K；证明 K⊆A 且 f(K)⊆K；证明任意 S⊆A、f(S)⊆S 有 S⊆K；注明最大性不需要弱记录条件。

关键错误：把可靠内近似错误称为等于安全核；把不变性仅写成 q 层面。

## S4　安全轨道上的迟延实现

恢复。S3 已给 q⁻¹(T)⊆K。证明对每个 n，所有 x∈K 都有 qx∈T_n。n=0 由安全性。假定第 n 层成立；给 x∈K，选所给 k，f^k x 仍安全（安全轨迹的尾部），因此 q(f^k x)∈T_n。该值等于 g(qx)，又 qx∈B，所以 qx∈T_(n+1)。到 n=|B| 得 K⊆q⁻¹(T)。证明不需要统一 k，也没有把每一步都假设为推进。

必需证据：判断该条件是否恢复 K=q⁻¹(T)；证明安全核对任意正整数迭代封闭；通过逐层归纳证明 K 的记录属于每个 T_n；不引入统一迟延界或全域精确交换。

关键错误：把迟延实现擅改为下一步精确交换；未证明迟延后的状态仍安全。

## S5　安全核相等能否反推精确记录

不必。取 X=Y=Bool，B=Y，q=id，f=id，g 为交换两点的映射。弱条件由停留支成立。所有点的真实轨迹安全，K=X；g(B)⊆B，所有层 T_n=B，故 q⁻¹(T)=X。精确记录却要求 x=g(x)，在每点失败。相等的安全集合不确定每一步的观测动力学。S4 也是充分条件，本例甚至不满足其迟延实现。

必需证据：判断该相等是否必推出精确记录；给出 K 与 T 明确且等式成立的反例；验证精确记录在某点失败。

关键错误：把一个充分条件误作必要条件；沿用 S2 中等式本来失败的反例。

## S6　源码假设的逐层审计

整体不对齐。RecordLayers 的下降、有限稳定和 terminal_mem 只依赖有限 B，正确可用。OrbitModel.Realizes 是 q(fx)=g(qx)，比题面允许停留强；safe_in_layers 和 exact_realization 用此强条件，不能把其证明搬到 S2。原最大不变集表述若把 q⁻¹(T) 当成 K，同样需要反向覆盖，S2 反例否定。S3 可另证真实 K 的最大性及 q⁻¹(T) 的可靠性；S4 的迟延条件足够恢复等式，但原条件未给它。编译通过说明强条件实现有效，不说明弱题面对齐。

必需证据：指出 Realizes 实为精确交换；分别检查稳定层、正反安全方向和最大性定理；给出弱条件下可保留结论与不可保留等式；不把新增迟延条件当成原始输入。

关键错误：把名为 Realizes 的参数当作题面弱条件；漏掉正向内近似仍正确；从 S5 等式反推出不具备的精确交换。
