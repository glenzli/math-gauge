## S1　正有限分母域

对每个 x，0<d(x)<∞ 保证 e(x)≤c d(x) 当且仅当 e(x)/d(x)≤c，包括 e 或 c 为∞的情形。对所有 x 取合取等价上确界≤c。空 X 的 r=0，Bound 对所有 c 真，0≤c 也总真。c=0 时约束 e=0；c=∞ 时正分母乘∞为∞，均吻合。

必需证据：证明 Bound(c)↔r≤c；检查 c=0、c=∞ 及空 X；给出除法不等式所需非零有限条件。

关键错误：在 d=0 或∞ 时无条件使用除法等价；误把 c 限制成正有限。

## S2　加入零分母点

在 d=0 点，c·d=0 对所有 c（含∞）成立，所以必须且只需 e=0，即 Z。在其它点用 S1 的除法等价，上确界正是题面 r。因此 Bound(c)↔Z∧r≤c。

必需证据：证明 Bound(c)↔Z∧r≤c；证明零分母分支与 c 无关；保留 c=∞。

关键错误：用 c=∞ 掩盖零分母处正 e；遗漏 ENNReal 的∞·0=0。

## S3　完整域与最小值取得

零分母给 Z，正有限分母给 r≤c。d=∞ 时，c=0 使乘积为0，要求 e=0，即 H；c>0 时乘积为∞，无额外要求。故总分类为 Z∧r≤c∧(c=0→H)。若有有限 c，则 Z 且 r≤c<∞；反向若 Z 且 r<∞，取 c=r+1，正且有限，故可行。若 r 有限且 r=0→H，则 r 本身可行，所有可行系数≥r，故最小。反之若有限最小 c 存在，已有 Z、r<∞；若 r<c，取 r<b<c 的有限正 b（严格稠密性，r≥0），由分类 b 可行，与最小性矛盾。因此 c=r，若 r=0 则可行性迫使 H。这是原题完整最弱范围。

必需证据：证明 Bound(c)↔Z∧r≤c∧(c=0→H)；证明有限系数存在 iff Z∧r≠∞；证明有限最小值存在 iff Z∧r≠∞∧(r=0→H)，且值为 r。

关键错误：把正系数时∞分母分支的规则延伸到 c=0；把下确界为 r 等同 r 自动可行；只证明存在性而漏最小值分类。

## S4　每个有限子域可控

不必。X=ℕ，d(n)=1，e(n)=n（嵌入 ENNReal）。任意有限 F 可取其元素最大值（空集取0）为有限 c_F。若全域有限 c 存在，需 n≤c 对所有自然数 n，违反 Archimedean 性；因此 r=sup_n n=∞。所有点都处在 S1 的良好分母域，失败源于缺少统一界而非端点。

必需证据：判断全域是否必存在有限系数；给逐有限子域可行而全域不可行的反例；验证每个有限子域的有限界与全域 r=∞。

关键错误：把任意有限子域量词换成单个共同 c；只展示某一个局部常数不够大。

## S5　统一有界的有限子域证据

是。对任意 x，取 F={x}，得到 e(x)≤c_F d(x)≤C d(x)，后一步是 ENNReal 乘法的单调性，在 d=0 或∞时同样成立。故 Bound(C)，且 C 已给有限。空 X 时结论真空成立。无需选择统一的 c_F，也不必让任何局部下确界取得。

必需证据：证明 Bound(C)；只使用单点子域与乘法单调性即可；处理 X 为空及 d=0、∞ 的边界。

关键错误：错误要求 c_F 必相同或最小；在∞分母边界使用非法除法。

## S6　完整分类代码审计

附件对 S3 完全对齐：regular 子类型精确排除 d=0、∞；bound_iff 分开 Z、比值上界及 c=0 时 H；有限存在取正的 r+1；最小值通过排除 r<c 与 r 端点可行性得到。Unit 取 d=∞、e=1 时 r=0，所有正有限 c 可行，c=0 不可行，因此有有限界而无最小界。S4 的每个有限子域存在不是全域有限存在；S5 新增共同 C 后才成立。这些新命题不在原声明中，不能用旧编译报告冒充新增形式化。

必需证据：核对上确界仅在正有限分母子类型上取；核对所有 c 与有限/最小分类；核对 Unit 无限分母正分子例子的未取得最小值；说明 S4/S5 不由旧编译自动覆盖。

关键错误：把无限分母点加入通常 e/d 上确界而漏零系数条件；要求 X 有限或非空；把 finite_exists 与 least_exists 混同。
