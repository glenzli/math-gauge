# 完整参考论证与失配证据

定义 $(Sf)_n=w_nf_n$。由于 $w_n=n+1>0$，逐点消去分母得到 $T(Sf)=f$ 与 $S(Tu)=u$；若 $Tu=f$，后一等式给 $u=Sf$。逐点分配律给 $S(f+g)=Sf+Sg$ 和 $S(af)=aSf$，故此逆在全部实序列上唯一且线性。

对每个 $r,n$ 有精确恒等式
$$w_n^r|(Sf)_n|=w_n^r|w_nf_n|=w_n^{r+1}|f_n|.$$
因此输入 `Control (r+1) C f` 立即给输出 `Control r C (S f)`，常数仍为原来的 $C$。若 $f$ 快速衰减，对任意输出阶 $r$ 选取输入阶 $r+1$ 的控制，便得到 $Sf$ 快速衰减。参考中的 `weighted_identity`、`control_solve`、`complete` 实现这一点，`complete` 只接收题设给定的一阶输入控制，不接收额外估计证书。

## 输入程序实际完成了什么

输入中的 `transport_solve`、`solve_transport`、`solution_unique`、`solve_add`、`solve_smul` 对应逆、唯一性和线性，均无问题；`rapid_solve` 也正确，因为快速衰减数据在所有阶都有控制。失配只在固定阶、固定常数的对外估计：`InputControl r C f` 展开为 `Control (r+2) C f`，`candidate` 将它交给 `control_solve_buffered`。后者先向下弱化一阶，再做乘子估计。因此原接口只保证两阶输入损失，并未给题面要求的一阶估计。

不能说两阶前提自动由一阶前提推出。取 $r=0,C=1$，序列 $f_1=1/2$，其余项为零。它满足 `Control 1 1 f`，却不满足 `Control 2 1 f`：在 $n=1$，两边分别是 $1$ 和 $2$。`witness_input` 与 `witness_extra_fails` 形式化此差异。该序列也是快速衰减的（每个阶取 $C=2^r/2$），所以额外给快速衰减假设不能修复固定常数的接口。

这个例子证明新增前提不由目标的前提推出，而不是证明目标错误；目标已由上面的精确恒等式证明。原程序中出现的局部代数等式可以用于修复，允许复用其正确部分；原来的公开定理接口仍然需要修订，不能把可补出的新声明视作原声明已经包含。

## 可选的最优阶数核对（不是必答义务）

不存在统一 $C$ 使所有 `Control 0 1 f` 均满足 `Control 0 C (Sf)`。否则取只在第 $N$ 项等于 $1$ 的序列，输出第 $N$ 项为 $N+1$，而 $N$ 可大于 $C$。参考 `no_uniform_zero_loss` 给出此证明。它说明一阶损失在这套整数加权尺度上确实必要，但本题判分不额外要求候选证明该旁支。

本题是受公开正则性阶数差异启发而独立构造的序列乘子题。没有将序列叫作真实环面函数，没有声称编码 PDE、证明 Navier–Stokes 结论，或复现外部模型答卷。误配的输入代码由本题作者有意制作，并非公开 OpenAI 工程的原文件。
