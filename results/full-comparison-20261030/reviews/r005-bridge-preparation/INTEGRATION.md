This temporary artifact is a focused Lean build, not a new benchmark release. The original frozen case, catalog, manifest, coverage, runner and model results were not edited. No candidate model was run.

`ClarifiedMaximality.lean` contains the new theorem `MathGauge.ConvexCost.reconstruct_maximal_ereal_of_isClosed_real_epigraph` and a refactoring of the existing `reconstruct_maximal_ereal` into its corollary. The temporary module deliberately imports `FiniteObservation`, not `ConvexCostExtras`, so the original theorem name can be checked without duplicate declarations. Do not import this whole module alongside the existing `ConvexCostExtras` unchanged. For the future new-version copy, replace the old theorem/comment block inside `ConvexCostExtras.lean` with the two theorem blocks. Its existing imports and remaining definitions can stay unchanged.

The new premise is exactly `IsClosed {p : E × ℝ | h p.1 ≤ (p.2 : EReal)}`. Thus it connects the new visible real-height epigraph convention directly to the current reconstruction. It does not require properness, nonnegativity, exclusion of either infinity, or convexity of h. Omitting the last assumption is a valid strengthening for convex f, not a change to the candidate obligation. The finite-G/top-G split is retained before any use of `toReal`.

The existing f/G type `ℝ≥0∞`, actual finite observation records and reconstruction are unchanged. `ConvexCost f` is the existing real epigraph convexity; `convexCost_of_jensen` preserves the original lower-semicontinuity interface. Real epigraph closedness and Lean `LowerSemicontinuous` are mathematically equivalent for EReal-valued functions, as explained in the semantic plan. No separate equivalence lemma is necessary when this direct wrapper is used.
