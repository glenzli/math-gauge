  * **构造层证明**（[domain_refinement_construction.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/formal_oet/vol_01/ch_05_operator_networks/domain_refinement_construction.lean#L184-L269), [domain_refinement_construction.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/formal_oet/vol_01/ch_05_operator_networks/domain_refinement_construction.lean#L449-L497)）：由 `coloured_terminal`、`coloured_eval` 与删冗余节点保外延性质证明全域算子等式 `P.network_extensional_eq : P.network.extensional_operator = N.extensional_operator`，并由 `P.network_refinement : NodeDomainRefinement N P.network` 与 `P.allowed_network_refinement : NetworkRefinement N P.network` 接入关系层定理。

#### （二）需要补充的衔接内容、数学影响与修复方向

尽管核心定义与证明无数学漏洞，以下四项衔接结论在当前源码中尚未作为显式声明给出：

1. **关系层全域外延算子相等与 `ExtensionalEquivalent` 显式推论**
   * **现状**：构造层已证全域相等 `P.network.extensional_operator = N.extensional_operator`，但关系层 `network_refinement.lean` 仅给出正文公式对应的 `LocalEquivalent N'.extensional_operator N.extensional_operator N.U` 与 `same_input_domain : N'.U = N.U`，未显式封装同章 [effective_equivalence.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/formal_oet/vol_01/ch_05_operator_networks/effective_equivalence.lean#L1181-L1184) 定义的 `FiniteOperatorNetwork.ExtensionalEquivalent N' N`（对应命题标题“保持外延等价” $\mathcal N'\sim_{\mathrm{op}}\mathcal N$）及全域等式 `N'.extensional_operator = N.extensional_operator`。
   * **数学影响与可复核论证**：对任意 $x\in X$，若 $x\in N.U$，由 `same_input_domain` 知 $x\in N'.U$，再由 `refinement_preserves_local_equivalence` 得两外延算子在 $x$ 处相等；若 $x\notin N.U$，则 $x\notin N'.U$，两外延算子按定义均取 `bot`。因此全域等式与 `ExtensionalEquivalent` 必然成立；缺少该封装仅使下游基于抽象 `NodeDomainRefinement` 改写全域外延算子时需手动补证域外 `bot` 分支。
   * **修复方向**：在 `network_refinement.lean` 中补充 `NetworkRefinement.extensional_operator_eq` 与 `NetworkRefinement.extensional_equivalent` 两条推论（结合 `Operator.ext`、`same_input_domain` 与 `refinement_preserves_local_equivalence` 即可在数行内完成）。

2. **`NodeDomainRefinement` 的重编号不变性与逆向唯一性刻画定理**
   * **现状**：源码证明了正向包含 `NodeDomainRefinement N P.network`，但未显式写出：（a）若 `NodeDomainRefinement N N'` 成立且 `e : V' ≃ W` 为节点双射（如编号编码 `standard_node_equiv`），则 `NodeDomainRefinement N (N'.relabel e)` 成立；（b）反之，任意满足 `NodeDomainRefinement N N'` 的 `N'` 必存在唯一双射 `e : V' ≃ {w : P.Label // P.presentation.Reached w}` 使 `(N'.relabel e).presentation_data = P.network.presentation_data`。
   * **数学影响与可复核论证**：
     * 逆向唯一性保证关系定义 `NodeDomainRefinement` 绝无多余模型：由 `source_injective`、`old_node_present`、`piece_node_present_iff_reached` 对接 `P.old_label_reached` 与 `P.piece_label_reached_iff`，映射 `v ↦ ⟨h.source v, ...⟩` 给出双射 $e$；再由 `old_node_op_compat`、`piece_node_op_compat`、`entry_domain_eq` 与 `edge_domain_eq` 逐项比对 `U`、`node_op`、`entry_domain`、`edge_domain`，即得 `(N'.relabel e).presentation_data = P.network.presentation_data`（已在 Lean 4.29.1 中完整机验通过）。
     * 重编号不变性则是将构造出的子类型标签网络 `P.network` 经 `standard_relabel` 编码为 `Fin n` 网络后仍保持 `NodeDomainRefinement` 见证的直接桥梁。
   * **修复方向**：在 `domain_refinement_construction.lean` 或 `network_refinement.lean` 中补充 `NodeDomainRefinement.relabel` 与 `NodeDomainRefinement.relabel_presentation_data_eq_constructed`。

3. **向编码网络对象空间 `NetworkObject X bot`（$\mathcal X_{\mathrm{net}}$）及 `IrreducibleRepresentative` 的提升接口**
   * **现状**：正文（[source.md](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/source.md#L298-L301)）指出域加细先用不交并/子类型作标签，作为对象空间 $\mathcal X_{\mathrm{net}}$ 元素使用时再作编号编码。在 [network_refinement.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/formal_oet/vol_01/ch_05_operator_networks/network_refinement.lean#L512-L518) 中，`IrreducibleRepresentative` 的规则参数类型为 `RefinementRule (NetworkObject X bot)`，而同文件的 `NodeDomainRefinement` / `NetworkRefinement` 定义在具体标签类型 `FiniteOperatorNetwork X bot V` 上，尚未提供提升到 `NetworkObject X bot` 的关系定义与外延等价保持定理。
   * **数学影响与可复核论证**：由于 `NodeDomainRefinement` 要求存在 `target : V`，输入域 $U$ 必非空，加细前后均对应非空网络对象（不涉及 `NetworkObject.empty`）；且 `NodeDomainRefinement` 仅依赖 `PresentationData`（`U`、`node_op`、`entry_domain`、`edge_domain`，其中实际输入域与入口路由均由 [network_identity.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/formal_oet/vol_01/ch_05_operator_networks/network_identity.lean#L43-L99) 证明由 `PresentationData` 唯一决定），故在商类型 `Quotient NonemptyOperatorNetwork.data_setoid` 上良定义。但若不补充该提升定义，尚无法直接将 `NodeDomainRefinement` 作为具体 `R : RefinementRule (NetworkObject X bot)` 传入 `IrreducibleRepresentative`。
   * **修复方向**：在 `NetworkObject` 命名空间中定义一步节点域加细关系（存在非空编号代表元 `N₀, M₀` 使 `N = nonempty N₀`、`M = nonempty M₀` 且 `Nonempty (NodeDomainRefinement N₀.network M₀.network)`），并结合上述全域算子相等推论证明 `NetworkObject.ExtensionalEquivalent M N`。

4. **求值深度保持与删点前终止域公式的独立引理封装**
   * **现状**：正文证明（[source.md](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/source.md#L1133-L1136), [source.md](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/source.md#L1166-L1170)）给出了删点前子节点终止域公式 $T'_{\beta_a}=f_{\beta,a}(U_{\beta,a})\cap T_\beta$ 及求值深度界 $r'\le\ell(\mathcal N)$（实际上每条路径长度不变，故 $\ell(\mathcal N')=\ell(\mathcal N)$）。源码通过 `choice` 直接完成终止路径归纳，已证逐点路径长度不变（`colour_path_length` 与 `NodeDomainRefinement.path_projection`）并沿用 `depth_bound := N.depth_bound`，但未单独写出 `N'.evaluation_depth = N.evaluation_depth`（基于 [operator_network.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/formal_oet/vol_01/ch_05_operator_networks/operator_network.lean#L655-L658) 的实际求值深度）。
   * **数学影响与修复方向**：不影响外延等价主定理；若后续章节在加细终止性分析中需调用实际求值深度不变性，可仿照 [network_relabeling.lean](file:///private/tmp/math-gauge-carbon-medium-parallel2-lane2-20261114-v4/attempts/AHR03/physical-1/session/work/formal_oet/vol_01/ch_05_operator_networks/network_relabeling.lean#L218-L226) 的 `relabel_evaluation_depth`，由 `NodeDomainRefinement.path_projection` 直接推出 `N'.evaluation_depth = N.evaluation_depth`。
