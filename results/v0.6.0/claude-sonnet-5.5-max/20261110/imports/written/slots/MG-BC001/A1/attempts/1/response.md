# 结果与对前期结论的更正

**前期结论需要更正。** 六个行列式 −4, −5, 9, 3, 5, −8 我核对无误，K 中任意两井确实没有秩一连接。但由此推出"零边界下没有能量趋零的混相序列、单元能有严格正间隙"是错的。两两不相容只排除两相层合和精确解（E(u)=0），不排除经过中间矩阵的高阶（此处是无穷阶）层合。四相能量 min_{i≤4} 也不能拆成二相刚性估计之和。

把 diag(a,b) 记作 (a,b)。K 是 Tartar 型 T4"风车"：A₁=(3,0)、A₂=(1,2)、A₃=(−2,1)、A₄=(0,−3) 依次落在单位方块 [0,1]² 的底边、右边、顶边、左边所在直线的延长线上，0 是方块的一个角点。

结论如下。

1. **e₀ = 0，且对一切 u∈𝒜 有 E(u)>0，所以不被任何 u 达到。**
2. **必然收敛，唯一可能的极限是 λ\* = (1/10, 3/10, 3/10, 3/10)。** 定量形式：对一切 u∈𝒜，max_i |π_i(u) − λ\*_i| ≤ 2(E(u)^{1/2} + E(u))。
3. 下面第 3 节给出显式位移 u_N∈𝒜，满足 ‖∇u_N‖_F ≤ √10 < 4，E(u_N) ≤ 149·6^{−N}，π(u_N)→λ\*。

## 0. 预备事实

|·| 为 Frobenius 范数。|A₁|=|A₄|=3，|A₂|=|A₃|=√5，det A_i = 0, 2, −2, 0，E(0)=min_i|A_i|²=5。

u∈𝒜 取 Lipschitz 代表（Ω 凸），在 ∂Ω 上为 0。零延拓 ū 是 R² 上的 Lipschitz 函数：对 x∈Ω、y∉Ω，线段 xy 交 ∂Ω 于 z，则 |ū(x)−ū(y)| = |u(x)−u(z)| ≤ L|x−y|。

- **(F1)** ∫_Ω ∇u = 0。理由：∫_{R²} ∂_jū_i = 0（Fubini 加沿直线的绝对连续，ū 紧支集）。
- **(F2)** ∫_Ω det∇u = 0。对光滑紧支撑 v 有 det∇v = ∂₁(v₁∂₂v₂) − ∂₂(v₁∂₁v₂)，积分为 0。取 v = ρ_η∗ū，则 ∇v 一致有界且几乎处处收敛到 ∇ū，由控制收敛得 ∫det∇ū = 0。
- **(F3)** 对 2×2 矩阵，det(Y+Z) = det Y + ⟨cof Y, Z⟩ + det Z，|cof Y|=|Y|，|det Z| ≤ |Z|²/2。故 |det X − det Y| ≤ |Y||X−Y| + |X−Y|²/2。
- **(F4)** 对 u∈𝒜 令 d(x)=min_i|∇u−A_i|=|∇u−A_{i(x)}|（i(x) 按题面规则取最近井，可测），Y(x)=A_{i(x)}。则 ∫d² = E(u)，∫d ≤ E^{1/2}（|Ω|=1），π_i=|{i(x)=i}|，Σπ_i=1。

## 1. 不可达

**引理 1.** 对 u∈𝒜，‖u‖²_{L²} ≤ E(u)。

*证明.* A_i 是对角阵，所以 ∇u−A_i 的非对角元就是 ∂₂u₁ 与 ∂₁u₂。因此几乎处处 |∂₂u₁|²+|∂₁u₂|² ≤ d²，积分得 ∫(|∂₂u₁|²+|∂₁u₂|²) ≤ E(u)。

对几乎每个 x₁，s↦u₁(x₁,s) Lipschitz 且 u₁(x₁,0)=0，故
|u₁(x₁,x₂)|² ≤ (∫₀¹|∂₂u₁(x₁,s)|ds)² ≤ ∫₀¹|∂₂u₁(x₁,s)|²ds。
积分得 ‖u₁‖² ≤ ‖∂₂u₁‖²。同理 ‖u₂‖² ≤ ‖∂₁u₂‖²。相加即得。∎

**推论 2.** 若 E(u)=0，则 u=0，从而 ∇u=0，于是 E(u)=E(0)=5≠0，矛盾。所以对一切 u∈𝒜 有 E(u)>0。

结合第 3 节的 inf E = 0，e₀=0 不可达。

## 2. 相体积分数唯一

**命题 3.** 对 u∈𝒜，设 E=E(u)，π=π(u)，则 max_i|π_i−λ\*_i| ≤ 2(E^{1/2}+E)。

*证明.* 记 Σπ_iA_i = diag(r₁,r₂)，其中 r₁=3π₁+π₂−2π₃，r₂=2π₂+π₃−3π₄。再记 r₃ := Σπ_i det A_i = 2π₂−2π₃。

(i) 由 (F1)，Σπ_iA_i = ∫Y = ∫(Y−∇u)，所以 r₁²+r₂² = |Σπ_iA_i|² ≤ (∫d)² ≤ E。

(ii) 由 (F2)，r₃ = ∫det Y = ∫(det Y − det∇u)。由 (F3) 及 |Y| ≤ 3，|r₃| ≤ ∫(3d+d²/2) ≤ 3E^{1/2}+E/2。

(iii) λ\* 满足 r₁=r₂=r₃=0 且 Σ=1。令 δ=π−λ\*，则 Σδ_i=0，且 (r₁,r₂,r₃) 是 δ 的同样线性函数。解这个 4×4 方程组（唯一解）：
- δ₁=(9r₁+r₂−7r₃)/30
- δ₂=(−r₁+r₂+3r₃)/10
- δ₃=(−r₁+r₂−2r₃)/10
- δ₄=(−3r₁−7r₂+4r₃)/30

把 |r₁|+|r₂| ≤ √2E^{1/2} 和 (ii) 代入，每个 |δ_i| 都不超过 1.1E^{1/2}+0.2E，故 ≤ 2(E^{1/2}+E)。∎

**说明.** 仅有重心条件 Σπ_iA_i=0 时，解是一条线段 π(s)=(s, 3(1−3s)/7, (12s+3)/14, (5−8s)/14)，s∈[0,1/3]。零拉格朗日量 det 给出额外关系 π₂=π₃，把它压成 s=1/10 一点。

因此对任何 E(u_j)→0 的序列，π(u_j)→λ\*。第 3 节的构造说明这个极限确实出现，所以极限集恰为 {λ\*}。

## 3. 近最优位移的显式构造

### 3.1 循环

记 C₁=(0,0)，C₂=(0,1)，C₃=(1,1)，C₄=(1,0)，C₅:=C₁。则：
- C₁=¾C₂+¼A₄
- C₂=⅔C₃+⅓A₃
- C₃=½C₄+½A₂
- C₄=⅔C₅+⅓A₁

每一对只差一个对角元，所以秩一连接：C₂−A₄=(0,4)，C₃−A₃=(3,0)，C₄−A₂=(0,−2)，C₅−A₁=(−3,0)。中间矩阵 C_j 不在 K 中，这正是前期"逐对检验"漏掉的地方。每转一圈，留在 0 的体积分数乘以 ¾·⅔·½·⅔ = 1/6。

第 s 步的类型 j=((s−1) mod 4)+1，数据如下，满足 C_j = θ_jC_{j+1}+(1−θ_j)A_{5−j}，C_{j+1}−A_{5−j} = t_j e_{k_j}⊗e_{k_j}：

| j | k_j | θ_j | t_j | D 段斜率 (1−θ)t | 井段斜率 −θt | 井 |
|---|---|---|---|---|---|---|
| 1 | 2 | 3/4 | 4 | +1 | −3 | A₄ |

### 3.2 单步细化引理

**引理 4.** 设 R=(α₁,α₁+ℓ₁)×(α₂,α₂+ℓ₂)，k∈{1,2}，k′=3−k，θ∈(0,1)，A、D 为对角阵，D−A=t e_k⊗e_k，|t|≤4，C=θD+(1−θ)A。设 ε∈(0,1)，δ=εℓ_{k′}/2，整数 m≥1 使 p:=ℓ_k/m ≤ δ。

令 ξ=x_k−α_k，r=ξ−p⌊ξ/p⌋，并定义
- g(x_k)=(1−θ)t·r（0≤r<θp），g(x_k)=θt(p−r)（θp≤r<p）；
- φ(x_{k′})=min{1, dist(x_{k′},{α_{k′},α_{k′}+ℓ_{k′}})/δ}；
- ψ(x)=g(x_k)φ(x_{k′})e_k。

则：

(a) ψ 在 R̄ 上 Lipschitz，在 ∂R 上为 0，且 ∇(Cx+ψ)=C+g′φ e_k⊗e_k+gφ′e_k⊗e_{k′}。

(b) 取 2m 个互不相交的开矩形：D 块 {ξ∈(jp,jp+θp)}，井块 {ξ∈(jp+θp,(j+1)p)}（j=0..m−1），都要求 x_{k′}∈(α_{k′}+δ, α_{k′}+ℓ_{k′}−δ)。在 D 块上 Cx+ψ 仿射、梯度为 D，在井块上梯度为 A。D 块总测度为 θ(1−ε)|R|，井块总测度为 (1−θ)(1−ε)|R|。

(c) 余集（测度 ε|R|，即 {φ<1}）上，梯度 = 对角部分 + 非对角部分。对角部分是线段 [A,D] 上的点。非对角部分只有一个分量 gφ′，|gφ′| ≤ p/δ ≤ 1。

*证明.* g 连续、分段线性，斜率在 D 段为 (1−θ)t，在井段为 −θt。一个周期内 (1−θ)t·θp − θt·(1−θ)p = 0，故 g(jp)=0，且 |g| ≤ θ(1−θ)|t|p ≤ p。

ψ 在 x_{k′} 方向的两条边上因 φ=0 而为 0，在 x_k 方向的两条边上因 g=0 而为 0，这给出 (a)。

在块上 φ=1。D−C=(1−θ)t e_k⊗e_k，A−C=−θt e_k⊗e_k，这给出 (b)。

(c) 中对角元 (k,k) 为 C_kk+φg′，即 C_kk 与 D_kk 或 A_kk 的凸组合，而 C_kk∈[A_kk,D_kk]；另一对角元三者相同。|gφ′| ≤ |g|/δ ≤ p/δ。∎

### 3.3 迭代

取整数 N≥1，ε=6^{−N}。令 𝓡₁={Ω}，并设 𝓡_s 的所有"胞"是边长相同的矩形。

第 s 步（类型 j，k=k_j）：
1. 设胞在 x_k、x_{k′} 方向的边长分别为 ℓ_k、ℓ_{k′}，取 δ_s=εℓ_{k′}/2，m_s=⌈ℓ_k/δ_s⌉，p_s=ℓ_k/m_s ≤ δ_s。
2. 对每个 R∈𝓡_s 用引理 4（C=C_j, D=C_{j+1}, A=A_{5−j}）得 ψ_R。
3. 𝓡_{s+1} 取为所有 D 块，它们仍是同形矩形，边长为 θ_sp_s（x_k 方向）和 (1−ε)ℓ_{k′}。

定义
**u_N := Σ_{s=1}^{4N} Σ_{R∈𝓡_s} ψ_R。**

第一步就是 u^{(1)}=(0, g₁(x₂)φ₁(x₁))：u₂ 沿 x₂ 做锯齿，斜率 +1 占 3/4、−3 占 1/4，在两侧各 δ₁=ε/2 的边界层里被 φ₁ 压到 0。

对 s 归纳可得：U_s:=Σ_{r<s}Σ_{R∈𝓡_r}ψ_R 在每个 R∈𝓡_s 上等于 C_jx+常数。理由是 D 块上 Cx+ψ_R 的梯度是 D=C_{j+1}，即下一步的起点。

### 3.4 验证

**(a) 零边界与 W^{1,∞}。** 每个 ψ_R 在 R̄ 上 Lipschitz 且在 ∂R 上为 0，零延拓后在 Ω̄ 上 Lipschitz。有限项求和后 u_N∈W^{1,∞}。∂Ω⊂∂R 的部分上 ψ_R=0，其余 ψ_R 在 R̄ 外为 0，所以 u_N|_{∂Ω}=0。

**(b) 梯度结构与统一上界。** 除胞边界这个零测集外，每个 x 在某步 s 停止下降，落入三类集合之一：
- 井块 W_s：∇u_N 恰为某个 A_i。
- 边缘 M_s：由引理 4(c)，对角部分在线段 [A, C_{j+1}] 上，非对角部分的分量绝对值 ≤ 1。
- 终胞 F=𝓡_{4N+1}：∇u_N=C₅=0。

这是因为更早的步 r<s 在 x 处贡献 D_r−C_r（x 在 D 块内），求和得 C_s−C_1，而更晚的步在 x 处无贡献。

线段 [A,C_{j+1}] 的端点范数 ≤ 3（井 3 或 √5，C_j 为 0、1、√2、1），范数凸，故对角部分范数 ≤ 3。于是 |∇u_N|² ≤ 9+1=10，即 **‖∇u_N‖_F ≤ √10 < 4**，该上界与 N、ε 无关，u_N∈𝒜。

把 p_s≤δ_s 换成 p_s≤ηδ_s，上界变为 (9+η²)^{1/2}。所以梯度上界 4 不是关键，任何 L>3 的上界结论都一样。

**(c) 测度与能量。** 由引理 4(b)(c)：
- |𝓡_{s+1}|=θ_s(1−ε)|𝓡_s|
- |W_s|=(1−θ_s)(1−ε)|𝓡_s|
- |M_s|=ε|𝓡_s|

记 q=(1−ε)⁴/6，则 |𝓡_{4n+1}|=qⁿ，|F|=q^N ≤ 6^{−N}。又 Σ_{s≤4N}|𝓡_s| ≤ 4Σ6^{−n} < 24/5，故 Σ|M_s| < (24/5)ε。

能量密度：井块上为 0；终胞上为 min_i|A_i|²=5；边缘上 ≤ (√10+|A₂|)² = (√10+√5)² < 30。因此

**E(u_N) ≤ 30·(24/5)ε + 5·6^{−N} ≤ 149·6^{−N} → 0。**

结合 E≥0，得 e₀=0，并与第 1 节一起得出 e₀ 不可达。

**(d) 相体积分数。** 令 S_N=Σ_{n<N}qⁿ，则 S_N→6/5。井块测度为：
- |W^{(4)}|=(1−ε)S_N/4
- |W^{(3)}|=(1−ε)²S_N/4
- |W^{(2)}|=(1−ε)³S_N/4
- |W^{(1)}|=(1−ε)⁴S_N/12

井块上 ∇u_N 恰为 A_i，最近井就是 A_i。其余集合 M∪F 的测度 ≤ (24/5)ε+6^{−N}，所以 |π_i(u_N)−|W^{(i)}|| ≤ 6·6^{−N}。令 N→∞ 得 π(u_N)→(1/10,3/10,3/10,3/10)=λ\*，与命题 3 一致。

**数值抽查（不属于证明）。** 我用精确有理数算术沿这套递归抽样检验。取 ε=1/200、N=6 时，零边界成立，差商 |u(x)−u(y)|/|x−y| 最大约 3.03 < √10，‖∇u‖_F 最大约 3.02，井块上梯度精确等于井。能量蒙特卡洛估计约 0.036，最近井相分数约 (0.096, 0.306, 0.301, 0.298)。

## 4. 总结

- **单元能：** e₀=0，由 u_N 的构造给出上界，E≥0 给出下界。
- **是否达到：** 不达到，因为对一切 u∈𝒜 有 E(u)>0（第 1 节）。
- **相体积分数：** 任何 E(u_j)→0 的序列都有 π(u_j)→(1/10,3/10,3/10,3/10)。只靠重心条件会留下一条线段，行列式零拉格朗日量把它压成一点。
