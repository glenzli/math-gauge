# 答卷：S1–S6

**结论摘要**
- S1：成立。
- S2：Y ≃ D ∨ ΣL。
- S3：取 K = L∗{v,w}，B 取一条含 v 的棱。
- S4：X 不必可缩。恒有 X ≃ Σ|lk_K(v)|，且 lk_K(v) ≠ ∅。可能的同伦型恰为“非空有限复形的悬挂”。X 可缩 ⇔ lk_K(v) 非空、连通且整系数零调。
- S5：不必。唯一新增类型是 S⁰，对应 v 为孤立顶点。
- S6：不能。

## 0. 约定与标准事实

**悬挂。** CY = Y×[0,1]/(Y×{1})，Y 视为 Y×{0}。ΣY = CY/Y，即把 Y×{0}、Y×{1} 各压成一点 S、N（极点）。约定 Σ∅ = S⁰。

- 若 Y ≠ ∅，则 ΣY 路径连通，且 H̃ₙ(ΣY) ≅ H̃ₙ₋₁(Y)（n ≥ 1，Mayer–Vietoris）。
- 若 Y 是非空 CW 复形，约化悬挂 = ΣY/({y₀}×I)。商掉的弧可缩，由 S1 知它与 ΣY 同伦等价。所以“约化/非约化”不影响下文任何结论。

**单纯复形。** K 为有限抽象单纯复形，v 为顶点。

- K−v := {σ∈K : v∉σ}。
- lk(v) := {σ∈K−v : σ∪{v}∈K}。
- St(v) := {σ∈K : σ∪{v}∈K} = v∗lk(v)。

它们都是子复形，且 K = (K−v) ∪ St(v)，(K−v) ∩ St(v) = lk(v)。|K| ⊂ ℝ^V 取重心坐标 x = (x_u)。有限时 |K| 是紧 Hausdorff 空间，也是有限 CW 复形。

**标准事实。**
- **(F1)** (X,A) 是 CW 对 ⇒ X×{0}∪A×I 是 X×I 的强形变收缩核，因此有同伦延拓性质（HEP）。
- **(F2)** Hurewicz + Whitehead：单连通 CW 复形若约化整系数同调全零，则可缩。
- **(F3)** 紧空间到 Hausdorff 空间的连续满射是商映射。特别地，q×id_I 是商映射，所以“先商后乘 I”等于“先乘 I 再商”。

**引理 A（删去顶点 v）**
- (a) |K| = |K−v| ∪ |St(v)|，且 |K−v| ∩ |St(v)| = |lk(v)|。
- (b) 若 lk(v) ≠ ∅，则 |St(v)| ≅ C|lk(v)|（顶点 v，底 |lk(v)|）。若 lk(v) = ∅，则 St(v) = {v}。
- (c) |K−v| 是 |K|∖{v} 的强形变收缩核。
- (d) 若 lk(v) ≠ ∅，则 |K|/|K−v| ≅ Σ|lk(v)|。若 lk(v) = ∅，则 |K| = |K−v| ⊔ {v}。

*证明。*
- (a) 含 v 的单形属于 St(v)，其不含 v 的面属于 lk(v)。
- (b) 映射 (y,s) ↦ (1−s)y + sv 把 |lk|×[0,1] 连续地映满 |St|。点 x ≠ v 可写成 (1−x_v)ρ(x) + x_v·v，其中 ρ(x)ᵤ = xᵤ/(1−x_v)（u≠v）。该映射恰把 |lk|×{1} 压成点 v，其余处为单射。紧 → Hausdorff，故诱导同胚。
- (c) 对 x ≠ v 有 x_v < 1。令 ρ(x)_v = 0，ρ(x)ᵤ = xᵤ/(1−x_v)，则 supp ρ(x) = supp x∖{v} ∈ K−v。令 r(x,s) = (1−s)x + sρ(x)。
  - 它落在单形 |supp x| 内，且 r(x,s)_v = (1−s)x_v < 1。
  - 它在有限个闭集 (|σ|∖{v})×I 上连续，由粘接引理得整体连续。
  - r₀ = id，r₁ 的像在 |K−v| 内，且 x_v = 0 时 r(x,s) ≡ x。
- (d) 复合 |St| ⊂ |K| → |K|/|K−v| 是连续满射，恰把 |lk| 压成点。它诱导紧 Hausdorff 空间间的连续双射 |St|/|lk| → |K|/|K−v|，故为同胚。再由 (b)，|St|/|lk| ≅ C|lk|/|lk| = Σ|lk|。∎

## S1　可缩子复形的商

**命题。** Y 为有限 CW 复形，A ⊂ Y 为非空可缩子复形。则 q: Y → Y/A 是同伦等价。

*证明。*
1. A 可缩：存在 h: A×I → A，h₀ = id_A，h₁ ≡ a₀。把 h 看成包含映射 A ↪ Y 的同伦。(Y,A) 是 CW 对，由 (F1) 延拓为 F: Y×I → Y，F₀ = id_Y，F|_{A×I} = h。于是 **F_t(A) ⊂ A 对所有 t 成立**，且 F₁(A) = {a₀}。
2. F₁ 在 A 上为常值，故存在连续的 g: Y/A → Y，使 g∘q = F₁。
3. **下降。** 合成 q∘F: Y×I → Y/A 在每个 A×{t} 上恒等于基点 *，这是因为 F_t(A) ⊂ A。又 Y×I → (Y/A)×I 是商映射，因为它是紧空间到 Hausdorff 空间的满射（Y/A 是紧 Hausdorff，A 闭，见 F3）。所以 G(q(y),t) := q(F(y,t)) 良定义且连续。
   - 若同伦不把 A 保持在 A 内，q∘F_t 在 A 上就不是常值，无法下降。
4. g∘q = F₁ ≃ F₀ = id_Y（由 F）。
5. G₀ = id_{Y/A}，因为 G₀q = qF₀ = q。G₁ = q∘g，因为 G₁q = qF₁ = qgq 且 q 是满射。所以 q∘g ≃ id。∎

**适用条件。**
- A 非空，否则 Y/A = Y ⊔ pt。
- A 是子复形，用于 HEP。
- 可缩性给出 h。
- 有限性使商空间 Hausdorff，且 (F3) 成立。

## S2　非可缩底空间上的锥附着

**命题。** D 是路径连通有限 CW 复形，L ≠ ∅ 是有限子复形，i: L ↪ D 零伦，Y = D ∪_L CL。则 Y ≃ D ∨ ΣL。

*证明。*
1. 取零伦 H: L×I → D，H₀ = i，H₁ ≡ d₀。
2. 令 Z = (D ⊔ CL×I)/((x,0,t) ~ H(x,t))，x ∈ L，t ∈ I。
   - 子空间 Y₀ = D ∪ CL×{0} 因 H₀ = i 而等于 Y。
   - 子空间 Y₁ = D ∪ CL×{1} = D ∪_c CL，c ≡ d₀。
3. (CL,L) 是 CW 对（L 为子复形）。由 (F1)（对 ε = 1 把 t 换成 1−t），CL×I 形变收缩到 CL×{ε} ∪ L×I (ε = 0,1)，且在后者上驻定。该形变在 D 上取恒等，与粘合 (x,0,t) ~ H(x,t) 相容。其连续性来自 (D⊔CL×I)×I → Z×I 是商映射（F3）。所以 Y₀ 和 Y₁ 都是 Z 的形变收缩核，从而 Y ≃ Z ≃ Y₁。
4. 在 Y₁ 中底 L 的每点都等同于 d₀，故 Y₁ = D ⊔ (CL/L)/(d₀ ~ S) = D ∨ ΣL。∎

**楔点的选择。**
- ΣL 一侧：楔点是极点 S = [L×{0}]（锥的底）。翻转 t ↦ 1−t 交换两极点，故取锥顶 N 同样可以。取 ΣL 的任一点，同伦型也不变，因为 ΣL 是路径连通 CW 复形（L ≠ ∅）。
- D 一侧：楔点是零伦的终点 d₀。因为 D 路径连通，d₀ 可取 D 的任意点（沿路径改接零伦）。又因 D 是 CW 复形（良配点），D∨ΣL 的同伦型与 d₀ 无关。
- 若 D 不路径连通，d₀ 只落在一个分支，选择就有影响。
- 具体的同伦等价依赖所选零伦，但同伦型不依赖。

**特例。** D 可缩时，S1（A = D）给出 Y ≃ Y/D = CL/L = ΣL，与 D∨ΣL ≃ ΣL 一致。

## S3　整数扭结的实例

设 L 是 RP² 的任一有限单纯三角剖分，顶点集为 V，u ∈ V。取新点 v、w，令

- **K = L∗{v,w}** = {σ, σ∪{v}, σ∪{w} : σ∈L} ∪ {{v},{w}}（v、w 不相连）。
- **B = {{v},{u},{v,u}}**，即一条棱。

例如取 6 点三角剖分 123, 134, 145, 156, 162, 235, 346, 452, 563, 624。

**验证。**
1. **|K|∖v 非空可缩。**
   - K−v = w∗L 是锥，|w∗L| 可缩（直线收缩到 w，每点到 w 的线段落在同一单形内）。
   - 由引理 A(c)，O ≃ |K−v| ≃ pt，且 w ∈ O。
2. **(|B|∖v) → |B| 是同伦等价。** |B| 是线段，|B|∖v 是半开线段，二者都可缩。可缩空间之间的任何映射都是同伦等价。
3. **同调。** lk(v) = L，K−v 可缩，由引理 A(d) 和 S1 得 |K| ≃ Σ|L|。S1 的条件：|K| 是有限 CW，A = |K−v| 是非空可缩子复形。因此 H̃ₙ(|K|;ℤ) ≅ H̃ₙ₋₁(RP²;ℤ)，即 H̃₂ = ℤ/2，其余为 0。由万有系数定理，H̃ₙ(|K|;ℚ) = 0 对所有 n 成立。
4. **不可缩。** H₂(|K|;ℤ) = ℤ/2 ≠ 0。
   - 实际上 |K| 单连通，π₂ = ℤ/2（Hurewicz），它是 Moore 空间 M(ℤ/2,2)。
   - 对上面的 6 点例，用 Smith 标准形机器核验得 H̃*(K;ℤ) = (0,0,ℤ/2,0)。

**为何“O∩C→C 为等价”推不出 O→X 为等价。** C 不是 v 的邻域，B 只看到 K 的一小块，看不到 lk_K(v)。

## S4　整体对象与恢复目标

**判定。**
- 目标“X 必可缩”不成立（S3 的反例满足全部条件）。
- 下面三条成立并给出证明：
  1. 同伦型的刻画；
  2. 全部类型的实现；
  3. X 可缩的充要判据。

记 D = K−v，L = lk_K(v)。

### 定理 4.1（限制）
设 (K,v,B) 满足题设。则：
1. |D| 非空可缩。
2. L ≠ ∅。
3. 商映射 |K| → |K|/|D| ≅ Σ|L| 是同伦等价，所以 **X ≃ Σ|lk_K(v)|**。
4. 对给定的 (K,v)，若 |D| 非空可缩，则存在满足条件的 B ⇔ L ≠ ∅。此时 B 可取任一条棱 {v,u}。

*证明。*
1. 引理 A(c) 说明 |D| ↪ O 是同伦等价，而 O 非空可缩。
2. 设 L = ∅。则 K 中含 v 的单形只有 {v}，故 {v} 在 C 中既开又闭。
   - 这时 O∩C = |B−v|，其包含映射的像不含分支 {v}，π₀ 不满，不是同伦等价。
   - 矛盾，所以 L ≠ ∅。
3. 用 S1，Y = |K| 有限 CW，A = |D| 是非空可缩子复形（由 1），再加引理 A(d)。
   - 也可用 S2：D 路径连通，L ⊂ D 是非空子复形，D 可缩所以包含映射零伦，X = D∪_L CL ≃ D∨ΣL ≃ ΣL。
4. 必要性已在 2 中证明。充分性：取棱 {v,u} (u ∈ L)，|B|∖v 与 |B| 都可缩，故包含映射是同伦等价。∎

**推论。**
- X 路径连通。
- H̃ₙ(X;ℤ) ≅ H̃ₙ₋₁(|L|;ℤ)。
- 记 c 为 L 的分支数。H₁(X) = ℤ^{c−1}，且 π₁(X) 是秩为 c−1 的自由群。这由 ΣL = 两个可缩开集的并，交 ≃ L，用 van Kampen 得到。
- X 单连通 ⇔ L 连通。
- 例：L = 两点时 X ≃ S¹，不单连通。

### 定理 4.2（实现，分类完成）
对每个非空有限单纯复形 L，三元组 (L∗{v,w}, v, 棱 {v,u}) 满足全部条件，且 lk(v) = L，|K| ≅ Σ|L|。

*证明。* 验证同 S3：K−v = w∗L 可缩，B 是棱，lk(v) = L。∎

**因此**，可能的同伦型恰为 **{Σ|L| : L 非空有限单纯复形}**。因为每个有限 CW 复形都同伦等价于有限单纯复形，这也就是 {ΣY : Y 非空有限 CW 复形}。

**不会出现的类型。**
- RP²、T² 不会出现，因为 π₁ 不是自由群。
- CP²、S²×S² 不会出现，因为 X 是两个可缩开集的并，约化上同调中的所有上积为零。

### 定理 4.3（可缩判据，只用含 v 的单形的关联数据）
取 V(K) 的全序。令 Eₙ 为以 K 中含 v 的 n 维单形为基的自由 ℤ-模（E₀ = ℤ{v}），并令

∂ᵛ(u₀<…<uₙ) = Σ_{j: uⱼ≠v} (−1)ʲ (σ∖uⱼ)。

即只保留仍含 v 的面。这正是 C*(K)/C*(K−v) 的边缘算子。数据就是含 v 的单形按包含序构成的有限偏序集，它同构于 lk(v) 的面偏序集再添一个最小元。则下列等价：

1. X 可缩；
2. H̃ₙ(X;ℤ) = 0（∀n）；
3. L 连通，且 H̃ₙ(|L|;ℤ) = 0（∀n ≥ 1）；
4. 链复形 (E,∂ᵛ) 在所有次数正合；
5. 记 mₙ = rank Eₙ，∂ₙ: Eₙ → Eₙ₋₁（∂₀ = 0）。对所有 n ≥ 0：rank ∂ₙ + rank ∂ₙ₊₁ = mₙ，且 ∂ₙ₊₁ 的非零初等因子全为 1（Smith 标准形可检验）。

等价地，局部同调 Hₙ(X, X∖v;ℤ) = 0 对所有 n 成立。

*证明。*
- **(1)⇒(2)** 显然。
- **(2)⇒(3)** 对 n ≥ 0，H̃ₙ(L) ≅ H̃ₙ₊₁(ΣL) ≅ H̃ₙ₊₁(X) = 0。n = 0 时给出 L 连通。
- **(3)⇒(1)**
  - ΣL 单连通：ΣL = U∪V，U = ΣL∖S，V = ΣL∖N，二者开且可缩，U∩V ≅ L×(0,1) 路径连通，van Kampen 给出 π₁ = 1。
  - H̃ₙ(ΣL) = H̃ₙ₋₁(L) = 0。
  - 由 (F2)，ΣL 可缩，故 X ≃ ΣL 可缩。
- **(3)⇔(4)** 令 φ(σ) = (−1)ᵖ(σ∖v)，p 为 v 在 σ 中的位置，则 φ∂ᵛ = −∂φ。因此 (E,∂ᵛ) 与 lk(v) 的增广链复形（空单形在 −1 次）相差一个移位和符号，Hₙ(E) ≅ H̃ₙ₋₁(L)。
  - L = ∅ 时 E = ℤ（只在 0 次），H₀ = ℤ ≠ 0，故不正合，与 X ≃ S⁰ 一致。
  - 对 L ≠ ∅，E₀ 处的正合性自动成立（∂₁ 有 ±1 元）。
- **(4)⇔(5)** 正合 ⇔ ker ∂ₙ = im ∂ₙ₊₁。这等价于秩相等，加上 im ∂ₙ₊₁ 是直和项（初等因子全为 1）。
- **局部同调**：Hₙ(K, K−v) = Hₙ(E)。∎

**注记。**
- “lk(v) 可缩”只是充分条件，不是必要条件。取二元二十面体群表现 ⟨s,t | s³t⁻⁵, (st)²s⁻³⟩ 的 2-复形，边缘矩阵 [[3,−5],[−1,2]] 的行列式为 1，故它整系数零调、连通。它的 π₁ 是 120 阶群，故不可缩。取同伦等价于它的有限单纯复形 P，则 ΣP 可缩，但 P 不可缩。
- 因此判据必须用同调（可由有限矩阵检验），不能用 lk(v) 的可缩性。
- B 的作用仅是排除孤立 v。取 B = K 时条件等价于 X 可缩。B 取 St(v) 时条件等价于 lk(v) 可缩。B 取含 v 的棱时恒成立。

## S5　不提供子复形 B

**结论。** 不必。设 K 有限，|K|∖v 非空可缩。则恰有两种情形：

- **lk(v) ≠ ∅**：与 S4 的证明相同，|K| ≃ Σ|lk(v)|，这是非空有限复形的悬挂。
- **lk(v) = ∅**（v 为孤立顶点）：|K| = |K−v| ⊔ {v} ≃ pt ⊔ pt = S⁰。它不路径连通，而非空复形的悬挂路径连通，所以不是这种悬挂。

**分类。** 新增类型只有 S⁰（两点离散空间）。它在约定 Σ∅ = S⁰ 下是空复形的悬挂。实现：K = {{v},{w}}，或 {v} ⊔ 任意可缩复形。

全部可能类型 = {Σ|L| : L 非空有限} ⊔ {S⁰}，两类因路径连通性不同而不相交。

S4 的 B 条件恰好排除了第二类（定理 4.1 的 2）。

## S6　悬挂信息的逆向恢复

**结论。** 不能。Σ|L₁| ≃ Σ|L₂| 推不出 |L₁| ≃ |L₂|。

**反例。**
- L₁：顶点 1–6，棱 12, 23, 13, 45, 56, 46（两个不相交的三角形边界，≅ S¹⊔S¹）。
- L₂：顶点 1–6，棱 12, 23, 13, 34, 45, 35，外加孤立顶点 6（8 字形 F = S¹∨S¹ 与一个孤立点的不交并）。

**引理 6.1。** A、B 非空有限 CW 复形 ⇒ Σ(A⊔B) ≃ ΣA ∨ ΣB ∨ S¹。

*证明。*
1. Σ(A⊔B) = P/(S_A ~ S_B)，其中 P = ΣA ∨ ΣB 在 N 处楔合，P 路径连通。
2. 令 P′ = P 加一条连接 S_A 与 S_B 的弧 J，即 P′ = P ∪_{S⁰} C(S⁰)。
3. 用 S2：D = P 路径连通；L = {S_A,S_B} 是非空有限子复形；包含映射零伦（沿路径把 S_B 滑到 S_A，P 路径连通）；C(S⁰) 是弧 J。得 P′ ≃ P ∨ ΣS⁰ = P ∨ S¹。
4. J 是 P′ 的可缩子复形，用 S1，P′ → P′/J = P/(S_A~S_B) = Σ(A⊔B) 是同伦等价。∎

**计算。**
- ΣL₁ ≃ ΣS¹ ∨ ΣS¹ ∨ S¹ = S² ∨ S² ∨ S¹。
- ΣL₂ ≃ ΣF ∨ Σ{p} ∨ S¹，其中 p 为孤立点。Σ{p} 是弧，用 S1 塌缩，得 ≃ ΣF ∨ S¹。
- 对 ΣF：塌缩弧 J₀ = {x₀}×I（x₀ 为 F 的公共顶点），由 S1 是同伦等价。ΣF/J₀ = Σ_red S¹ ∨ Σ_red S¹ = S²∨S²。
- 所以 ΣL₂ ≃ S²∨S²∨S¹ ≃ ΣL₁。
- 机器核验：两个悬挂的约化整系数同调都是 H₁ = ℤ，H₂ = ℤ²。

**L₁ ≄ L₂。**
- 设 f: L₁ → L₂ 是同伦等价，g 是同伦逆，p 为 L₂ 的孤立点，x = g(p)。
- fg ≃ id 给出 L₂ 中从 f(x) 到 p 的路径。而 {p} 是 L₂ 的一个路径分支，所以 f(x) = p。
- 同伦等价诱导 π₁(L₁,x) ≅ π₁(L₂,p) = 0，但 π₁(L₁,x) = ℤ。矛盾。

**连通情形也不成立（补充，不影响上面的完整证明）。**
- Σ(S¹×S¹) ≃ S²∨S²∨S³ ≃ Σ(S¹∨S¹∨S²)（标准分裂 Σ(X×Y) ≃ ΣX∨ΣY∨Σ(X∧Y)）。但 π₁(T²) = ℤ² 不是自由群，π₁(S¹∨S¹∨S²) = F₂ 是自由群，所以 T² ≄ S¹∨S¹∨S²。
- pt 与上面 S4 注记中的 P：ΣP 与 Σ(pt) 都可缩，但 P 不可缩。
