# 审阅结论

**不能不加区分地说“定义和实现完全对应”。** 附件包含两条不同的形式化路线：

1. `domain_refinement_construction.lean` 从任意合法节点分划出发，实际构造加细数据并删除不可达节点，证明所得网络的全局外延算子等于原网络。这条路线确实覆盖正文的节点域加细，包括自环、重复访问和不可达子节点；不是仅对预先假定等价的网络证明等价。
2. `network_refinement.lean` 的 `NodeDomainRefinement N N'` 是给定两个有限网络之间的证书。它足以推出所声明的外延等价，但**比正文规定的结构性加细关系更宽**：它只约束实际产生的输出处的后继规则，没有完整约束保留节点之间未被实际使用的边域。这个差别有具体反例，不能用“已经删除不可达节点”解释掉。

因此，外延保持结论本身有正确且一般的构造性实现；不足主要在于具名加细关系对正文定义的精确刻画，以及构造路线与该关系之间尚未补齐的接口定理。以下只审阅节点域加细。

## 一、正文要求与构造实现的对应

### 1. 分划和局域算子

正文要求分划整个 `dom(fβ)`，而不只是实际到达 β 的输入域。`NodePartitionData` 的字段逐项对应：

- `count_pos`：子域个数为正；`Fin count`：有限索引。
- `nonempty`、`disjoint`、`cover`：各片非空、两两不交，其并恰为 `N.node_dom target`。
- `local_domain`：子节点算子定义域恰为分划片。
- `local_eq`：在该片上与原算子逐点相等。

`local_op_eq_restrict` 已证明子节点算子在整个底集上就是原算子的域限制。域外必须取吸收元，是由 `dom` 的定义和 `local_domain` 推出的，不是遗漏的附加假设。关系版中的 `local_equiv` 使用的 `LocalEquivalent` 也是逐点相等，不是伪度量零距意义的弱等价。

### 2. 标签、入口与全部边域

构造使用标签

\[
\{v\in V:v\ne\beta\}\sqcup\operatorname{Fin}(q).
\]

`piece_at` 在 β 的域内选取唯一所属片；域外的默认值只是函数全定义化。`mem_piece_at` 和 `piece_at_unique` 保证合法求值不依赖这个默认值。

`lift_label v x` 依据**当前输入** x 分配标签；`entry` 对原入口及其输入应用该函数。因此入口片恰为正文所写的交集，其他入口不变。

`choice` 按原输出选择决定停止或后继，并用同一个输出点给后继选片。虽然没有把正文的每一种边域公式都单独命名为定理，但从该定义可以逐点验证：在删除冗余节点之前，对任意新标签 v、w，记投影为 π，有

\[
D'_{v\to w}
 =D_{\pi(v)\to\pi(w)}
   \cap f'_v(U'_v)\cap U'_w. \tag{1}
\]

证明要点是：新源输出属于原源输出像，新的 `next w` 恰表示原后继为 π(w)，且输出落入 w 对应的域；若目标是分片，其唯一性由分划保证。原网络的边域本来就包含于源输出像和目标定义域，故 (1) 对未替换节点可约去多余交集，分别得到正文的入边、出边、不相关边公式。

对自环，`self_loop_choice_iff` 已明确证明：在源片输出像上，新选择为片 b，当且仅当输出属于原自环边域且属于片 b。加上其源像前提，正是

\[
D'_{\beta_a\to\beta_b}
 =D_{\beta\to\beta}\cap f_{\beta,a}(U_{\beta,a})\cap U_{\beta,b}.
\]

这里没有把所有访问 β 的发生错误地固定到同一个子节点，也没有假设输出像之间互不相交。源片由当前节点标签决定，目标片由输出点决定。

新终止域由停止选择、等价地由全部出边域的补集确定。因此删除前有

\[
T'_{\beta_a}=f_{\beta,a}(U_{\beta,a})\cap T_\beta,
\]

未替换节点终止域不变。此处应区分“由定义可推导”与“已有单独命名的 Lean 定理”；附件没有逐项列出全部边域及终止域等式。

### 3. 有限性、终止和删除冗余节点

`colour_path` 随每一步当前输入重新着色；其递归在执行原局域算子后继续处理余下路径。因此同一原节点被多次访问、甚至经自环连续访问时，仍可选中不同片。

源码已有：

- `coloured_terminal`：原合法终止轨迹产生新合法终止轨迹。
- `coloured_eval`：两条轨迹终值相等。
- `colour_path_length`：长度不变。
- `colour_path_projection`：忘掉分片标签后恢复原标签序列。

`presentation` 用这些结果构造 `FiniteNetworkPresentation`，继承原 `depth_bound`。它不是把加细后的终止性当作额外输入。节点集有限、节点域非空、入口合法、后继合法和统一有限终止界都已得到；此时唯一尚未要求的是所有节点均被入口轨迹访问。

随后 `network := presentation.prune` 使用 `Reached` 保留且仅保留被某个输入轨迹访问的标签。`prune` 保留剩余节点的原局域算子，只删除去往被删除标签的转移，符合正文的“删节点及关联边”，并非把所有节点域或边域都有效约化。

`prune_path_labels`、`prune_eval` 已证明路径标签及终值保持。原来每个非目标节点都可达，着色又保留其发生，因此不会误删原来的非目标节点；目标子片是否保留，取决于是否有某次实际发生的当前输入落在该片中，而非仅看原入口输入是否落在该片中。

### 4. 已证明的外延结论

`NodePartitionData.network_extensional_eq` 的结论是

\[
P.network.extensional\_operator=N.extensional\_operator.
\]

这是整个底集上的算子相等，比正文在 U 上局部等价更强。证明在 U 内使用着色求值相等和剪枝求值保持，在 U 外使用两侧均取吸收元。`network_path_labels`、`network_path_projection` 还给出了实际路径对应；长度相等随之得到。

所以，不能把本附件批评为“没有真正构造新网络”“不处理删除冗余节点”“漏掉自环”或“只证明条件性的抽象模拟”。构造文件已处理这些问题。

## 二、关系版的缺口：只管实际输出，不管全部保留边域

`NodeDomainRefinement` 对分划、局域算子、输入域、标签对应和保留哪些片都有实质约束。特别是：

- `source_injective` 排除重复标签；`old_node_present` 保留旧的非目标节点。
- `piece_node_present_iff_reached` 精确要求保留实际访问的片。
- `entry_projection` 联合入口属于节点定义域，足以恢复入口交集规则。

但其唯一后继约束 `choice_projection` 的前提是

\[
z\in f'_v(\texttt{node_actual_input_domain}_{N'}(v)),
\]

而非整个节点输出像。于是它没有规定实际输出像以外、但仍在局域算子输出像以内的边。正文的边域等式却在整个节点域和输出像上成立；删除不可达**节点**不允许任意增删两个保留节点之间未被入口轨迹使用的边。

这不是 totalized `choice` 在节点输出像外无关取值的差异：下面的差异发生在真正的节点输出像内，改变了实际记录的边集和终止域。

### 可复核反例

取底集

\[
X=\{\bot,0,1,2\}.
\]

如需配规范结构，可取不同点间距离为无穷、同点距离为零；此处论证本身不依赖度量。

原网络 N 只有节点 β：

- `fβ` 在 0、1、2 上为恒等，在吸收元处取吸收元，故节点域是 `{0,1,2}`。
- 总输入域和唯一入口片是 `U={0,2}`。
- 没有任何边，即输出选择处处停止。
- 每个入口输入的轨迹都是 `[β]`，统一长度界为 1，节点可达。

分为两个非空片

\[
A=\{0,1\},\qquad B=\{2\},
\]

局域算子分别取恒等算子在 A、B 上的限制。两片都被实际访问。

现构造候选 N'：

- 节点为 a、b，对应 A、B，局域算子如上。
- 输入域仍为 `{0,2}`，0 从 a 进入，2 从 b 进入。
- 增加唯一边 `a→a`，边域是 `{1}`；其余边为空。

这是合法有限网络：0 在 a 输出 0 并停止，2 在 b 输出 2 并停止。两节点都可达，长度界仍为 1；额外边满足源输出像与目标域包含条件，同源边互斥。若从不属于总输入域的状态 `(a,1)` 开始会循环，不违反只对入口输入要求统一有限终止的网络定义。

这个 N' 满足附件的 `NodeDomainRefinement N N'` 全部字段：

- 分划、算子、标签注入、输入域和入口投影均直接满足；不存在非目标旧节点，故相应字段为空条件。
- 两个 `NodePieceReached` 都成立，分别由原输入 0、2 的第零次发生见证。
- N' 在 a、b 的实际输入域分别是 `{0}`、`{2}`，实际输出也分别是 `{0}`、`{2}`。
- 在这些实际输出上 N' 与 N 都停止，因此 `choice_projection` 成立。它不检查输出 1。

然而，正文规定

\[
D'_{a\to a}=D_{\beta\to\beta}\cap f_a(A)\cap A
=\varnothing,
\]

与候选网络的 `{1}` 矛盾。两个子节点均实际可达，根本没有可通过剪枝删除的节点，故这不是剪枝允许的变化。候选的终止域 `T'_a={0}`，而正文构造的终止域应为 `{0,1}`。

两网络的外延算子仍然相等：都在 0、2 上返回输入，在其他点返回吸收元。这说明缺口不是“外延等价定理为假”，而是**形式关系接受了并非正文一次节点域加细的额外结构变化**。例如它可在本应无边的结果中引入未使用的自环，影响底层图是否有环及其他表示层判断。

## 三、关系版定理真正证明了什么

`NodeDomainRefinement.terminal_projection` 从 N' 的实际状态出发，利用实际后继闭包逐步投影终止轨迹；`path_projection` 再用 `terminal_path_unique` 证明它就是原输入的路径。`eval_projected` 用局域算子相等证明对应链求值相等。

由此，`NetworkRefinement.path_eval_eq` 的节点域分支和 `refinement_preserves_local_equivalence` 确实证明

\[
\operatorname{LocalEquivalent}(\phi_{N'},\phi_N,U)
\]

对所有满足这个较宽证书的有限网络成立。路径对应和最终相等不是该结构的字段，不存在直接把待证外延结论塞进前提的循环。但这条关系路线以 N、N' 已是 `FiniteOperatorNetwork` 为前提，不能单靠它证明任意分划一定产生合法有限网络；后一个任务由独立的构造路线完成。

在所给文件中，没有把 `P.network` 装配为 `NodeDomainRefinement N P.network` 的桥接定理，也没有证明该关系等价于正文交集构造后剪枝的结果。前一种桥接可补证；后一种针对当前关系则被上面的反例否定。不能因为有两个同主题定理，就把这两个不同命题混为一谈。

## 四、修复方向

建议保留已成立的外延模拟结果，同时精确化“节点域加细”接口：

1. **构造式定义**：把正文节点域加细定义为来自 `NodePartitionData.network` 的网络，允许保持局域算子、入口片及全部边域的节点重命名。然后由现有 `network_extensional_eq` 推出外延保持。当前较宽关系可另命名为实际轨迹模拟证书。
2. **加强关系式定义**：在当前分划和保留标签条件之外，对每对保留节点 v、w 要求完整边域公式
   \[
   D^{N'}_{v\to w}
   =D^N_{\pi(v)\to\pi(w)}
      \cap f'_v(U'_v)\cap U'_w.
   \]
   这同时处理入边、出边、自环和不相关边，且允许删掉不可达标签及其关联边。随后证明这些条件蕴含现有的实际输出投影条件，复用现有外延证明。
3. 补上从 `NodePartitionData` 构造到精确关系的桥接，并将入口、各类完整边域、保留片判据以及剪枝前后的相应等式明确陈述为定理，便于复核定义符合性。

**不要简单把 `choice_projection` 的前提改为整个节点输出像而仍要求处处与原选择投影相等。** 原网络可能在未实际产生的输出处转向一个后来被删除的子片；正确剪枝会把这个选择改成停止。对完整输出像强求原投影选择不变，会排除正文允许的结果。按保留端点规定边域，或明确先构造再剪枝，才能兼顾精确性与剪枝。

同样，`T'βa=fβa(Uβa)∩Tβ` 是剪枝前的等式；剪枝删除去往不可达片的边后，剩余节点的终止域可能增加未实际产生的输出。源码的剪枝没有因此出错，也不应把上述剪枝前公式不加区别地要求到最终网络上。

## 最终判断与核验范围

- **已覆盖且正确**：任意合法有限分划的实际构造；局域限制；逐发生着色；自环和重复访问；统一有限终止；不可达节点删除；构造结果的全局外延算子相等。关系版在其现有前提下的外延等价证明也成立。
- **尚不准确或未补齐**：`NodeDomainRefinement` 对正文结构性一步加细的刻画过宽；构造与具名关系的桥接未给出；完整边域等式应作为定义符合性接口补齐，而不能从仅约束实际输出的关系字段推出。
