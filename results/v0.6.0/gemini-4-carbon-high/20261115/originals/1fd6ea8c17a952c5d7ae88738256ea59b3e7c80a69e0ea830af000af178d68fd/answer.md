### 二、仍有的不确定性

尽管项目在固定工具链下零误差通过内核检查并覆盖全部 92 项义务，从形式化建模与外部评审视角仍存在以下属于“等价表示选择”层面的不确定性：

1. **宇宙层级特化（`Type` vs `Type u`）**：为与冻结背景模块（如 [operator_space.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/formal_oet/vol_01/ch_01_foundations/operator_space.lean) 和 [metric_entropy.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/formal_oet/vol_01/ch_01_foundations/metric_entropy.lean) 中固定在 `Type` 上的 `Operator`、`covering_number`、`metric_entropy`）无缝对接，本章声明统一采用 `{X I : Type}` 而非宇宙多态 `{X : Type u} {I : Type v}`。在基准测试与教材具体空间（有限集、$\mathbb{R} \sqcup \{\bot\}$ 等）下二者完全兼容，但若外部调用方在更高宇宙层级 `Type (u+1)` 上实例化则需额外升降级包装。
2. **算子链与预序方向的索引/序约定**：
   - 命题 3.2(ii)（[Sec1_ComponentPartition.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/Ch03/Sec1_ComponentPartition.lean#L176-L284)）用 `0`-指标序列 `ϕ : ℕ → Operator X bot` 与 `⋃ m < n` 表示原文 `1`-指标有限链 $c_n = \phi_n \circ \cdots \circ \phi_1$ 与 $\bigcup_{m=1}^n$（下标平移 $m_{\text{lean}} = m_{\text{text}} - 1$，零步基例 $c_0 = \mathrm{id}_{\mathcal{X}}$ 完全一致）。
   - 纤维预序（[Defs.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/Ch03/Defs.lean#L215-L226)）直接按原文定义为二元关系 `FiberGe d U ϕA ϕB`（即 $\phi_A \succeq_{\mathrm{fiber}, U} \phi_B$），而在绑定 Mathlib 的 `Preorder` 类型类（以 `≤` 为原语）时采用标准对偶 `a ≤ b := FiberGe d U b.1 a.1`；相关定理均直接以 `FiberGe` 与 `relZero` 表述以避免方向歧义。
3. **部分定义映射与子类型商的编码方式**：
   - 命题 3.6 与 3.7（[Sec2_FibersAndFactorization.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/Ch03/Sec2_FibersAndFactorization.lean#L227-L500)）将 $T : \phi_A(U) \to \mathcal{X}$ 与 $\overline{T} : \phi_A(U)/{\sim_{\mathcal{G}}} \to \phi_B(U)/{\sim_{\mathcal{G}}}$ 编码为子类型 `operator_image ϕA U` 及其 `Quotient` 上的全函数，而非全空间 `X → X` 上附带子集限制条件的函数；两种编码在数学上等价，但调用接口形态不同。
   - 映射熵差 $\Delta E$（[Defs.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/Ch03/Defs.lean#L509-L586)）通过显式依赖证明参数 `hdef : MappingEntropyDiffDefined ...` 在类型层面排除 $+\infty - (+\infty)$ 不定形（而非无前提全函数对未定义处赋默认值 `0`），从而严格兑现命题 3.18(ii)“只要良定则为 0，不定义无穷减无穷”的要求。
4. **带吸收元实直线的具体类型表示**：反例与习题中的 $\mathcal{X} = \mathbb{R} \sqcup \{\bot\}$ 由代数数据类型 `RealWithBot`（[RealLineExt.lean](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/Ch03/RealLineExt.lean#L15-L18)）实现，与 `Option ℝ` / `WithBot ℝ` 同构但独立命名以避免继承 `WithBot ℝ` 上与吸收元隔离公理冲突的默认序/代数算子实例。
5. **对齐台账中定义展开引用的粒度**：在 [alignment.json](file:///private/tmp/math-gauge-carbon-high-effort-lane1-20261115-v2/alignment/R1/physical-3/session/work/alignment.json#L853-L870) 的 `CH03-P09-02` 中，`dependencies` 列出了同注记内的前置子项 `CH03-P09-01`；在 Lean 项层面，`remark_fiberGe_chain_le` 直接对展开后的集合包含使用了 `Set.Subset.rfl` 与 `Set.Subset.trans`（即 `CH03-P09-01` 所证自反性与传递性的定义体本身），未显式点名调用常量 `Ch03.remark_fiberGe_refl_and_trans`。这属于数学逻辑依赖与内核常量名直接引用之间的细微粒度差异，不影响任何编译、公理或台账合法性判据。
