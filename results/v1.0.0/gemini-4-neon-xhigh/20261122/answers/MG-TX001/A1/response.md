这个结论是正确的，下面给出完整证明。

### 证明

记全部 $N$ 次单位根组成的集合为
$$\mu_N = \{z \in \mathbb{C} : z^N = 1\},$$
记所求的根集合为
$$Z = \{z \in \mu_N : P(z) = 0\}.$$
注意对任意 $z \in \mu_N$，都有 $|z| = 1$（从而 $z \ne 0$ 且 $\overline{z} = z^{-1}$）。

---

#### 引理（幂映射在 $\mu_N$ 上的单射性）

对任意 $1 \le i < j \le 3$，记 $d = a_j - a_i$。则映射
$$\varphi_d : \mu_N \to \mu_N, \qquad \varphi_d(z) = z^d$$
是单射。

**证明：**
因为 $a_i < a_j$，所以 $d = a_j - a_i$ 是正整数。又因为 $a_1, a_2, a_3$ 模 $p$ 两两不同，故 $p \nmid d$。由于 $p$ 是素数且 $N = p^r$，$N$ 唯一的素因子是 $p$，因此 $\gcd(d, N) = 1$。

由 Bézout 恒等式，存在整数 $u, v$ 使得
$$u d + v N = 1.$$
设 $z_1, z_2 \in \mu_N$ 满足 $z_1^d = z_2^d$。因为 $z_1^N = z_2^N = 1$ 且 $z_1, z_2 \ne 0$，在 $\mathbb{C}^\times$ 中有
$$z_1 = z_1^{u d + v N} = (z_1^d)^u (z_1^N)^v = (z_2^d)^u (z_2^N)^v = z_2^{u d + v N} = z_2.$$
因此 $\varphi_d$ 在 $\mu_N$ 上是单射。 $\square$

---

#### 主证明

因为 $c_1, c_2, c_3$ 不全为零，按其中非零系数的个数分三种情况讨论。

**情况 1：恰有一个系数非零。**

设 $c_k \ne 0$，其余两个系数为 $0$，则 $P(z) = c_k z^{a_k}$。对任意 $z \in \mu_N$，由于 $|z| = 1$，有
$$|P(z)| = |c_k|\,|z|^{a_k} = |c_k| > 0,$$
故 $P(z) \ne 0$，从而 $|Z| = 0 \le 2$。

**情况 2：恰有两个系数非零。**

设 $c_i \ne 0, c_j \ne 0$（其中 $1 \le i < j \le 3$），余下的一个系数为 $0$。对任意 $z \in \mu_N$，由于 $z \ne 0$ 且 $c_j \ne 0$，
$$P(z) = c_i z^{a_i} + c_j z^{a_j} = 0 \iff z^{a_j - a_i} = -\frac{c_i}{c_j}.$$
由引理，映射 $\varphi_{a_j - a_i}(z) = z^{a_j - a_i}$ 在 $\mu_N$ 上是单射，因此满足该式的 $z \in \mu_N$ 至多有 $1$ 个，即 $|Z| \le 1 \le 2$。

**情况 3：三个系数均非零（$c_1, c_2, c_3 \ne 0$）。**

令 $d = a_2 - a_1 > 0$。对任意 $z \in Z \subseteq \mu_N$，因 $z \ne 0$，将 $P(z) = c_1 z^{a_1} + c_2 z^{a_2} + c_3 z^{a_3} = 0$ 两边同除以 $z^{a_1}$ 并移项，得
$$c_1 + c_2 z^d = -c_3 z^{a_3 - a_1}.$$
记 $w = z^d = \varphi_d(z)$。由 $|z| = 1$ 可知 $|w| = |z|^d = 1$（从而 $w \overline{w} = |w|^2 = 1$，即 $\overline{w} = w^{-1}$），同时 $|z^{a_3 - a_1}| = |z|^{a_3 - a_1} = 1$。对上式两边取模的平方，得
$$|c_1 + c_2 w|^2 = |-c_3 z^{a_3 - a_1}|^2 = |c_3|^2.$$
将左端展开：
$$|c_1 + c_2 w|^2 = (c_1 + c_2 w)(\overline{c_1} + \overline{c_2}\,\overline{w}) = |c_1|^2 + |c_2|^2 |w|^2 + c_2 \overline{c_1}\, w + \overline{c_2} c_1\, \overline{w}.$$
代入 $|w| = 1$ 和 $\overline{w} = w^{-1}$，整理得到
$$|c_1|^2 + |c_2|^2 - |c_3|^2 + c_2 \overline{c_1}\, w + \overline{c_2} c_1\, w^{-1} = 0.$$
两边同乘 $w$，得
$$(c_2 \overline{c_1})\, w^2 + \bigl(|c_1|^2 + |c_2|^2 - |c_3|^2\bigr) w + \overline{c_2} c_1 = 0.$$
令多项式
$$Q(w) = (c_2 \overline{c_1})\, w^2 + \bigl(|c_1|^2 + |c_2|^2 - |c_3|^2\bigr) w + \overline{c_2} c_1.$$
因为 $c_1 \ne 0$ 且 $c_2 \ne 0$，所以 $\overline{c_1} \ne 0$，从而二次项系数 $c_2 \overline{c_1} \ne 0$。故 $Q(w) \in \mathbb{C}[w]$ 是二次多项式，方程 $Q(w) = 0$ 在 $\mathbb{C}$ 中至多有 $2$ 个不同的根。

由于对每个 $z \in Z$ 都有 $Q(\varphi_d(z)) = 0$，因此像集 $\varphi_d(Z)$ 包含于 $Q$ 的根集中，从而 $|\varphi_d(Z)| \le 2$。再由引理，$\varphi_d$ 在 $\mu_N$ 上是单射，于是
$$|Z| = |\varphi_d(Z)| \le 2.$$

综合上述三种情况，在全部 $N$ 次单位根中，满足 $P(z) = 0$ 的不同根至多有两个。证毕。 $\blacksquare$

---

**注：** 上界 $2$ 是紧的（可以取到）。事实上，任取两个不同的 $N$ 次单位根 $z_1, z_2 \in \mu_N$，关于 $(c_1, c_2, c_3)$ 的齐次线性方程组
$$c_1 z_1^{a_1} + c_2 z_1^{a_2} + c_3 z_1^{a_3} = 0, \qquad c_1 z_2^{a_1} + c_2 z_2^{a_2} + c_3 z_2^{a_3} = 0$$
只有 $2$ 个方程而有 $3$ 个未知数，必存在非零复数解 $(c_1, c_2, c_3)$，对应的 $P(z)$ 在 $\mu_N$ 中恰好有 $z_1, z_2$ 这 $2$ 个不同的根。
