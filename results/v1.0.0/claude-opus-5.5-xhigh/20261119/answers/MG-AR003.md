# 答卷审阅报告

## 总体结论

答卷在各阶段的最终判断都正确：

- S4：求值映射不必连续；第一可数性足以保证 kX = X。
- S5：f 不必是同胚。
- S6：给出的充要条件是 k(f): kX → kY 为同胚；第一可数时可以升级为普通同胚。

S1、S2(1)(2)、S4、S5 以及 S6 的主要论证基本严格。

但答卷不能算完全严格。主要问题有三处：

1. **S3 第 4 步引用 S1 时条件不成立。** 这是唯一实质性的论证错误。结论本身为真，可以修补，修补方法见下文。
2. **S2(3) 有一个错误的集合等同。** 不影响该小节的结论。
3. **若干要求的验证被省略。** 包括 S3 关于 S 的自然性，以及 α ↦ ev∘(α×I) 与 CGHaus 伴随一致这一点。

S5 中另有一处措辞错误，无害。

## 一、实质性问题

### 1. S3 第 4 步：S1 的指数律被用在不满足条件的位置

答卷写道："由 S1 的指数律（由于 S 局部紧 Hausdorff，置于紧开拓扑第一变量）：C(S×kX, kY) ≅ C(S, C_co(kX, kY))"。

- S1 证明的是 C(Z, C_co(X,Y)) ≅ C(Z×X, Y)，要求局部紧的是映射空间的**定义域** X，参数空间 Z 可以任意。
- 要得到答卷所写的同构，需取 Z = S、X = kX，于是要求 **kX 局部紧**。原题没有给出这一条件，一般也不成立，例如 X = ℚ。
- 若按 S 局部紧来套用 S1，只能得到 C(kX, C_co(S, kY)) ≅ C(kX×S, kY)。这是另一个方向的柯里化，不是答卷需要的式子。
- 原题明确要求"援引此前结果时说明其条件为何适用"，所以这是一个引用错误。

**结论本身为真，可以这样修补：**

- **柯里化方向 F ↦ Ψ(F)。** S1 中证明 Ψ(F) 连续只用了管道引理，没有用到局部紧性，所以对 S×kX 同样成立。
- **反向 g ↦ G，其中 G(s,x) = g(s)(x)。**
  - 由第 3 步，S×kX 是 k 空间。因此只需检验 G 在每个探针 p: K → S×kX 上连续。
  - 记 B = pr₂(p(K))，它是 kX 的紧子集。
  - 在 S×B 上有 G = ev_B ∘ ((r_B∘g) × id_B)。
  - 限制映射 r_B: C_co(kX,kY) → C_co(B,kY) 连续，因为对紧集 K' ⊂ B 有 r_B⁻¹[K',O] = [K',O]。
  - ev_B 连续：这是 S1 的情形，B 紧 Hausdorff，因而局部紧。
  - 所以 G∘p 连续，从而 G 连续。
- **另一种修补方式。** 直接引用 CGHaus 的指数律 C(S, kC_co(kX,kY)) ≅ C(S×_k kX, kY)，再用第 3 步得到 S×_k kX = S×kX。答卷在 S3 第二部分自己也用到了这条指数律。

**影响：** S3 中 C(S,M) ≅ H_{X,Y}(S) 的论证在这一步不成立，需要按上述方式替换。修补后整个构造成立，S6 也不受影响。

### 2. S2(3)：把"由原拓扑连续映射诱导"的集合写成了 C(X, kY)

答卷写"连续映射 f: X→Y 诱导的自然变换对应于集合 C(X, kY) ⊂ C(kX, kY)"。这是错的。

- 在 S2 的双射下，h_f 对应的就是函数 f 本身。所以这个集合应为 **C(X, Y)**。
- 包含关系 C(X,Y) ⊂ C(kX,kY) 成立，因为 k 是函子。
- C(X,kY) ⊊ C(X,Y) 可以真包含。反例：取 S5 中的超滤空间 Z，令 X = Y = Z。id_Z ∈ C(Z,Z)，但 id_Z ∉ C(Z,kZ)，因为 kZ 是离散空间。

**影响：**

- 答卷证明的是"(∀Y: C(X,kY) = C(kX,kY)) ⇔ kX = X"，它在字面上与题目要求的"(∀Y: C(X,Y) = C(kX,kY)) ⇔ kX = X"不同。
- 不过实际推理不受影响：
  - 充分性：C(X,kY) ⊂ C(X,Y) 已经足够。
  - 必要性：取 Y = kX 时，C(X,Y) 恰好就是 C(X,kX)。答卷的那句"恒等映射 id_X: X → kX 必须连续"在正确的表述下照样成立。
- 因此结论正确，只需改正这一处集合等同。

## 二、省略的验证与较小的瑕疵

**S1**
- 关于 Y、X 的自然性只做了逐点等式验证。没有检验后复合 C_co(X,Y) → C_co(X,Y') 和预复合 C_co(X,Y) → C_co(X',Y) 是连续的，因而没有说明 C(X,k)∘g、C(j,Y)∘g 仍是连续映射。
- 补充很容易：k₊⁻¹[K,O'] = [K, k⁻¹O']，j*⁻¹[K',O] = [j(K'), O]。

**S2(1)**
- 没有说明 βD ∈ U。补充：βD ⊂ P(P(D))，而 P(P(D)) ∈ U。
- 其余部分正确：βD 是紧零维 Hausdorff 空间；π: βD → K 是闭满射，因而是商映射。

**S2(2)**
- 正确。点求值确定 α_S(f) = g∘f。
- C(S,Y) = C(S,kY)，再加上 kX 是关于 profinite 探针的终拓扑，两者给出所需的双射。

**S3**
- 第 2、3 步正确：k(S×X) = k(S×kX) 是因为两边的探针相同；第 3 步引用的是"局部紧 Hausdorff 空间与 k 空间之积为 k 空间"。答卷没有说明题目用"探针"定义的 k 与经典的"紧子集"定义在 Hausdorff 空间上一致，这是小缺口。
- "在所有 S 上自然"只是断言，没有验证。实际验证只需一行：对 θ: S' → S，有 G_{φθ}∘(σ',ψ) = G_φ∘(θσ', ψ)。
- "恰由 α ↦ ev∘(α×I) 实现"也没有验证。验证如下：若 α_T(σ) = g∘σ，则 ev_T(gσ, ψ) = G∘(σ,ψ)，其中 G 是 g 的反柯里化。这正好对应 CGHaus 伴随下的 g ↦ G。验证成立，但答卷没写出来。
- M(u,Y)、M(X,v) 的连续性是断言的。可以由 CGHaus 中求值复合后再柯里化得到。
- 关于 X、Y 的自然性，答卷只给出了 ev 的双自然性等式。它推出 Nat 同构的自然性只需一行，答卷没有写出。

**S4(1)**
- 结论正确，反例 ℚ、ℝ 有效。
- 答卷直接说 0 的邻域可以取成 [K,(−ε,ε)] 形式，这需要一句理由：基本开集 ∩[K_i,O_i] 若含 0，就包含 [∪K_i, (−ε,ε)]，其中 ε = min ε_i。
- K = ∅ 时 δ = ∞，公式需要另行解释。
- "K 在 ℝ 中疏朗 ⇒ 在 ℚ 中无内点"这一步成立：K 在 ℝ 中闭，若 K ⊃ (a,b)∩ℚ，则 K ⊃ [a,b]，与 K ⊂ ℚ 矛盾。

**S4(2)**
- 正确。这是"第一可数 ⇒ 序列空间 ⇒ k 空间"的标准论证。
- 收敛序列连同极限构成的紧子集给出一个探针，方向用得对。

**S5**
- 结论与反例 id: kZ → Z 都正确。
- 超滤空间 Z 的构造正确：它是 Hausdorff 空间，紧子集都有限，{p} 不是开集。
- "由超滤子性质，**恰有一个**集合不属于 𝒰"是错的。当 A₁ ⊔ A₂ ∉ 𝒰 时，两个集合都不属于 𝒰。正确说法是"至少一个不属于"，而后文"不妨设 A₁ ∉ 𝒰"只需要这一点，所以无害。
- 由"紧子集都有限"推出 kZ 离散时，用的是紧子集的说法而不是探针的说法。补充：对探针 f: K → Z，f(K) 是有限集，所以 f⁻¹(A) 是有限个闭纤维的并，因而闭。

**S6**
- 复合映射由 CGHaus 中"结合同构 → id×_k ev → ev → 柯里化"得到；结合律和单位律通过"连续映射由底层函数决定"得到。都正确。
- 充要条件 k(f) 为同胚正确。依据是 S2 的双射保持复合，即 α_S(φ) = g∘φ。
- 第一可数时由 S4(2) 得 kX = X、kY = Y，可以升级为普通同胚。正确。

## 三、结论

| 阶段 | 结论 | 论证 |
|---|---|---|
| S1 | 正确 | 基本严格；自然性中映射空间之间映射的连续性未验证 |
| S2 | 正确 | (1)(2) 严格；(3) 有错误的集合等同 C(X,kY)，结论不受影响 |
| S3 | 构造正确 | **第 4 步误用 S1**（要求 kX 局部紧）；关于 S 的自然性、与 ev 公式的对应未验证 |
| S4 | 正确（不必连续 / 足以保证） | 严格，有小处省略 |
| S5 | 正确（不必为同胚） | 严格；"恰有一个"应为"至少一个" |
| S6 | 正确 | 严格，依赖 S3 和 CGHaus 的标准事实 |

总评：所有判断题结论正确，构造可以成立。但 S3 的核心同构依赖一次条件不满足的引用，需要按第一节第 1 点补上论证；另需改正 S2(3) 中的集合等同，并补全 S3 中省略的自然性验证。
