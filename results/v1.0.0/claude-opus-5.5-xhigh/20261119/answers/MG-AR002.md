## 逐项核查

### S1：正确
- **解集维数**：齐次解空间是 W^⊥，由非退化性得 dim W^⊥ = |I| − dim W，正确。
- **纤维维数**：x|_A = 0 当且仅当 x ∈ U_A^⊥，所以纤维的方向空间是 W^⊥ ∩ U_A^⊥ = (W+U_A)^⊥，维数为 |I| − dim(W+U_A)。备注里的另一写法 |I| − |A| − dim W + dim(W∩U_A) 由 dim U_A = |A| 得到，也正确。
- **可延拓判据的必要性**：直接计算即可，正确。
- **充分性**：设 T: W^⊥→k^A 为限制映射。对 v∈W^⊥，有 (T\*u)(v) = Σ_{i∈A} u_i v_i = ι_A(u)·v。在有限维下 (W^⊥)\* ≅ k^I/W^{⊥⊥} = k^I/W，所以 T\*(u) = ι_A(u)+W，ker T\* ≅ W∩U_A。再由 Im T = (ker T\*)^⊥ 推出判据。z·u 的计算利用了 supp w ⊆ A，正确。
- **β 的良定义**：β 只依赖 w 而不依赖系数 c_j 的选取，这一点由相容性保证，答卷说明正确。

### S2：正确
- 解数 q^{|I|−dim W}。
- 每个可实现坐标的完成数 q^{|I|−dim(W+U_A)}。
- 可实现坐标数用"总数 ÷ 纤维大小"得到 q^{dim(W+U_A)−dim W}。由于所有非空纤维大小相同，这个除法成立。
- 公式只用到题目允许的四个量。上面的穷举也确认了这些公式。

### S3：正确
- **紧性与非空**：Tychonoff 给出 k^I 紧且 Hausdorff。f_j 只涉及有限个坐标，所以连续，S_j = f_j^{-1}(b_j) 是闭集。题设给出有限交性质，所以 S 非空；S 是紧空间的闭子集，因而紧。
- **全不连通**：连通子集在每个坐标上的投影都是 k 中的连通集，只能是单点，所以乘积全不连通，子空间继承这一性质，论证成立。
- **π_A(S) 闭**：紧集在 Hausdorff 空间中的连续像是紧集，因而闭，正确。
- **元素刻画**：闭集族 {S_j} ∪ {K_i = π_i^{-1}(y_i)} 的有限交性质恰好就是"有限行加有限 A 坐标同时可实现"，再用紧性得到全交非空，正确。

### S4：判定和证明都正确，分类表缺证明
- **β 的良定义**：有限关系 Σc_j a_j = 0 与有限子系统的解 x^{(F)} 配对，得到 Σc_j b_j = 0。这里 a_j 有限支撑，所以配对是有限和，论证有效。
- **整体解**：把 W 的基扩充为 k^{(I)} 的基（Zorn 引理），在补充的基向量上取 0，得到 β̃。由 a_j = Σ a_j(i)e_i（有限和）可得 Σ a_j(i)x\*_i = β̃(a_j) = b_j，正确。
- **S 的描述**：S = x\* + W° = {x : ⟨w,x⟩ = β(w), ∀w∈W}。两种写法的等价性由线性立即得到，答卷没写出来，但无碍。
- **像的定理**：在 W+U_A 上定义 ψ(w+u) = β(w)+γ_y(u)；β 与 γ_y 在 W∩U_A 上一致保证 ψ 良定义。把 ψ 延拓到全空间后取 x_i = Φ(e_i)。两个方向都正确。这里所用的数据 (W, β) 以及 W∩U_A 上的 β 都只由 a_j、b_j 决定，符合题目要求。
- **纤维**：纤维是 x + W°∩U_A° = x + (W+U_A)°，正确。

**缺口：分类表（S4 第 5 节）只有断言。** 三条结论都是对的，但无限维情形下"单射 ⇔ W+U_A = k^{(I)}"需要一个答卷没有写出的引理。补证如下：

- **单射**：S 非空，纤维是 (W+U_A)° 的陪集，所以单射等价于 (W+U_A)° = 0。若 M := W+U_A ≠ V（V = k^{(I)}），取 v∉M，把 M 的基并上 v 扩充成 V 的基，令泛函 φ 在 v 上取 1、在其余基向量上取 0。再令 x_i = φ(e_i)，就得到 (W+U_A)° 中的非零元。反方向显然。
- **满射**：若 W∩U_A = 0，由像的定理，所有 y 都可实现。若存在非零 w ∈ W∩U_A，取某个 i₀∈A 使 w_{i₀} ≠ 0，调整 y_{i₀} 使 Σ w_i y_i ≠ β(w)，这样的 y 不可实现。
- **双射**：就是上面两条同时成立。

- 每行有限支撑。

### S6：正确
- **闭性**：w ∈ W∩U_A ⊆ k^{(I)}，所以 supp w 有限。每个 C_w 是有限坐标上的线性条件，在离散拓扑下是 clopen 柱集。π_A(S) = ⋂C_w 是闭集的交，因而闭。论证不依赖 |k|。
