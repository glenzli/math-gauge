## S1

**主证明正确。**
- 指标集 𝓘 = ∏ 𝓘_{x_i} 是有向集。
- 映射 (U_i) ↦ ∪U_i 是余终的。
- 投影 𝓘 → 𝓘_{x_i} 和 𝓘 → 𝓘_{x_i}×𝓘_{x_j} 都是满射单调映射，因此余终。由此中间项识别为 G(S_i)，右项识别为 G(S_i×_S S_j)。
- 在 Ab 中，滤过余极限与等化子交换，结论成立。

还有一个小缺口：S_i×_S S_j = lim(U_i∩U_j) 需要先说明 S→X 是单态射（它是局部化），从而 S_i×_S S_j = S_i×_X S_j。答卷"仿射极限下对应张量积"的说法过于粗糙。

**第 3 部分有两处问题。**

**(a) 概形层面的断言是错的。** 答卷说"dim O_{X,x_i} ≥ 1 时，O_{X,x_i} 不是有限生成的 O_{X,Σ}-代数"。反例如下：
- 取 X = 𝔸¹ = Spec k[t]，Σ = {0,1}，M = k[t] 中与 t、t−1 都互素的多项式所成集合。
- 任一不被 t 整除的多项式都可写成 (t−1)^m·g，其中 g ∈ M。所以 O_{X,0} = O_{X,Σ}[1/(t−1)]，是有限生成的。
- 在拓扑上，S = {m₀, m₁, η}，而 S₁ = {m₀, η} = D(t−1) 是开集。
- 因此维数为 1 时 S_i 是开子概形（n = 1 时更是平凡地成立）。

维数 ≥ 2 时"不是有限生成"确实成立。但那只能由"S_i 不是开集"再结合 EGA IV 17.9.1（局部有限表示的平坦单态射是开浸入）反推出来，答卷并没有独立证明。

**(b) 拓扑论证缺少前提。** 答卷说"非零的 f 只含于有限多个高度 1 素理想"，这要求 x_i 与 x_j 位于 X 的同一个连通分支（光滑时即同一不可约分支）。
- 反例：X = 𝔸²⊔𝔸²，x₁、x₂ 分别取两个分支的原点。此时 S = S₁⊔S₂，S_i 是开集。取 f = (1,0) ∉ 𝔭₁，它落在第二个因子的所有素理想中。
- 此外，"存在 𝔮 ⊂ 𝔭_j，使 f ∉ 𝔮 且 𝔮 ⊄ 𝔭_i"这一步没有证明。补法：取 g ∈ 𝔪_j ∖ (𝔪_i ∪ 𝔮₁ ∪ … ∪ 𝔮_r)，其中 𝔮_k 是 f 的极小素理想。素避免定理适用，因为 ht 𝔮_k = 1 < ht 𝔪_j。再取 𝔮 为 g 的、含于 𝔪_j 的极小素理想即可。

加上"同一分支、维数 ≥ 2"之后（例如 𝔸² 上两个不同闭点），"S_i 不必是开子概形"这个结论仍然成立。

## S2

**结论和图追逐都正确。**
- 由于 S_i→S 是单态射，有 S_i×_S S_i ≅ S_i，所以对角分量不提供任何条件。
- 底行由 S1 给出。图追逐中，中间竖直映射是同构，右侧竖直映射是单射，由此推出满射。这一步无误。

**缺口：** 答卷直接把"使序列正合的覆盖 (U,V)"称为有向系统，并且断言 U、V 能同时收缩，都没有验证。下面补上：
- S 的点恰好是 x₁ 或 x₂ 的一般化，而开集在一般化下封闭。因此任意开邻域 U∋x₁、V∋x₂ 必然覆盖 S。
- **有向性：** 给定两个好覆盖 (U,V) 和 (U′,V′)，则 (U∩U′, V∩V′) 仍是分开两点的覆盖。由题设，可以把它收缩成好覆盖 (U″, V∩V′)，其中 U″ ⊂ U∩U′。
- **余终性：** 对任意一对邻域 (U₁, V₁)，先去掉另一点的闭包使其分开两点，再用题设得到好覆盖 (U, V₁)，其中 U ⊂ U₁。

补上这两点后，三个余极限分别等于 H(S₁)⊕H(S₂) 和 H(S₁×_S S₂)，答卷的结论成立。

## S5（主要问题）

**1. "稠密开浸入单射性定理"是错的。**
- 取 F = Pic = CH¹。它是 Cor_k 上的同伦不变函子：转移由 α^*(z) = p_{Y*}(α·p_Z^*z) 给出（Fulton 精细交积，α 在 Y 上有限，因而在 Y 上真）；同伦不变性见 Fulton Thm 3.3；在完满域上它就是 H^{2,1}_M。
- 但 Pic(ℙ¹) = ℤ → Pic(𝔸¹) = 0 不是单射。

答卷的纤维化草图实际上只能在有限个点的某个邻域内成立，也就是半局部单射性定理 F(S) ↪ F(k(S))，却被写成了整体结论。

**2. 由此推出的两个推论也都是错的。**
- "F 是 Zariski 分离预层"：Pic(ℙ¹) 在两片 𝔸¹ 上的限制都是 0，但它本身不是 0。
- "对任意开集 U，F(U)→F_Zar(U) 是单射"：由于线丛 Zariski 局部平凡，Pic_Zar = 0，于是 η_{ℙ¹}: ℤ→0 不是单射。

**3. S2 所需的三个前提都没有得到有效证明。**
- η_S 是单射本身是对的，但需要半局部单射性定理，答卷没有给出。
- η_T（T = S₁×_S S₂，以及归纳中的 S′×_S S_n）是单射：答卷的依据正是上面那条错误的分离性，因此没有证明。
- Mayer–Vietoris 收缩引理是整题的核心，答卷只有"有限对应移动技术"之类的描述和无法核实的引用编号（"MVW Lemma 4.22/5.7"），没有证明，也没有说明适用条件。

**4. 域的条件没有处理。** 题目允许任意域 k，而答卷所引的 Voevodsky 结论（F_Zar 同伦不变、F_Zar = F_Nis）在文献中以 k 完满为前提；标准三元组和 Gabber 型论证需要 k 无限（有限域需要额外的转移论证）。答卷对此只字未提。

**5. 归纳步骤也有缺口。** 底行用的是以 S′ 和 S_n 拼接 S，这并不是 S1 的原样结论，需要类似的论证。右侧竖直映射是单射，同样依赖错误的分离性。

**答卷中正确的部分：**
- 单点情形 n = 1（预层与其层化的茎同构）。
- "𝔸¹-同伦的对应诱导相同的映射"。

**可行的修补路线（供核查用，不是答卷内容）：** 设 k 完满，并承认两条标准定理：F_Zar 是同伦不变的带转移预层；同伦不变带转移预层满足半局部单射性。
1. 令 K、C 分别为 F→F_Zar 的预层核与预层余核。它们都是同伦不变的带转移预层，并且 K_Zar = C_Zar = 0。
2. 因此 K、C 在 S 的一般点处的茎为 0，半局部单射性给出 K(S) = C(S) = 0。
3. 滤过余极限正合，所以 η_S 是同构。

由此看，结论本身没有问题，但答卷的论证不能成立。
