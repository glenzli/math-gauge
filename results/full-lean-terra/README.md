- 请求模型 `gpt-6.1-terra`，推理档位 `max`；十个新独立会话，每题恰好一份有效答卷，stdin 仅为原题字节。没有历史上下文、参考答案、补充指令或工具反馈。

- 每条 AI 审核绑定实际 response SHA-256；Lean 证明的是作者形式化陈述，不声称模型提交了 Lean 证明。
