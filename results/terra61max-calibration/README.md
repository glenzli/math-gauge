## 本轮学到的设计问题

1. 短题及经典加难题容易饱和。长链题的20个评审义务被压缩成了一篇短而完整的证明；节点多不等于有效推理深。
2. 研究轨迹中，模型识别原零距商的定义域障碍，构造所有未来词的同余，并从未来截断观察的上确界构造有限个新增规范，使商分离、原数值仍保留。这是有证明的派生结构，不能因为超出内部基线就拒绝。
3. 模型区分了即时分量和全部未来分量、有限规范指标和有限状态、存在性与可计算性。`R²` 只用于实现合法反例，未替换一般空间的假设。
4. 三轮仍很短；最后只请求标准库形式化核心，并允许披露剩余义务。这没有测试“在完整项目和充分工具下，把整套正文100%形式化”的任务。
5. 继续降低提示、增加字数或一直换题直到出错，不能代替可复现的难度校准。下一步应由作者选取更贴近真实长期协作的公开历史场景，固定原始目标、上下文长度和全套交付义务，再安排同源配对及重复试验。

设计协议见 [长链与持续研究评测](../../protocol/layered-design.md)。本轮在预定的三轮轨迹结束后停止，等待作者复核；没有启动后续自动任务。

## 设置与复现范围

每个独立任务请求 `gpt-6.1-terra`、`max`、`fork_turns=none`；作答者只被允许访问题包和自己的输出。前两组各为一批，组内各题共享同一作答上下文；长链题单独开始；研究轨迹在全新上下文起步后保留自己的三轮历史。没有提供父对话、OET 项目源码、参考答案或评分标准，没有中途数学反馈。模型供应商快照、实际 token 和费用未由工具返回，不补填。

文件访问限制是指令层隔离，非操作系统隔离。本轮由子agent工具实际生成输出，目录中的 `external-agent` 记录是如实导入的外部运行；通用 runner 用于题包投影、响应绑定和单轮报告，不把回放脚本冒充模型调用。多轮为研究性外部记录，尚无通用供应商多轮适配器。Lean 由父任务在全部作答结束后检查，编译器没有供作答者使用。

全部新增题与可公开结果仅使用已核实的公开卷I结构及独立构造；开发仓库历史的具体取样另存本地研究材料。此次本地修改尚未提交或推送。
