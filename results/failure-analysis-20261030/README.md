# 两模型未通过项复核与下一批出题依据

本次复核覆盖原 41 题比较中的 **15 份未严格通过答卷、14 道不同题**。Terra 只有 F104；Gemini 有 14 项，其中 F104 重合。原始比较仍为 Terra **40/41（97.56%）**、Gemini **27/41（65.85%）**。这里没有新模型答题、没有覆盖原答卷或追改成绩；新增的是逐题诊断和明确标记的修改副本实验。结论属于 AI 审核，人工审定状态不变。

主要判断：Terra F104 是可局部修复的 Lean 实现失败；Gemini 的失分则同时包含数学推理错误、Lean 实现错误和服务未交付。不能把这些错误合成一个“数学不会”的原因。

## F104：Terra 到底差在哪一步

题目要求为任意映射族 `fᵢ : X → Yᵢ` 构造使全族连续的最粗拓扑，证明唯一性及完整的映射充要性质。Mathlib 的拓扑序按开集反向包含，`⊥` 为离散拓扑。原附件对所有可行拓扑取 `sInf`，而离散拓扑总可行，因此所得是离散拓扑，不是所求最粗拓扑。这是故意设置的形式化失配，不是题目坏了。

Terra 准确指出这个问题，给出空指标族、两点空间的边界反例，并另行构造：一个集合开，当且仅当它在每个可行拓扑下都开。它据此证明实现性、最粗性和唯一性，再借助沿 `g` 的 coinduced 拓扑完成反向连续性。全程保留任意指标、依赖值域和原有量词，没有增加分离性、有限性或非空性。

原答卷在一个额外的诊断引理处停止：

```lean
  · exact bot_le
```

固定 Lean 4.29.1 / Mathlib `5e932f97dd25535344f80f9dd8da3aab83df0fe6` 报告无法合成 `OrderBot (TopologicalSpace X)`。最小独立探针也复现此现象，同时能合成 `CompleteLattice (TopologicalSpace X)`。因此这里不能解释为不存在最小拓扑，也不是缺缓存或超时。

本次只在诊断副本中把这一行替换为显式使用已存在的完整格实例：

```lean
  · exact TopologicalSpace.instCompleteLattice.bot_le _
```

其余源码字节不变。结果为：

| 检查 | 原始交付 | 本次诊断副本 |
| --- | --- | --- |
| Core | 通过 | 通过 |
| Construction | 第 19 行编译失败 | 通过 |
| Candidate | 未执行 | 通过 |
| 全部声明公理审计 | 未执行 | 12 个声明全部通过；仅 `propext`、`Classical.choice`、`Quot.sound` |
| 是否模型新答卷 | 是，原冻结答卷 | 否，是审核者修改的副本 |

证据：[唯一差异](f104-diagnostic/minimal-change.patch)、[诊断报告](f104-diagnostic/report.json)、[全声明审计](f104-diagnostic/logs/Audit.log)、[最小探针](f104-diagnostic/probe/Probe.lean)。诊断直接在全新构建目录调用固定 Lean，使用原冻结依赖搜索路径；不是一次新的隔离答题试验，也不计入模型通过率。

结论应是：**原始正式交付没有通过；数学解法及主结论对齐；一个证明表达式的局部修改已足以使完整交付通过。** Terra 明确说明自己未运行编译，因此也不应附加“谎称编译通过”的判断。

[独立二审](f104-independent-review.md) 另外核对了唯一差异、完整语义、12 个审计声明及保存日志的身份，没有重跑或改写原成绩。[证据校验](validation.json) 对本次报告引用及诊断副本的 169 项散列检查均通过，涉及 131 个独立文件。

Gemini 的 F104 不宜作同样的“一行即全好”结论。其第一个错误是 `construction_bound t f s hs hU` 漏了集合 `U`。本次独立副本补为 `… hs U hU` 后，Construction 通过，但 Candidate 第 42 行进一步报未知常量 `TopologicalSpace.induced_iInf`。本次没有继续修复，没有全声明审计成功结论。见[该副本报告](f104-gemini-diagnostic/report.json)和[后续失败日志](f104-gemini-diagnostic/logs/Candidate.log)。

## 两项需要单独保留的题目质量边界

**R005。** 旧题竞争函数的值域约定不够明确，已有 0.3.1 独立补测，不把新版通过回填旧 41 题。补测 Gemini 的主任务被接受，但一条额外分离论证仍有符号错误；正确的独立闭包路线支持主结果。故“主任务通过”和“全文每一个旁支都正确”仍需分开。详见数学报告的补测节。

**P003。** 候选不需要提交 Lean，失败来自书面几何论证。作者已编译的 Lean 只支持半局部化、余终性及图追等辅助模块，未集成全部几何输入与完整主定理。不能以这些辅助模块通过，声称主命题已完全形式化；也不能因候选缺少 Lean 而扣分。

## 对下一批题的影响

1. 加入整章形式化，给明确的章外背景，要求自己建立本章定义、接口和全部证明。语义覆盖与编译分别审核。
2. 给长任务一个事前固定的编译反馈轨道，同时保留无反馈轨道。F104 说明二者测到的能力不同，不能混报。
3. 书面题增加局部到整体的实质桥梁：相容选择、原空间与完备化、闭值域与稠密像、统一量词、有限层回缩与全局分类。短反例合法完成原题时仍应接受。
4. 10–20 个证明应围绕真实依赖组织。R008 已经是复合分类题，Terra 已通过；简单拆成更多小问可能送出证明路线，反而降低难度。
5. 为整链同时报告完整完成率、逐义务完成率、互相独立的根因和后续传播。正确前缀救援只能作为另一次诊断，不回填原成绩。
