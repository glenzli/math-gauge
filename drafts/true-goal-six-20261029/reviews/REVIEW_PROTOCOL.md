# 本组六题的复核边界

本文件给评审者使用，不属于候选输入。

1. 先只读题面，记录它实际要求的结论、能找到的最短合法路线，以及定义或量词是否不够明确。不能把参考稿的步骤数作为评分要求。
2. 再核对参考证明：每个主目标都要闭合；错误捷径的反例必须满足该捷径在题目中实际可用的前提。指出某个更强命题失败不等于证明原目标。
3. 对照 Lean 的实际类型、假设和结论，追踪关键定义及辅助定理。只证明公式、特殊情形或带目标证书的抽象引理，不能算题面已经完整覆盖。
4. 给出语义审阅意见后，用同一套仓库验证器从精确源码重新编译。审计全部 MathGauge 声明及递归公理依赖，不只审计选出的主定理。
5. 数学审阅和形式化对应结论绑定 task.md、reference.md、rubric.json、COVERAGE.md 及所有 Lean 源码的 SHA-256。修订使对应审核失效，须复核改动与受影响结论。

通过标准允许任何条件忠实、完整有效的短证明。候选无须复述作者的反例或识别全部预设陷阱；只有实际使用错误推断才构成相应错误。明确加条件的旁支成果与冒称完成原目标分别评判。

本轮不进行候选模型试跑。作者和独立评审者均为 AI；human 保持 pending。六题是否比已有题更能区分特定模型，留待冻结版本后的实际校准。
