# MG-GF102　商环塔的稳定、比较与自然性

版本 0.1.1。

设 R 是任意交换含幺环，I⊆R 是理想。令 Q_n=R/I^(n+1)、q_n:R→Q_n、J_n=q_n(I)，m≤n 时令 ρ_mn:Q_n→Q_m 为自然商映射。附件 Core.lean 给出这些对象的 Lean 定义。所有层数为自然数，不预设 R 非零、I 真、Noether 性或有限生成性。

逐阶段提交答案。后续可以引用已经证明的结论，但须明确引用的是哪条结论，并核对它的全部条件。判断题须先给结论；成立时给证明，不成立时给出满足本阶段全部条件的反例。每个阶段均须作答。

按各阶段要求提交一套可共同编译的完整 `.lean` 源码，并给出阶段与声明名称的对应表。源码须保留题面的对象、条件、量词和结论；不得使用 `sorry`、`admit`、新增公理或把待证结论作为结构字段/假设。可以增添辅助定义和定理。

必交源码文件：`Answer.lean`。可附加辅助 `.lean` 文件，但不得省略上述文件；未改动的输入依赖也须一并提交。

固定环境：Lean 4.29.1（提交 `f72c35b3f637c8c6571d353742168ab66cc22c00`），Mathlib 提交 `5e932f97dd25535344f80f9dd8da3aab83df0fe6`。附件仅包含下列输入文件：`Core.lean`。

## S1　平方零理想的塔

暂设 I²=0。确定 Q_0 及所有 n≥1 时 Q_n 与 R 的关系，并解释对应的 J_n 和相邻过渡映射。

## S2　任意理想的三项相容性

删除 I²=0。证明 J_n^(n+1)=0、ρ_mn(J_n)=J_m、ρ_lm∘ρ_mn=ρ_ln。所有声明须覆盖本题最一般的 R 和 I。

## S3　最终从源环无损进入各层

判断：I 幂零，当且仅当存在 N∈ℕ，使所有 n≥N 时 q_n 都单射。这里要求的是指定的 q_n，而非只要求抽象环 Q_n 与 R 同构。

## S4　第零层信息的延伸

现在比较 (R,I) 与 (S,L)。若已知第零层 R/I 与 S/L 同构，是否能推出对所有 n，R/I^(n+1) 与 S/L^(n+1) 都同构？

## S5　有指定同态时的自然性

补充指定环同态 φ:R→S，满足 φ(I)⊆L。构造所有层的诱导同态，并证明它们与商映射及过渡映射相容。说明 S4 的信息缺口是否因此自动得到同构意义上的解决。

## S6　完整 Lean 实现

在 Answer.lean 中实现 S1–S5 的数学结果，包括 S4 的完整判定及相应的证明或反例。可以用 ZMod、理想商或经证明等价的具体环模型；使用具体实例时须验证该阶段的全部条件及相应结论。提交逐阶段声明对应表。
