## S1　平方零理想的塔

Q_0=R/I。若 n≥1，则 I^(n+1)⊆I²=0，所以 Q_n=R/0，自然 q_n 为同构；该同构下 J_n 对应 I。两个层数都≥1 的过渡映射对应 R 的恒等映射；从任意 n≥1 到第 0 层的过渡对应 R→R/I。没有断言 q_0 单射，除非 I=0。

必需证据：确定 Q_0 以及 n≥1 的 Q_n；说明 n≥1 时 q_n 是环同构；给出这些同构下 J_n 和过渡映射的解释。

关键错误：把平方零当成后续一直保留的假设；未区分第 0 层与其余层。

## S2　任意理想的三项相容性

自然理想包含 I^(n+1)⊆I^(m+1) 给过渡映射。商映射理想像满足 (q_n(I))^(n+1)=q_n(I^(n+1))=0。ρ_mn∘q_n=q_m，故理想像相等；复合式在每个 q_n(a) 上都等于 q_l(a)，由 q_n 满射得相等。该阶段保留原生成题的完整最弱核心。

必需证据：证明 J_n^(n+1)=0；证明像相容和过渡复合；证明映射存在，不增加源幂零假设。

关键错误：仅对平方零情形实现；把 n+1 次界改成未指定指数。

## S3　最终从源环无损进入各层

成立。若 I^e=0，取 N=e，则 n≥N 时 I^(n+1)⊆I^e=0，ker q_n=0，故单射。若给 N，取 n=N，单射给 I^(N+1)=ker q_N=0，故幂零。N=e 不是最优但足够；e=0 时 R 为零环同样有效。不能换成“所有过渡同构”：I=R 时零环塔恒定但 R 非零时 I 不幂零。

必需证据：证明 I 幂零当且仅当存在 N 使所有 n≥N 时 q_n 单射；说明 N 与幂零次数的关系；不把过渡同构替换成源映射单射。

关键错误：偷换成商环抽象同构；未处理所有足够高层的量词。

## S4　第零层信息的延伸

不能。取 R=ℤ、I=(2)，S=ℤ/2ℤ、L=0。第 0 层都是 ℤ/2ℤ。第 1 层分别为 ℤ/4ℤ 与 ℤ/2ℤ，前者有四个元素而后者有两个，故不同构；也可用前者 1+1≠0、后者 1+1=0 证明。已知模 I 的信息没有指定更高幂理想的数据。

必需证据：判断第 0 层同构是否保证全部同层商环同构；给出明确第 0 层同构以及某个更高层不同构的证明。

关键错误：反例只展示不同的选定映射而未排除抽象同构；擅加理想的更高阶结构数据。

## S5　有指定同态时的自然性

由乘法与和的保持，φ(I^(n+1))⊆L^(n+1)，故 φ_n(q_n^R(a))=q_n^S(φ(a)) 良定义。源商方块按定义交换。若 m≤n，两条到 Q_m(S,L) 的复合在代表元 a 上都给 q_m^S(φ(a))，满射性给同态相等。此条件保证一族相容同态，不保证同构；S4 的例子可取 φ 为模 2 映射、L=0，其高层诱导仍非单射。

必需证据：构造每层 φ_n:Q_n(R,I)→Q_n(S,L)；证明与源商映射和全部过渡映射相容；说明该条件只保证同态而不保证同构。

关键错误：只验证 n=0；把 φ(I)⊆L 错误当作 φ_n 双射的充分条件。

## S6　完整 Lean 实现

实现路线：理想像幂公式加商核处理 S2；Ideal.Quotient 的核刻画加幂的单调包含处理 S1、S3；S4 可使用 ZMod 4 与 ZMod 2 及显式整数商同构，或在商环里证明 2 的像分别非零与为零；S5 用商映射 lift/factor 并按代表元证明交换图。编译时须把 S1 的假设只放在其局部声明，不让它污染 S2–S5。具体 Lean API 不固定，数学义务固定。

必需证据：Answer.lean 完整形式化 S1–S5 的正结论和反例；覆盖全部三项原目标而非只实现商对象；声明对应表、实际编译与公理审计。

关键错误：只交类型或证明草图；用 I 幂零作为整个文件的共享变量假设；只声明反例结论但不验证非同构。
