# 条件连续性的设计与后续校准

本批测的是在持续推理中保持当前数学合同：前序结论既可能真正可用，也可能只在前序额外条件下可用。题面必须说明条件变化，难点来自论证迁移是否有效，不能来自含糊措辞。参考依赖图只是一种可行组织，不要求候选重复作者路径。

## 机制组合

| 机制 | 本批实例 | 审核关注点 |
|---|---|---|
| 量词及一致性 | GR013、GR102、GF107、GF111 | 每个对象有界与统一界；先固定次数还是先取极限 |
| 对象或赋值范围变化 | GR014、GR015、GR105 | 全乘积与有限支持、原空间与完成、点值与商值 |
| 有限记录到整体 | GR006、GR007、GR016、GR101 | 有限核、有限呈示、稳定像、相容数据各自承担什么作用 |
| 正确结论但旧证明失效 | GR007、GR014、GF108 | 不把一条证明路线需要的条件当作定理必要条件 |
| 必要、充分与反向 | GR019、GR020、GF109、GF112 | 逆命题、组合之后反推因子、量化常数的端点 |
| 精确与近似 | GR004、GR005、GR105 | 闭包与原像、下确界与取到、强收敛与范数收敛 |
| 自然运输与自然选择 | GR006、GR007、GR102 | 解空间有自然同构不等于存在首选解 |
| 特定映射与抽象同构 | GF102、GF103、GR010 | 要求的是指定箭头、全部测试对象，还是仅同一抽象类型 |
| 局部估计与整体估计 | GF106、GP003、GR017 | 覆盖是否保留指定点、局部选择能否同时拼接 |
| 空集、零权重、无穷 | GF105、GF108、GF112、C002、C003 | 边界是合法数据；不得用形式系统默认值扩大数学定义域 |
| 自然语言与Lean范围 | GF101–GF112、C002、C003 | 可编译类型是否保留实际结构、量词、域及结论强度 |

这些不是互斥题类，同一题组可以组合几种机制。110个转折标签只服务评审归因，不能当作110个独立统计样本。源母题或同一数学机制的多个版本也有相关性。

## 难度与归因

新题有实质延伸，但尚无新模型试跑，不能从长度或作者感觉宣称实际更难。后续应在固定模型身份、推理配置、同等输入、足够容纳整份题面及完整交付的预算下先校准。输出截断、服务错误、Lean编译错误、数学错误与题包问题分开；不把无法交付完整代码的预算设置冒充数学难度。

主实验仍以整组一次作答为单位。若要测“前序是否诱导条件误用”，另立配对实验：同一关键阶段单独给出，与带前序题组给出比较；对照需要提供同样可用的定义及已证结论，以区分信息增益与条件携带错误。也可独立版本化排列顺序或交错真/假转折。配对结果按母题分析，不能把同一次长答卷拆成很多独立样本来夸大显著性。

无编译反馈的源码生成和允许Lean迭代反馈的工程任务应分别冻结协议、分别报告。本批已有可接收的题面与评分约束；具体模型预算和反馈方式在新一轮实验前登记，不追溯修改既有成绩。
