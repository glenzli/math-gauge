# MG-GF111　扩展非负界、有限子域与统一常数

版本 0.1.1。

X 是任意集合，d,e:X→[0,∞]（Lean 的 ENNReal）。Bound(c) 表示 ∀x，e(x)≤c·d(x)，有限系数指 c≠∞。记 Z 为 d(x)=0⇒e(x)=0 对所有 x 成立，H 为 d(x)=∞⇒e(x)=0 对所有 x 成立，r=sup{e(x)/d(x):0<d(x)<∞}，空集上确界为 0。采用 ENNReal 的运算约定，特别 0·∞=0。LeastFinite(c) 表示 c 有限、满足 Bound，且不大于任何其它有限可行系数。附件给出一份 Lean 实现。

逐阶段提交答案。后续可以引用已经证明的结论，但须明确引用的是哪条结论，并核对它的全部条件。判断题须先给结论；成立时给证明，不成立时给出满足本阶段全部条件的反例。每个阶段均须作答。

本组交付逐阶段书面论证、源码语义审计及题面要求的数学修复路线；无需提交新增或修复后的 Lean 源码。

固定环境：Lean 4.29.1（提交 `f72c35b3f637c8c6571d353742168ab66cc22c00`），Mathlib 提交 `5e932f97dd25535344f80f9dd8da3aab83df0fe6`。附件仅包含下列输入文件：`ExtendedBounds.lean`, `CoefficientClassification.lean`, `BoundaryExample.lean`。

## S1　正有限分母域

先假设每个 d(x) 都严格正且有限。证明对所有扩展非负 c，Bound(c) 当且仅当 r≤c，并核查空域。

## S2　加入零分母点

允许零分母，但仍不允许无限分母。证明所有 c 的可行性分类，并明确零分母点的作用。

## S3　完整域与最小值取得

恢复全部 d,e。证明所有 c 的可行性分类、有限可行系数的存在判据、有限最小值的存在判据及其值。

## S4　每个有限子域可控

若每个有限子域 F⊆X 都有某个有限可行系数 c_F，是否必有一个适用于整个 X 的有限系数？

## S5　统一有界的有限子域证据

改为存在固定有限 C，使每个有限 F 都能选到 c_F≤C。判断 C 本身是否必是全域可行系数。

## S6　完整分类代码审计

审计附件的所有分类与边界例子。特别比较“有限系数存在”“有限最小系数存在”和本组有限子域命题的不同量词。
