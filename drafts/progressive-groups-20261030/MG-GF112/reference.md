## S1　良好分母下的最优界

每点的除法等价给 Bound(c)↔r≤c，所以 c=r 可行且最小，给定 r≠∞ 保证有限。无需某点比值达到 r：上确界自身就是所有比值的上界。空域 r=0，所有 c 可行，最小为0。

必需证据：证明 Bound(c)↔r≤c；证明 r 是最小有限系数；空域最小值为0。

关键错误：默认上确界一定有限而未用给定条件；引入 X 有限或上确界在某点取到。

## S2　完整分类

按 d=0、0<d<∞、d=∞ 三类分点：第一类要求 e=0；第二类与比值≤c 等价；第三类仅 c=0 时要求 e=0。有限存在的必要性由 r≤c<∞，充分性取 r+1>0 且有限。若 r 有限并在 r=0 时 H 成立，则分类说明 r 可行且最小。反向最小 c 若大于 r，可在 r 与 c 之间选有限正 b，b 满足分类，违背最小性；故 c=r，零端点又给 H。本阶段完整保留原生成题核心。

必需证据：证明全体 c 的精确 Bound 分类；证明有限系数存在的充要条件；证明最小有限系数存在的充要条件及唯一值。

关键错误：用 S1 的除法规则处理零或无限分母；只给充分条件或只给正 c；假设最小有限系数总能取得。

## S3　有限可行但不取得的端点

没有零分母点，Z 真；唯一点 d=∞ 而 e=1，H 假；没有正有限分母点，r=0。S2 给 Bound(c)↔c≠0，所以有限可行恰是 0<c<∞。若 c 为这样的候选最小值，c/2 仍正有限且小于 c，因此可行并矛盾。也可直接用 S2 的最小存在判据 r=0 且 H 假。

必需证据：计算 Z、H、r；证明有限可行系数恰为正有限 c；证明没有最小有限系数。

关键错误：把 r=0 直接说成最小可行值；只说明0不可行而未排除任意正最小值。

## S4　两个系统的不交并

是。全称量词在不交并上拆成两支，所以并系统可行当且仅当两支都可行。由 a≤max(a,b)、b≤max(a,b) 及乘法单调性，两支在最大值处均可行；两个数有限故最大值有限。任意并系统有限可行 c 对两支也可行，由各自最小性 a≤c、b≤c，因此 max(a,b)≤c。

必需证据：证明并系统 Bound(c) 当且仅当两个分支均 Bound(c)；证明 max(a,b) 有限且可行；证明它不大于并系统任何有限可行系数。

关键错误：只证明并系统有界而没证明最小；错误要求两个最小系数相等。

## S5　最小值能否反向分解

不必。第一支取 S3 的 Unit、d=∞、e=1，可行系数为所有正数，无最小有限值。第二支取 Unit、d=1、e=1，可行系数为 c≥1，最小为1。并系统须同时满足两者，恰为 c≥1，故最小有限值1存在。第二支的正下界消除了第一支的零端点不取得现象。

必需证据：判断是否可反推每个分支都有最小有限系数；给出两个分支及并系统最小值的完整反例；说明另一分支如何排除未取得端点。

关键错误：把 S4 的充分前提当成必要条件；只给第一支无最小而不验证并系统有最小。

## S6　完整 Lean 分类与组合

先按 S2 建立 Bound 精确分类与最小存在/取值定理，S1 和 S3 是其特例。对 Sum 定义分段 d,e，逐构造元证明 bound_sum_iff；用系数单调性与 max 的序性质证 S4。S5 复用 S3 第一支及 d=e=1 的第二支，验证并系统可行 iff 1≤c，导出最小1，同时引用第一支无最小。最小值证明中的严格序 API 可替换，但不得靠未验证类型推断或新增假设跳过 r<c 时的中间系数。
