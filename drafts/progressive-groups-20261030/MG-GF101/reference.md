采用逐阶段判卷：每一阶段须满足所有 required_evidence 且不触发任一关键错误；数学分数、语义对齐、Lean 编译分别记录。完整有效的替代论证、等价表示及不同正确 Mathlib API 均可接受。某一步的错误可以影响依赖它的后续结论，但后续独立有效的重新证明仍按本阶段证据给分。整组 pass 必须各阶段均通过。

## S1　商映射下的幂零判据

商映射对理想乘法及幂保形，故 (q_B(A))^r=q_B(A^r)。对任意理想 L，q_B(L)=0 当且仅当 L⊆ker q_B=B，代入 L=A^r 即得。r=0 时左边是 R/B 的单位理想为零，等价 R/B 为零环；右边是 R⊆B，即 B=R，仍等价。这里没有从 q_B(A) 幂零推得 A 幂零。

必需证据：证明 (q_B(A))^r=q_B(A^r)；证明 (q_B(A))^r=0 当且仅当 A^r⊆B，包含 r=0。

关键错误：无依据地把像的幂零反推为源理想幂零；遗漏零环或 r=0。

## S2　任意理想的有限层

I^(n+1)⊆I^(m+1) 保证 ρ_mn 良定义，且 ρ_mn(q_n(a))=q_m(a)。S1 取 A=I、B=I^(n+1)、r=n+1，得所需精确次数。像理想等式由 ρ_mn∘q_n=q_m 及理想像的复合性得到。复合式在每个代表元 a 上两边都是 q_l(a)，q_n 满射所以环同态相等。这正是旧题的最弱条件核心。

必需证据：证明 J_n^(n+1)=0；证明 ρ_mn(J_n)=J_m；证明 ρ_lm∘ρ_mn=ρ_ln。

关键错误：额外假设 I 幂零、Noether 或真理想；仅证明某个未指定次数幂零而不证明 n+1 次。

## S3　过渡映射的核

每个 q_m(a) 是 ρ_mn(q_n(a))，故满射。q_n(a) 在核内当且仅当 a∈I^(m+1)，因此 ker ρ_mn=q_n(I^(m+1))。核为零由 S1 的 r=1 情形等价 I^(m+1)⊆I^(n+1)；与反向的自然包含合并即理想相等。满射环同态核为零当且仅当双射，故给出同构充要条件。

必需证据：证明 ρ_mn 满射；证明 ker ρ_mn=q_n(I^(m+1))；证明 ρ_mn 为同构当且仅当 I^(m+1)=I^(n+1)。

关键错误：把 J_n 幂零当成 ρ_mn 单射；忘记 I^(n+1)⊆I^(m+1) 后错误处理核的逆像。

## S4　统一有限层界

不必然。取 R=ℤ、I=R、N=1。任意 n 时 I^(n+1)=R，Q_n 为零环，J_n=0，所以统一次数 1 有效；而 I^k=R≠0 对所有 k 成立，源理想不幂零。S1 只能给 I^N⊆I^(n+1) 对所有 n，不能在没有额外条件时把右边的交集替换为零。S3 中每个过渡映射事实上都是零环间同构，这也不会推出 I 幂零。

必需证据：判断该条件是否推出 I 幂零；给出所有 n 同时满足条件而 I 不幂零的反例；解释单层与源理想的逻辑差别。

关键错误：把 ∀n∃N_n 与 ∃N∀n 混同；反例未满足统一 N 条件。

## S5　分离条件下的统一次数

成立。正向用 S1 得 I^N⊆I^(n+1) 对每个 n 成立，故 I^N⊆交集=0。反向 I^N=0⊆I^(n+1)，逐层用 S1。N=0 时两边都等价 R 为零环；分离条件仍按题面使用。不需要证明交集定理，因为交集为零是本阶段明给的假设。

必需证据：证明 (∀n,J_n^N=0) 当且仅当 I^N=0；保留同一个 N，不仅证明某个幂零次数；处理 N=0 的零环边界。

关键错误：只证明逐层各自存在不同次数；擅用 Noether 性或 Krull 交集定理。

## S6　完整输入的语义审计

整体不对齐。SourceData I 要求已经给定 I^e=0，S2 未假设且 ℤ 的单位理想反驳普遍可构造性。transport 与 Candidate 的幂零项在该强条件下有效，却仅输出 IsNilpotent J_n，没有明给的 n+1 次界。修复应直接使用 S1 的商核判据，不先证明源 I 幂零。过渡像与复合两项使用商映射本身，完全覆盖 S2。S4 的统一商幂零不能填补 SourceData；S5 加分离性后可从统一界构造，但这些都不是 S2 条件，不能追溯添加。编译只检验所写强条件下的证明，独立于该语义判定。

必需证据：逐一核对 Candidate 三项与 S2 的全部条件及结论；指出 SourceData 的数学含义和调用义务；区分精确次数、存在某次数和真正的可编译性；给出无需 SourceData 的正确修复路线。

关键错误：把 SourceData 当作无条件可构造的证书；把源码可编译等同 S2 已证明；误判正确的像及复合两项。
