# 来源与改编边界

本题为公开数学结构的独立构造，不是对 OET 现有正文或 Lean 的错误指控。没有复制未公开 OET 内容。

OET 公开第一卷第2章明确使用扩展非负值上界，并区分合法证书与各条目下确界的取到。这里仅取其公开结构与约定作为背景，把单分量上界抽象为任意集合上的数值数据；完整可行系数及最小值判据在本题独立推导，不引用未公开卷的结论。Mathlib 的 ENNReal 定义与除法定理是可核对的标准依赖。

确切来源 URL、提交、许可和已读取源文件 SHA256 在 `sources.fragment.json`。OET 来源从本地公开仓库的确切 Git 对象读取，网络缓存无法抓取该路径；没有用工作区未提交文本替代公开版本。题目和源码是独立改编，引用不表示上游作者审定本题。

所有来源、改编说明、参考、评分、审核和配对信息均不进入候选投影。公开题不能保证模型未见过；同母题的变体不得跨训练/测试拆分。
