# MG-P003：完整形式化仍需的命题

以下不是 Lean 假设清单；代码没有用这些未证明命题生成完整目标。可以用适用的现有完整定理或另一条已证明路线取代 G1–G3，但必须保留题面的全部量词与典范箭头。

1. **领域与有限对应。** 在实际任意域 k 上，用真实光滑、分离、有限型概形作对象；同态是有限对应自由阿贝尔群，复合是通常交积和推前。建立图函子、加性反变预层及对真实投影 `Y × A1 → Y` 的同伦不变性。本固定 Mathlib 快照的定向源码搜索没有找到这套有限对应/PST 接口。公开 Motivic 库已提供这类实际结构，但版本与依赖闭包尚未在本项目重放核验。

2. **环境与邻域延拓。** 证明任意光滑拟射影 X 的有限点集有共同仿射开邻域，仿射邻域余终；题面 `colim H(U)` 与选定有限素理想局部化的延拓值自然一致且不依赖仿射选择。对闭点分块的 `S1,S2` 及真实纤维积 `T=S1×S S2`，证明分离开集对给出相应余极限，且有限型覆盖可下降并再次缩小。现有真实 `Spec(Localization ...)`、谱像和邻域拓扑定理只覆盖此项的一部分。

3. **G1：半局部泛点单射。** 对任意域上的实际 HI 带转移预层 E，光滑概形在有限点处的半局部化 S 和稠密开 W，证明 `E(S) → E(W)` 单射；特别地到各不可约分支泛点值之和单射。本题不需要纯性。外部库中已检查的“在每个选定单点附近为零”与“已经分离的预层在稠密开上检测”不能直接证明未分离 E 的同时有限点版本。

4. **G2：Zariski 分离商。** 真实逐对象局部零子群须被所有有限对应拉回保持，商 `sF` 仍具有转移和 A1 不变性；建立与原 F 的层化自然同构，并利用 G1 证明 `F(S) → sF(S)` 双射。公开库的实际 Nis 单位像之转移与 HI 不能在未证明拓扑比较时改名为 Zariski 分离商。

5. **G3：有限点收缩后的 Mayer–Vietoris 正合。** 对上述 S、每个二开覆盖 `S=U0∪V` 和实际 HI 带转移预层 E，构造 `U⊆U0`，保留 `S=U∪V`，并证明 `0 → E(S) → E(U)⊕E(V) → E(U∩V) → 0` 正合。必须适用于非环境闭点和有限底域；不能使用只保留单个点的主开收缩替代同时保留有限点集的构造。`exists_successful_separating_refinement` 只证明若已有某收缩性质，则成功阶段仍在正确索引系统内，不提供 G3。

6. **层化与组装。** 将光滑大位点底层预层的 Zariski 层化限制到 X 的小位点，并证明该过程与实际层化单位和所有邻域极限相容。完成第 2 项极限识别、第 3–5 项的实例化、对真实闭点数的归纳及典范交换图，最终声明任意域/任意有限点集的 `IsIso η_S`。当前单点定理已经针对真实小位点的邻域极限成立；一般有限点单位只已定义。

另一条可能复用路线是先在公开 Motivic 库中证明**所有**有限点局部化上的 Nis 单位同构。其单点特例可用于识别普通 Zariski 与 Nis 层化，再导出题面目标。当前已检查的 `isLocallySurjective_toNisnevichSheafify` 与 `exists_nisnevichImage_representing_cover` 只在真正的 Nis 覆盖上提供代表；它们不提供 Zariski 半局部邻域上的原像。无需 HI 就成立的这类局部表述不能承担缺少的几何步骤。

上述缺口限制的是当前可核验形式化覆盖，不否定原数学定理。原数学终点可正确引用 MVW 引理 22.12；其适用范围已在第二轮数学审查中核对。
