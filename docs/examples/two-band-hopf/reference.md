# 全局周期本征基不保证固定二带平凡化

## 1. 真实结论

题面第一项全部成立：w全域非零，z与U光滑周期，U∈SU(2)，H有精确能带−1与+1，三个坐标二维环面上的第一Chern数均为0。

第二项要求的固定二带保隙变形不存在。用T³的dk_1∧dk_2∧dk_3定向、S³在R⁴=(Re z_1,Im z_1,Re z_2,Im z_2)中的边界定向，以及Berry联络A=−iz†dz，有

Q=(1/(4π²))∫_{T³}A∧dA=−4。

任何题面允许的保隙路径都会保持这个值；常数模型的值为0。因此不能补出所要求的变形公式。

## 2. 原始模型、能隙和全局基

设实四分量

r(k)=(sin k_1,sin k_2,sin k_3,m(k))，z=r/|r|

其中后一个式子按C²与R⁴的指定对应理解。若r=0，前三个分量要求每个k_j等于0或π。令其中π的个数为j，则

m_j=7/2−2j+2(−1)^j，
(m_0,m_1,m_2,m_3)=(11/2,−1/2,3/2,−9/2)。

均不为0，故r全域非零。紧致性给出其范数的正下界，因而z、P、H光滑且周期。

P²=P、P†=P、rank P=1，所以H=I−2P的两个特征值精确为−1,+1。z是负能带基，另一列

v=(−overline{z_2},overline{z_1})^T

与z正交且归一化，det(z,v)=|z_1|²+|z_2|²=1。因此U=(z,v)∈SU(2)，并有U†HU=diag(−1,1)。

在固定全局基z中，Berry联络A=−iz†dz为全局实1形式，曲率F=dA。每个坐标二维环面都是闭流形，故由Stokes定理

(1/(2π))∫_{T²_{ij}}F=0。

这严格验证三个Chern数。它只说明占据线丛本身平凡，不说明该投影作为映入固定C²中的一条线的映射可缩。

## 3. 提升映射的精确度数

考虑z:T³→S³。取南极s=(0,0,0,−1)。其原像要求三个sin均为0且m<0，所以恰为

(π,0,0)，(0,π,0)，(0,0,π)，(π,π,π)。

在S³南极附近，前三个实坐标(x_1,x_2,x_3)为正向坐标，因为边界体积形式来自

ι_{−e_4}(dx_1∧dx_2∧dx_3∧dx_4)=dx_1∧dx_2∧dx_3。

在每个原像角点，归一化映射前三分量的Jacobian是

|m_j|^(−1)diag(cos k_1,cos k_2,cos k_3)。

其行列式非零，所以南极是正则值。四个点分别有j=1或3个π，局部度均为(−1)^j=−1。总度为

deg z=−4。

没有使用数值积分或无法检查的拓扑标签。

## 4. Berry积分的归一化与符号

在标准S³上令u=(x_1+ix_2,x_3+ix_4)，定义

α=−iu†du=x_1dx_2−x_2dx_1+x_3dx_4−x_4dx_3。

直接外微分和楔乘给出

α∧dα=2ι_R(dx_1∧dx_2∧dx_3∧dx_4)|_{S³}=2vol_{S³}，

其中R为径向单位法向。S³体积为2π²，所以

∫_{S³}α∧dα=4π²。

本模型A=z*α，因而按映射度积分公式

(1/(4π²))∫_{T³}A∧dA=deg z=−4。

如果改用另一支全局本征基z'=g z，其中g:T³→U(1)，则A'=A+β，β=−ig^(−1)dg是全局闭1形式。即使g没有全局实角函数，仍有

∫β∧dA=−∫d(β∧A)=0。

因此上述值与全局相位选择无关。F精确与A∧dA积分非零没有矛盾；A不是闭1形式，而A∧dA也不由“F精确”自动成为恰当的全导数。

## 5. 排除一般二带保隙路径

假设存在题目要求的H_t(k)。统一费米能隙使负能带秩一谱投影P_t(k)光滑周期，并满足P_0=P、P_1=diag(1,0)。这不要求H_t始终平带；负能谱投影可用统一围道的Riesz积分定义，也可用二阶Hermitian矩阵的显式谱投影公式。

下面直接构造其全局提升，不必仅引用Hopf丛的同伦提升定理。定义

K_t=[∂_tP_t,P_t]，∂_tV_t=K_tV_t，V_0=I。

K_t反Hermitian，因此V_t酉，且由参数依赖ODE理论光滑、周期。对投影求导有P_t(∂_tP_t)P_t=0和

[[∂_tP_t,P_t],P_t]=∂_tP_t。

于是∂_t(V_t†P_tV_t)=0，即P_t=V_tP_0V_t†。令z_t=V_tz，就得到从z开始的全局周期归一化占据基，并有P_t=z_tz_t†。

因此z_t是T³→S³映射的一条同伦，度数保持为−4。其终点却必须落在常数投影diag(1,0)的纤维上，即

z_1(k)=(g(k),0)，|g(k)|=1。

该映射的像包含于S¹，拉回任何S³体积3形式均为0，所以其度数为0。这与同伦不变性矛盾。

等价地，可将S³体积形式拉回T³×[0,1]并用Stokes定理直接证明端点积分相同。故没有任何满足所要求端点和统一能隙的二带H_t。

## 6. 常见候选公式的具体故障点

本节用于核查错误构造，不是题面提示。

- 线性Hamiltonian插值H_t=(1−t)H+t diag(−1,1)在k=(0,0,0)处失败。此时z=i e_2、H=diag(1,−1)，所以t=1/2时H_t=0，能隙闭合。
- 归一化线性基插值[(1−t)z+t e_1]/||…||在k=(5π/3,π,π)处失败。该点m=0、w=(−√3/2,0)，z=−e_1，t=1/2时分子为0。
- 通过全局连续矩阵对数收缩U也不可行。U在上一点等于−I，主对数已经遇到分支问题；更根本地，任何全局连续对数都将给出收缩，与已证非零度数矛盾，不能靠改局部分支消除全局障碍。

## 7. 可选的稳定化对照

如果额外增加一个空带，可定义

Z_t=(cos(πt/2)z_1,cos(πt/2)z_2,sin(πt/2))^T，
\widetilde H_t=I_3−2Z_tZ_t†。

Z_t全程归一化，谱始终为−1,+1,+1，从H⊕(+1)连到diag(1,1,−1)。这条路径合法，但违反题面固定两带的要求，因此不能作为第二项的答案。

它解释了背景错误的来源：线丛平凡与稳定平凡可以成立，但固定二带投影的同伦类仍非平凡。Hopf／非稳定两带拓扑是已知原理，degree−4的显式质量项不应被宣称为新拓扑理论。
