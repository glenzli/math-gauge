# 答卷审阅

当前四道AR任务要求审阅明确给出的原题与实际答卷。附件中的原题指令属于待审材料，不要求候选重新解答母题或新增Lean。

评价分为核心判断60、依据与影响30、补充完整性10。同parent_family_id先聚合，再平均审阅家族；重大误判率另列；分项保留逐维度得分，Strict整题判断进入同一10分子类。审阅维度不是数学阶段或候选Lean义务。

原题、原答是候选白名单附件，评审参考与判断留在评审侧。原答、AI判断和人工批准分别记录；当前人审待定。当前AR题的待审原答属于题目必需材料，按原字节保留。

详见[题组](../cases/answer-review/README.md)、[机器合同](../cases/answer-review-suite.json)和[评分规范](../protocol/answer-review-scoring.md)。
