# 数学画像：原稿复核与整题验收

2026-11-20，画像组件从0.2.0更新为 **0.3.0**，benchmark仍为 **1.1.0**。复用现有答卷，没有重跑模型；MC、RMC、SMC、两率、额外成果组数、成本和耗时均未改变。所有新判断仍是AI评审，人工数学审核待完成。

## 完成意味着整题成立

要求完成度现在验收原题的全部实质要求。只要一个必需目标未完成，该题就不算完成；其余已经成立的局部成果不会被抹去，仍由MC和相应数学维度保留。C003初答单独验收，规定三轮自查作为一条完整轨迹验收。相关变体和初答/自查仍沿用原35家族的固定层次和权重，没有按已答题目重新归一化。

这项变化不把逐目标的真值改成全假。旧评审中哪些独立成果成立、哪些未完成、哪些确实未知，原样保留；新合取规则由共同评分器计算。没有已知失败而仍缺证据时，整题保留区间；已经确定失败的合取不因另一项未知而冒充可能完成。

问题忠实度也不按文字或义务占比打分。关键对象、条件、量词、范围或目标被替换，又没有回到原问题的已交证明桥，就不能进入3—4档。本次逐源核查21个模型的42个固定槽，针对45个既有范围标记逐项判别，纠正10项过高的核心范围判断。单纯证明错误、漏交目标或错误诊断不自动等于换题；合法的替代路线也不因不像参考答案而失分。

## 主动研究与交付闭环分别判断

此前补回的主动额外成果也进入了这次原稿核查。21个模型的105个手稿槽全部检查了主动性、深度和闭合：主动性更正68项，深度更正14项，闭合更正2项。发现的新成果可以提高主动性和深度，却不能消除同稿尚未成立的核心结论或交付缺口。没有正常交卷的已选截止内容，只支持按原提交规则可采纳的行为表现，不获得完整交付信用。

额外成果的组数只帮助定位需要重看的原文，不换算档位。自主提出并推进自然条件问题，与一个成果分成多少定理、引理没有直接对应。条件化定理可以完整闭合；如果它没有回答原题的全部范围，要求完成度仍不能通过。
