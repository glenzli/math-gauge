# 首答画像的核心验收

评分版本 **1.1.0**，画像组件 **0.4.0**。覆盖全部 **21 个模型、882 个答题及自查槽**，使用统一的原题核心验收尺度和规则选定原答，没有重跑模型。

本文记录这一轮首答验收方法与结果。当前1.2.0另有[首答／含续答切换](mathematical-profile-revision.md)和独立的[开放研究能力](open-research.md)，当前配置范围见新版说明；原七轴来源保持不变。

严格完成度直接采用同一答卷的正式 **SMC**，保留书面35%、Lean35%、研究30%的主榜权重及整条三轮自查规则。六个独立评审轴继续使用固定35家族；页面分别说明家族和SMC计分类别的覆盖，未知保留正式区间。

论证能力要求原题核心成立：必需分支、关键依赖、审计判断或表示桥未建立时，不能用其他正确义务或文本比例抵补到3、4档。复核修正了86项过高判断；另22项仅有可分离题外错误，按相同核心尺度补回，原错误在可靠性、审辨和SMC中继续保留。正确反例及合法替代路线仍可得满档；TX原题基线不因缺额外R3自动降档。

本轮复用未变的源绑定断言、完整目标、语义和编译核验，逐槽重判画像中的原题核心；没有声称重新编译全部工程或另做一轮独立全文数学评审。原答、数学评审、完整目标事实、MC/RMC/SMC、两率、成本及耗时不变。
