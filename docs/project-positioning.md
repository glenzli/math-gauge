# 项目定位

Math Gauge 测量数学任务在实际给定条件下是否完成、自然语言目标与 Lean 声明是否对应，以及模型能否审阅真实写出的数学答卷。正确结论需要有效论证；在更强前提下成立的结果不能自动完成较弱前提下的原目标。

题材涵盖分析、代数、拓扑、范畴与几何。评审保留原有假设、量词、定义域与结论强度，不补入分离性、完备性、统一界或全局提升条件。九项[考察重点](../cases/by-focus.md)是交叉阅读索引，不是九个独立能力分。

## 当前范围与样本

0.4.0默认公开基准包含36份任务：18份书面推理、6份Lean语义审计、6份Lean生成与修复、2份整章形式化，以及4份真实答卷审阅。原数学题库另有11份显式后备；43份数学试卷与4份审阅任务共47条相关任务记录。公开36份任务关联32个母题家族；综合开发报告再接入3份私有研究探索后，共39份任务、35个母题家族。

每份完整题组或整章是一份相关样本；阶段、义务、重复作答和自查版本不能拆成独立试题。4份审阅任务直接关联既有4份母题并共享历史执行来源，不能当作4个独立新增数学家族。同母题审阅先聚合，再在审阅方向内汇总。

整章题提供含证明的完整原文，测量该条件下的形式化交付，不测未提供证明时的独立发现。审阅题提供完整原题与真实原答，只要求审阅其中实际作出的断言，不要求重新完成母题或补交Lean。

## 分项与解释范围

公开基准有五个能力方向，综合报告加入研究探索后有六个方向。真实答卷审阅占能力分10%；公开版原四方向各22.5%，合并版原五方向依次为22.5%、18%、18%、18%、13.5%。综合分统一由75%能力分、5%重复作答稳定性、10%无反馈自查、10%立场干扰下的自查构成。详见[评分标准](../protocol/benchmark-scoring.md)。

作答稳定性与自查表现从公开任务中固定选取6题检查，不代表36或39份任务的普遍可靠性。三次独立作答检查完整交付的稳定性；无反馈自查和立场干扰下的自查看重点数学正确性。其提示指明检查对象，不等于完全自主查错；无论据立场也不等于真实外部反证。

真实答卷审阅按每题核心判断60分、依据与影响30分、补充完整性10分审核，重大误判率另列，严格通过仅作辅助诊断。当前8份既有审阅答卷按新规重评；AR纳入和权重变更发生在观察结果之后，是方法更新及重算，不是一次新考试。旧原答、执行与审核证据保留。

## 证据与当前状态

[当前结果](benchmark-comparison-2026-11-03.md)为AI审核的暂定开发比较。题目与答卷均待人审；作者Lean、候选编译、公理审计、数学语义对应、执行来源审核及人工批准分别记录。原43份数学卷的作者证据不覆盖新增审阅任务，也不能代替候选交付或人审。

完整合法反例、有效短证、不同构造和替代形式化均可完成对应目标，参考路线和篇幅不是隐藏义务。诚实未完成、错误论证、交付缺失、环境故障与审核未决分别报告，不按已完成部分重新归一化。

参考及Git历史继续公开，供透明复核；它们不属于候选输入，本题库不宣称隐藏留出或保证训练未见。请求型号、日期与散列不能独立认证实际后端。正式比较需核实运行真实性、公平性、题目与答卷的人审及适用的Lean门槛，当前不具备认证排名资格。

所有公开与私有任务共用runner。候选只接收白名单题面、附件和允许的本分支历史；外部harness分开保存solver、controller和evaluator材料。无工具与显式本地工具/禁止外部搜索的条件分别冻结与报告，不混合解释。

当前题库与任务包版本为0.4.0；已发布0.3.0及历史资产保持原样。
