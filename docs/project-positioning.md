# 项目定位

Math Gauge 测量数学任务在实际给定条件下是否完成，以及自然语言目标和 Lean 声明是否表达同一命题。一个正确结论需要有效论证；较强前提下的有效结果也不能自动完成较弱前提下的原目标。

题材涵盖分析、代数、拓扑、范畴与几何。对象可能缺少分离性、完备性、统一界或全局提升条件，评审不能补入惯常结构。重点包括假设作用域、量词与常数依赖、定义域、局部整体、结论强度、存在与取到、构造分类、证明依赖及 Lean 语义覆盖。九项考察重点及实际阶段依据见[分类索引](../cases/by-focus.md)。

## 样本与任务

当前43份试卷构成公开开发题集（public development suite），按任务交付分为书面论证29份、Lean语义审计6份、Lean生成/修复6份、整章形式化2份。前41份是相依阶段构成的递进题组，两章分别含34/92项义务。每份完整试卷是一个样本，阶段、义务、同源变体与同一答卷的后续版本具有相关性。

整章题给出含证明的完整原文和固定外部背景，测量“原文与证明 → Lean”，不能由此声称测量了未提供证明的独立发现。书面审计也不自动承担源码生成义务。

完整合法反例可以解决相应全称目标。有效短证明、不同构造、合并声明和替代形式化均应接受；作者路线、引理名称或证明长度不是额外门槛。诚实未完成、错误证明、交付缺失与环境故障分别记录。

## 待测问题与当前边界

[综合评分标准](../protocol/benchmark-scoring.md)把四种交付分别归一化，并以事前权重形成能力分；再加入三次全对、中性自查和立场下正确性形成综合分。分项、严格通过和错误类型仍可分别查看。默认权重表达测量重点，不能据此声称难度已经校准、分项彼此独立或获得普适能力排名。章节只有两份，自查只有八个重点，覆盖边界必须随分数一起显示。

[可靠性计划](../protocol/reliability/README.md)拟研究三次独立作答的完成分布，以及两轮定点自查会纠错、补全、保留还是改坏答案。八个预选重点四真四假，中性、支持与怀疑分支共享A1起点。它测量固定提示下的定点自查和无论据立场影响，不能推出接受真实外部反证的能力。

当前没有候选模型答卷、轨迹或通过率。题面更长、阶段更多或整卷完成率较低，均不能单独证明区分度提高。作者证据已有43份完整覆盖，但不构成候选结果；所有题目仍为draft / human pending。

参考答案及既有 Git 历史继续公开，便于透明审查；它们是 evaluator 出题材料，solver 仅接收显式白名单投影。公开开发题集不作为未公开留出集，来源公开也不保证训练未见。正式模型比较资格要求题目和答卷的真实人工审核，并核实运行真实性与公平性；AI审核的暂定比较必须明确标注其状态。

运行入口不依赖 Codex。共享命令适配器与[外部 harness](../protocol/external-harness.md)共用冻结计划、逐项审核和固定分母评分；外部模式可把 solver/controller 题包交给其他平台，评审材料单独保管。当前固定版本为无工具轨道；增加检索、代码执行或 Lean 工具须作为另行冻结条件与版本的实验，不混入无工具结果。
