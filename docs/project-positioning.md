# 项目定位

Math Gauge 测量数学任务在实际给定条件下是否完成、自然语言目标与Lean声明是否对应，以及模型能否审阅真实写出的数学答卷。正确结论需要有效论证；在更强前提下成立的结果不能自动完成较弱前提下的原目标。

当前为**本地0.6.0草稿 / human pending，尚未发布**。题材涵盖分析、代数、拓扑、范畴与几何；评审保留原有假设、量词、定义域与结论强度，不补入分离性、完备性、统一界或全局提升条件。九项[考察重点](../cases/by-focus.md)是交叉阅读索引，不是九个独立能力分。

## 当前范围与样本

默认公开基准包含26份相关任务：14份书面论证、4份历史Lean语义审计、4份大Lean形式化和4份真实答卷审阅，共18个数学家族。另31份显式reserve保留原路径，全bank共57条任务。合并3份私有研究探索后为29份任务、21个家族。精确清单以[suite](../cases/suite.json)、[profile](../protocol/benchmark-profile.json)及[0.6选题说明](selection-v0.6.0.md)为准。

大Lean形式化为LCH01的8项、LCH02的20项、历史HCH02的40项及原MG-C003的92项。前三份共享CH2家族，先家族内聚合，不能作为三个独立家族重复加权。历史审计含两对失配/正确对照，以35/20/30/15四维审阅，不增加候选Lean生成义务；历史中间版本的公开可得状态尚未核实，不能据此称隐藏留出或已公开历史发布。

每份完整题组或整章是一份相关样本；阶段、义务、重复作答和自查版本不能拆成独立试题。默认数学阶段/形式化义务共226项，与15项书面判准、16项语义审计维度和12项AR维度分开记账。4份AR关联既有母题并共享历史执行来源，不构成4个新增独立数学家族；同母题审阅先聚合，再在审阅方向内汇总。

整章题提供含证明的完整原文，测量该条件下的形式化交付，不测未提供证明时的独立发现。审阅题提供完整原题与真实原答，只要求审阅其中实际作出的断言，不要求重新完成母题或补交Lean。

## 分项与解释范围

公开能力分有四个方向，合并研究探索后有五个方向，按冻结的[profile](../protocol/benchmark-profile.json)及[组合政策](../protocol/composition-policy-v0.6.0.json)计算：

| 能力方向 | 公开权重 | 合并探索后 |
| --- | ---: | ---: |
| 书面论证 | 22.5% | 22.5% |
| 历史Lean语义审计 | 22.5% | 18% |
| 大Lean形式化 | 45% | 36% |
| 私有研究探索 | — | 13.5% |
| 真实答卷审阅 | 10% | 10% |

能力分只取A1，并先按数学家族聚合；综合分统一由75%能力、5%重复稳定性、10%中性自查、10%立场自查构成。缺测、执行失败和审核未决保留固定分母，不按已完成子集重新归一化。详见[评分标准](../protocol/benchmark-scoring.md)。

协议0.4仅从书面任务中选取GR002、GR014、GP001、GP002四题检查重复与自查：各两次独立作答A1/A2，neutral/affirm/deny从各自A1开独立分支，各一次。公开标准42条记录（26个A1、4个A2、12个R1），合并探索45条；它们不能推为全部26或29份任务的普遍可靠性。提示指明检查对象，不等于完全自主查错；无论据立场也不等于真实外部反证。

8份Lean能力任务只用fresh A1。两模型各18个标准新槽包括8份Lean A1及GP001/GP002各完整5槽；相容的旧written/AR记录和GR002/GR014五槽包按原生成身份复用，保留每源系统、参数、工具条件、实际内外预算及未知项。选题与组合均发生在观察结果之后，不是全套同步fresh新考。MG-C003的92项对齐专项另固定3次中性追问，不计入标准42/45槽、权重或分母，也不能用续作替代首次A1；操作续接不自动取得正式fresh A1身份。

真实答卷审阅按每题核心判断60分、依据与影响30分、补充完整性10分审核，重大误判率另列，严格通过仅作辅助诊断。8份既有审阅答卷按新规重评；AR纳入和权重变更是观察后的方法更新，不是一次新考试。旧原答、执行与审核证据保留。

## 证据与当前状态

[既有0.5.0暂定开发比较](benchmark-comparison-2026-11-03.md)保留原配置、覆盖与结果身份，不能当作0.6.0完整成绩。题目与答卷均待人审；作者Lean、候选编译、公理审计、数学语义对应、执行来源审核及人工批准分别记录。原作者证据仍限43份数学卷、372项义务和470个模块，新增范围不继承其覆盖，也不能用作者证明替代候选交付或人审。

完整合法反例、有效短证、不同构造和替代形式化均可完成对应目标，参考路线和篇幅不是隐藏义务。诚实未完成、错误论证、交付缺失、环境故障与审核未决分别报告。可读文本、成功终态和完整工程交卷是不同证据，按[终态证据说明](../protocol/native-terminal-evidence.md)和[到时封卷规则](../protocol/deadline-submission.md)留存；观察后收取的首份工程及操作续接属于独立诊断，不改写标准A1。

参考及Git历史继续公开，供透明复核；它们不属于候选输入，本题库不宣称隐藏留出或保证训练未见。请求型号、日期与散列不能独立认证实际后端。正式比较需核实运行真实性、公平性、题目与答卷的人审及适用的Lean门槛；当前正式资格为false，不具备认证排名资格。

所有公开与私有任务共用runner。候选只接收白名单题面、附件和允许的本分支历史；外部harness分开保存solver、controller和evaluator材料，私有题、答案、判据及逐题结果不进入公开ZIP。无工具与显式本地工具/禁止外部搜索的条件分别冻结与报告，不混合解释。

当前0.6.0仅为本地草案；已发布[v0.4.0](https://github.com/glenzli/math-gauge/releases/tag/v0.4.0)及更早资产、原答与旧审核保持不可变。本地准备、检查与导入不调用候选模型，也不表示已发布新任务包。
