# 未交卷原稿的明确选择

来源选择例外组件 0.1.0 单独记录用户在观察后指定的原稿。它是结果级来源附录；Benchmark 1.0.0 的封版文件、题目、量规、权重和原始审核保持原字节。

默认采用第一份正常 final；没有正常 final 时，MC 核验规则选定的末次有效尝试在截止前留下的原始数学成果。某条记录若另获用户明确指定，可仅为 MC 采用那一份独立核验的未交卷原稿，并由该记录的提交政策列出准确的例外描述符。它不启动新测试、不自动挑选其他题的最好尝试，也不适用于已存在正常 final 的题。

例外须保留用户原话、消息来源、实际事后选择时间、物理和有效尝试次数、原生截止 seal，以及唯一原稿的字节数和散列。原稿必须确实存在于该次截止 seal 中；全部其他尝试和原审核继续留存。不能修补原稿、读取隐藏思考或跨尝试拼接，也不能改写为正常交卷、执行时预注册或人工数学批准。

该题 RMC、SMC 仍为 0。实际末次失败的操作记录、计时与用量不变；被指定的 MC 原稿另行绑定。公开侧只含匿名例外描述符和合并成绩，原稿、私有题标识及完整选择证据留在私库。

The result-level exception records an explicit post-observation user choice of one original nonfinal artifact for MC only. The default first-final/last-effective rule and sealed benchmark bytes remain unchanged. Exact authorization, attempt numbers, cutoff seal and original bytes must be retained; source repair, hidden reasoning, cross-attempt unions and automatic best-of selection remain excluded. RMC and SMC stay zero. Operational timing and usage continue to follow the actual last effective failure; private evidence stays private.
