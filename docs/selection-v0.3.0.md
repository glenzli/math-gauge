# 0.3.0 默认题集：32题、80次运行

本次把默认公开开发集从43题精简为 **32题**，另 **11题进入备选**。所有原题及参考材料保留，11道备选整题放在 [cases/reserve/](../cases/reserve/README.md)；备选题可显式单独运行，不进入默认题包和默认综合分。目录与成员关系见[题目索引](../cases/README.md)。

筛选发生在[Terra 开发试跑](terra-pilot-2026-11-02.md)之后，不是预先登记的独立验证。该轮41个非整章题组三次均通过，不能据此精确排出这些题的难度。因此本次同时考虑考点重合、交付形式、长依赖和边界覆盖；“移入备选”不表示证明简单或数学内容无价值。

## 运行与计分安排

| 部分 | 安排 | 次数 |
| --- | --- | ---: |
| 默认能力评测 | 32题各一次独立 A1 | 32 |
| 重复稳定性 | 预定六题额外各做 A2、A3 | 12 |
| 无反馈中性自查 | 同六题各两轮 | 12 |
| 立场影响自查 | 同六题分别支持、怀疑，各两轮 | 24 |
| 完整计划 | 以上所有槽位去重 | **80** |

两章默认各做一次。独立作答使用新上下文；三个自查分支分别从同题 A1 出发，每个分支的第二轮只延续自己的第一轮，不交叉共享回答，也不接收评审反馈。是否使用本地工具仍只由事前条件决定，不额外提示使用 Lean。

**能力分只使用32份 A1**：四类仍各25%，先按整份试卷归一化。六题的额外 A2/A3 只进入重复稳定性诊断，避免因选择性重跑改变能力分的题目权重。重复项分母为六题，中性自查分母12，立场分支分母24；综合权重仍为70/10/10/10。44份独立初答的严格通过率另报，不能冒充32题 A1 通过率。

可独立跑书面论证、Lean审计、Lean生成、整章、重复、中性或立场目标；所需父回答算在实际调用量中。例如单跑中性目标需要6份 A1 加12份自查，共18次；单跑立场目标需要6份 A1 加24份自查，共30次。合并目标时复用同一冻结计划中的父回答，避免重复收费。缺测维持冻结分母与区间。

旧版177次计划继续按旧版43题三次平均的公式解释；新旧版本不得直接混用分母或汇总成一次实验。已对同批旧答卷另做[32题方案事后分析](terra-pilot-2026-11-02.md)，综合分93.15；该分析既不是新执行，也不是新中性题包的执行成绩。

下一轮先冻结本版成员、次数和提示，再运行。出现错误后可以分析其无反馈自查表现，但不能事后改选面板、删除难题或改总分分母。对更难的新题，优先增加需要交付表示桥、合法反例和多项端点计算的连续任务，而非只给单个命题加更长文字。
