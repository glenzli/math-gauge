# 分类、题型和评测方式

当前为benchmark **0.6.0本地开发草稿**；分类聚合方法 **0.8.0**、Strict **0.2.0**、非逻辑重跑接纳 **0.1.0**。均为观察已有答卷后的方法调整，AI审核、人审待定，正式比较资格为false，尚未发布。

主分类用于计分；题库的F01至F09标签是跨题能力索引，不另立权重。物理目录与原case合同保持原样，可由[catalog](../cases/catalog.json)的source_categories追溯；categories是当前三大类／八子类。私有研究探索原任务并入书面论证，不发布公私独立总分。

书面论证要求有依据的证明、反例或条件化结论；论证审阅要求识别错误、定位证据并说明影响。Lean语义审计检查已给声明的意义，形式化要求交付真正对应目标的工程，对齐自查观察连续三轮真实修复、判断与退步。四档形式化8／20／40／92项只是相关规模变体，CH2三档先聚合，不能让规模档数变成额外家族权重。

研究的“背景核查”强调无专项提醒地审查资料：不能仅照着有问题的背景推出后果，也不能把明确假设当成错误；要给出可核验修正及其影响。“命题拓展”强调证明严格更强结论、更弱条件或统一结论，并识别继续拓展的障碍。三个子类分别侧重材料依据、研究稿的严格完成和数学结论的拓展。新题加入前冻结研究目标与成功判准，安排正确背景的控制样本、反例与误报判准；背景核查公2／私2已建；研究稿完善仍0题；命题拓展保留6个家族的源绑定A1记录，明确标注为观察后选题和计分方法，不冒称新预注册。

研究稿完善从尚未定型的研究方案出发，要求明确概念与命题、补齐证明和边界、整理依赖，形成可检验的完整数学稿。核心目标、允许修正与成功判准须事先冻结；分项按实际数学完成度，Strict按整份稿的全部实质要求。具体题目尚未加入。

分项逐要求计分，Strict整题二值，均先聚合家族再按固定子类权重相加。Lean自查独立10分：分项固定三轮平均并扣误报，Strict评整段轨迹，不能仅看最后一份工程。命题拓展6题与背景核查4题各占10分，研究稿完善10分待建，已建权重90。正式没有研究邀请；按首答R档位减B基础错误扣分，Strict要求B2/R3。主表为已确认贡献／100，未测题保留未知和固定分母，完整总分保持区间。[完整评分标准](../protocol/benchmark-scoring.md)和[机器政策](../protocol/scoring-policy.json)定义精确合同。

现有三家材料是来源条件不同的观察后组合；新方法不是重新考试。题目、原答、工程和原审核不因重分类而改写；人审和运行认证仍待定。新运行须独立上下文、完整原返回与自评、封卷工程及明确预算，不以文件散列认证真实后端。

当前评分提供数学能力MC、可靠数学能力RMC（默认主分）和严格数学交付Strict，首次与允许重跑分别记录；原文的“分项”数学数值对应RMC。MC新增的正向换算不更改原答、源审核和原RMC/Strict分值，见[当前完整报告](results.md)。
