# 评测方法与证据

一次可复核评测先明确题目、评分与运行条件，完整投放候选材料，保留原始输出，再对同一答卷作数学与交付审核。共享runner核对合同、身份与审核绑定；数学正确性仍需阅读实际论证。

## 当前输入与范围

0.4.0的默认公开基准含36份任务：原32份数学任务和4份真实答卷审阅。11份后备数学卷仍须显式选择；3份私有探索只在合并报告中接入，合并能力范围为39份任务。公开36份任务关联32个母题家族，合并39份任务关联35个家族。历史发布与旧原答不改写，新增审阅与母题的相关性明确保留。

候选只接收task、可选中性instruction和显式solver_files。共享 `candidate_message(request)` 传递完整附件；参考、评分、来源、真假、分类、审核与作者证据留在评审侧。审阅任务接收完整原题、完整原答及适用的本轮核查文本，不接收作者模型名、既有分数或新参考。原题的作答要求是待审材料，不构成本次审阅者重新作答或提交Lean的义务。

目录分离不提供执行隔离。独立作答使用新上下文，三个自查分支互不可见；保存角色顺序、完整文本、附件、尝试、偏差与运行条件。[外部harness](../protocol/external-harness.md)分开solver材料、controller调度和evaluator完整计划。导入与散列核验不独立认证运行来源或后端。

## 数学、审阅与汇总

原数学任务逐项审核假设忠实性、论证有效性、范围与不必要限制。猜对真值但证明无效不通过；条件化贡献与原目标完成分开记录，接受有效短证和替代路线。整组严格通过要求全部必答义务满足；后题若独立重证正确，不因前题错误自动失败。

真实答卷审阅按每题100分记录：核心判断60、依据与影响30、补充完整性10。同母题先聚合，再在方向内平均；重大误判率单列，严格通过仅作辅助诊断。判准不能要求候选照抄参考或修复母题。定义和裁决边界见[审阅评分合同](../protocol/answer-review-scoring.md)。

能力分只使用每份任务的首次独立答卷；重复与自查不重复进入能力。公开版原四方向各22.5%、审阅10%；合并版书面推理22.5%、Lean审计18%、Lean生成修复18%、整章18%、探索13.5%、审阅10%。两版综合分均为75%能力分、5%重复作答稳定性、10%无反馈自查、10%立场干扰下的自查。

当前AR纳入、权重和8份既有审阅答卷重评发生在观察结果之后，明确标为方法变更与重算，不是新考试或事前冻结的独立比较。原始数学完成分、原答、执行及旧审核保留；已发布版本保持不变。[综合评分标准](../protocol/benchmark-scoring.md)给出当前分母与版本边界。

## 作答稳定性与自查表现

从公开数学任务中固定选择6题，每题额外独立作答两次，并分别进行无反馈、支持立场、怀疑立场三个分支、各两轮自查。公开全计划84份记录，合并探索后87份：36或39份首次答卷、12份额外独立答卷、36份后续自查。审阅与探索目前只做首次答卷，不在这6题的重复/自查分母内。

重复作答稳定性是这6题三次严格全对的比例。无反馈与立场干扰下的自查看12份与24份后续的重点数学正确性。真假标签、核查论据、完整答卷和交付状态分别报告；重点正确不能掩盖其他交付缺口。起点没有已知错误时，纠错率没有分母，记为不适用。

KEEP继承紧邻上一版完整主体，FULL重新提交整份答卷。当前核查中的确定数学断言仍要审核，不能仅因KEEP或真值标签正确而判通过。保留首次、第一轮、第二轮的完整轨迹；技术失败、数学错误、未完成和审核未决分别记录。详见[执行协议](../protocol/reliability-execution.md)与[自查评分](../protocol/reliability-scoring.md)。

## 分开的证据链

| 证据 | 证明什么 | 不能代替什么 |
| --- | --- | --- |
| 软件与材料检查 | 当前合同、路径、散列与白名单投影 | 数学正确性或真实模型能力 |
| 作者Lean编译与公理审计 | 固定源码在固定依赖下通过核验 | 语义等价、候选交付或人审 |
| 候选原样Lean核验 | 同一冻结答卷满足编译、公理与交付门槛 | 数学语义对应 |
| AI或人工数学审核 | 对实际论证的具名裁决 | 其他身份审核或后端认证 |
| 运行证据与来源审核 | 原始尝试、上下文与可观察执行的绑定 | 公平性、人审或数学正确性 |

原43份数学卷作者证据为43/43份、372/372项义务、470个已编译模块；这些历史身份只在源文件与依赖不变时复用，不因AR纳入重编。生成、修复和整章的候选严格通过仍需完整原样工程、适用公理审计和逐义务语义对应；作者参考不能替代候选交付。

未知精确分为null并保留固定分母区间，区间不是置信区间；不以已完成子集重新归一化。题包缺陷需独立复核与版本处理，不按模型答卷好坏删题。题目与答卷目前仍待人审，当前图表只是暂定开发比较。
