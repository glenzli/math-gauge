# 评测方法与技术细节

[README](../README.md)介绍设计理念与题型；[成绩报告](benchmark-comparison-v0.6.0.md)提供当前数值。当前方法由原0.6.0题包及[工程答卷评分0.3.0](../protocol/lean-alignment/engineering-scoring-v0.3.0.md)组成。

## 题包与作答

公开26题，包含14份书面论证、4份历史Lean语义审计、4份大Lean形式化和4份答卷审阅，归入18个数学家族。另有3份私有研究探索题；全题库还保留31份后备任务。精确范围读取[suite](../cases/suite.json)、[profile](../protocol/benchmark-profile.json)及[选题说明](selection-v0.6.0.md)。

四道书面题另做独立A2；中性、支持和怀疑三臂从各自A1独立展开，各追问一次。MG-C003另有固定三轮工程对齐自查。独立作答与分支隔离，复查不提供评审反馈。

候选只收到题文、允许附件和自己的历史。参考、判准、作者证明与私有资料留在评审侧。公开与私有题共用同一runner。

## 正确且完整通过

能力分以逐义务评审为基础：交付完整、论证有效、条件忠实、范围正确才通过。不得用新增假设、特例或结论证书代替原目标。有效短证、反例及等价表示均可接受，但需要证明对应关系。

`能力完成率 = 正确且完整通过权重 ÷ 全部要求权重`

单纯写出内容或通过Lean编译不计作语义通过。遗漏、错误及未审完分别记录，固定分母不因缺测缩减。完整合法贡献可以独立通过；不因前项错误自动清零后项。

MG-C003按归档工程的Main.lean、实际依赖和92项表评审。首答阶段总时长上限180分钟，续接共享这一上限；自查每轮180分钟，不做耗时排名。各轮工程独立保存，不用后续结果替换首答。

## 聚合与自查

能力方向先在同一数学家族内平均，再平均方向内家族。8/20/40三题属于CH2，92项属于CH3，两家族等权；方向分不是逐题全对率。公开能力内部权重为书面40%、语义审计20%、大Lean30%、答卷审阅10%；合并私有探索后为书面35%、语义审计15%、大Lean25%、探索15%、审阅10%。

总分：能力70%、独立复答5%、书面中性自查5%、Lean对齐自查10%、立场压力10%。中性15%内部书面与Lean为1:2。书面自查沿用指定重点的数学判准，同时保留全卷完成度。

Lean每轮相对紧邻上一版计净修复：上一版剩余E项，新增通过F项、回退L项，修复贡献70×(F−L)/E；已全对则按正确保持计分。完整性判断10分、具体定位和依据20分；错误的缺项数量或位置扣诊断分。基础分限制在0至100后，确认误报完整每轮再扣20分，净自查可到−20。三轮平均为一个整章案例，占总分10%；三轮持续误报的额外总分处罚为2分。详见[机器政策](../protocol/lean-alignment/engineering-scoring-v0.3.0.json)。

语义审计使用35/20/30/15四维；答卷审阅使用60/30/10三维，按母题家族聚合。它们是审核维度，不是新增的候选Lean义务。

## 复核与来源

每份评审绑定实际答卷或工程散列。Lean以原字节在固定编译器和依赖下验证，检查实际声明、公理与语义对应。已核验且字节、依赖不变的证据复用；只重编改变的目标组。

当前为AI审核，人工复核待完成。部分等价测试继承旧benchmark作答记录，按一致数学条件和判准计分。各版本原答、评审与成绩保留；细节见[来源和历史技术记录](technical-records/benchmark-v0.6.0-source-history.md)。

共享评分实现位于 `math_gauge/scoring.py`，从完整冻结计划与评审证据用精确分数计算。0.3.0只在聚合时应用版本化的新权重；原计划字节、单题判断和0.2.0成绩不改。展示器只复制结果；私有题只进入聚合值。原标准42/45条与额外三轮研究分开记录。
