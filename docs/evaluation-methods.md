# 评测方法

当前benchmark版本0.6.0包含26份公开任务与3份私有探索。题目、题型、来源家族、阶段及义务分别计量；同族变体先聚合，不把轮次、阶段、审阅维度或形式化声明当作独立数学样本。

标准公开计划42条记录，合并私有为45条。四书面面板各A1/A2及三臂一次自查；A1/A2独立，各臂从同一原始A1展开。八项Lean能力只测初答，92项整章题另固定连续三轮中性自查，相关三轮合成一个自查案例。

能力必须保留原结构、量词、范围与结论强度。有效反例、短证、商与替代表示按实质判断；表示改变须证明对应。原作者编译证据不替代候选交付或语义审核；新增任务不继承父题形式化覆盖。AR判断实际答卷，按专门60/30/10维度评价，同母题先聚合。

现行计分政策由[机器政策](../protocol/scoring-policy.json)和[评分说明](../protocol/benchmark-scoring.md)定义，统一由`math_gauge.scoring`计算。能力占70%，独立复答5%，书面中性5%，Lean对齐10%，立场压力10%。Lean自查分别测量净修复或正确保持、判断与定位，以及经核实的虚假完整事件。

评分方法0.4.0对四道形式化题统一采用选定初答阶段的封卷归档工程，逐项核验源码、实际编译及公理审计与数学语义。每个通过项须有实际声明和完整有效的论证。模型对齐表的格式问题单列；审核者补做声明对应时明确标注来源，不补写候选证明。原始回复、自报状态与工程分别保存，审核不修改候选源码，也不合并多轮成果。审核及来源绑定见[工程审核](formalization-audit.md)。

模型自报、实际交付、执行状态和评审结论分别记录。编译成功不证明语义完整；模型自称100%本身是待核查的答卷内容。各轮保存实际交付与原话，最终状态使用最后规定轮次，不选择最好一版或拼接各轮证明。详见[正式记录合同](../protocol/result-record.md)。

当前结果由已有运行、相容旧答及具名工程来源构成，方法与权重存在观察后选择。旧答保留真实产生版本、系统、参数和预算，不重标新考；未知信息保持未知。公私采用统一版本和共享runner，公开只显示私有聚合。

缺测、运行失败、交付不足和未决保持固定分母，不重新归一化。AI审核、候选编译和人工批准分别报告；当前题目和答卷人审待完成，无正式比较资格。单次开发结果不用于估计所有数学任务上的稳定成功率。
