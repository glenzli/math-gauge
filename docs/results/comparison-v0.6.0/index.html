方法变更与解释范围

观察结果后的重评

本地0.6是观察后选题与分层开发组合；新补考和旧答复用分别保留实际来源、预算及条件。缺测保留完整分母，专项续作不自动成为正式fresh A1；原答、旧结果与发布资产不重写。标准三臂仅测书面；92项Lean对齐专项固定三次中性跟进，单独归档、不替代A1、不入标准分。候选实际消息、原答、旧评审快照与真实执行证据均保留。

为什么单列这些项目

各能力方向反映不同交付；稳定性与两种自查反映不同协作条件；审阅另看重大误判，整章另看义务完成。总分与能力分作概览，严格通过作辅助。九个交叉重点标签不另造分数或重复加权。

执行与审核分别记录

新原生初答、旧答复用与后验重评分别保留对应来源。两边允许本地工具、禁止外部搜索；预算、上下文与执行批次保留各自证据，不视作一次同步完全等条件竞赛。中断与续接保留原始记录。

暂定开发比较

题目和答卷为AI审核、人审待办；编译、公理审计、语义对应与来源审核分别记录。既有作者Lean证据不自动覆盖新增矩阵任务、加强题或审阅。请求标签和散列不能认证实际后端。公开参考与Git历史不是隐藏留出集，本页不具正式比较或认证排名资格。已发布v0.4.0资产保持不可变。
