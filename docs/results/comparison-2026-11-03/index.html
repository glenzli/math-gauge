方法与解释范围

哪些项目单列

五个能力方向是冻结的主要测量维度；重复、中性与立场反映不同的协作风险，另列三项；两章另看义务完成以暴露工程交付缺口。综合分和能力分用于概览，严格通过用于诊断。九个交叉重点标签没有另外冻结的子分数，不另造排名或重复加权。

同一评分配置，不同执行批次

Terra 复用历史独立答卷并新增两份私有探索；权重在知晓 Terra 旧结果后调整，Gemini 随后使用相同配置。两边允许本地工具、禁止外部搜索，原题交付要求不变。各初答与后续分支按隔离条件处理，预算与来源保留各自记录；这些结果不能视作一次同步、完全等条件的竞赛。

AI 评审与执行证据

Gemini 82份答卷有原生 gpt-6.1-terra/max 主评，root 抽查、仲裁并直接终审 C003；Sol 仅负责工程。83个评分槽对应85次真实原生提交，两次额度中断保留并在原上下文剩余预算内续接，另一次 R2 继续既有分支。旧故障队列不计分。

暂定开发比较

题目及答卷均待人审；AI审核、原样 Lean 编译、语义对应和执行来源审核分别记录。模型请求标签与散列不能独立认证实际后端。公开参考与 Git 历史保留，本题库不宣称隐藏留出集；本页不具正式模型比较资格，也不支持一般能力的认证排名。
