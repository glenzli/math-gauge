# 原生答卷来源接纳补充

本补充适用于当前来源适配；封存版本的结果协议和数学判准保持原样。

`math-gauge.agy-native-evidence/v2`补充已在截止内正常交卷、但外层返回混合了包装内容的来源。计分使用同次封卷数据库中实际完成的可见最终回复，逐字绑定原生成功事件、响应序号与完整原文；原aggregate、首次终态、原CLI清理结果和封卷数据库分别保留。可读的ERROR或DONE不因此变成成功，也不从工作区、其他尝试或隐藏推理补卷。用户消息的分片与完整角色历史须重构为同一份无损输入，并分别核对原题、提供材料及自查自己的实际父答；短启动提示本身不冒充完整题文。

同次原生控制证据由`agy_control_evidence.py`核查实际工具边界，不能用事后新增配置替换旧设置，或用后端回显证明型号认证。历史配置探针、已完成进程的出生身份和原native事件各保留其实际证据范围；缺少独立历史快照就明确标缺，不能补造验证。

原生首答的数学留档仍使用普通`record.json`，但由`native_written_sources.py`、`native_engineering_sources.py`、`native_assessment_sources.py`和既有各数学组件逐项绑定实际原答、原合同与原AI评审，不伪造CLI导入或先前已采用成绩。首次评分来源证明与执行冻结分开；观察后整理的字段映射须保持数学值与原判准不变。若中性续答冻结时父答尚未正式留档，后续接纳必须核对显式来源桥：冻结的自己的完整首答、原评审、入选失分模式与后来仅规范字段的正式首评分逐项等价，不能改写冻结包。记录内引用从该记录目录解析；续答包引用从采用层解析，不搜索同名文件或用损坏材料的其他副本兜底。
