# 数学画像：全卷表现与七轴

评分版本 **1.1.0** 的画像现采用独立组件 **0.2.0**。它不改变 MC、RMC、SMC 或两率，不新增模型作答。完整判准见[数学画像标准](../protocol/mathematical-profile.md)。

七条轴是论证能力、问题忠实度、要求完成度、数学审辨力、主动研究性、数学深度和成果闭合度。全部检查同一组 **39 道初答、三轮规定自查、35 个数学家族**。每家族在每轴权重相同；相关变体先聚合，C003 的初答占家族一半、三轮轨迹占另一半。

旧版“研究深度”“研究完成度”容易被理解为只看六道命题拓展，或只看有没有整篇研究完成。本版改用“数学深度”“成果闭合度”：证明、审阅、背景核查、形式化和手稿中实际成立的相关数学都参与评审。六道拓展题与其他家族等权，不再占这两轴的一半。

- **论证能力**看原问题的关键障碍跨过了多少。
- **问题忠实度**看对象、条件、范围与目标是否保持，合法替代路线是否有返回桥梁。
- **要求完成度**逐一验收原题的完整目标。
- **数学审辨力**看真假、证据、作用域和自身完成判断是否准确。
- **主动研究性**看全卷实际出现的有用超要求探索；题面已经要求的研究或修复本身不自动得主动分。
- **数学深度**看已成立的机制、结构解释和自然范围，题名、篇幅与未证大主张不加分。
- **成果闭合度**看实际交出的实质核心成果是否把证明、依赖、范围与必要桥梁闭合；正确的条件化结果与未完成的原目标分别显示。

各轴均为固定 0—100 刻度，不相加、不按雷达图面积排名，也不随主榜 MC/RMC/SMC 选项切换。完整小成果、深但尚不完整的机制、保持原意的诚实局部进展，可以呈现不同的轴形状。

已确定的空白或无可采纳内容的未交卷按本场规则结算为 0，并计入已结算范围；这不是对模型先天能力的断言。无正常交卷时，仅允许按提交规则核验原截止成果；已有正常答卷则补齐相关审核。只有真正未运行、缺失原始数学证据或确实无法裁决的项目保留未知区间及具体原因，固定分母不缩小。

本次是用户查看旧结果后提出的方法修订。原 0.1.0 政策、评审和数学原件保留，0.2.0 新判断逐项绑定原文来源；正常答卷、截止原成果、编译与语义审核各有边界。公开页只提供合并画像、家族范围与不透明散列；私有题面、原答和逐题评审留在私库。结果仍标 AI 评审，人工数学审核与正式比较资格另行记录。
